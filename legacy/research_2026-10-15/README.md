# 이전 연구 코드 보관

이 폴더는 현재 실행 경로가 아니다. DOSE/TRACE, 상쇄 장부, paired/response 감사, 이전 baseline·집계 실행기와 해당 테스트를 보관한다. 결과는 원래 `FUBA/logs/`에 남겨 두었다.

파일 내용은 이동 전과 동일하다. [이동 목록과 SHA-256](moved_files.json)으로 확인한다. 경로를 전제로 작성된 과거 코드를 이 폴더에서 바로 실행하지 않는다. 과거 실행을 재현할 때는 [정리 이전 커밋](https://github.com/sijoon-sung/BadFU_defend/tree/4c4c38f19d969fa776f75064a112543d8ce2657d)을 별도 checkout으로 사용한다.
