모든 수치는 **1회 실행·소규모**(FUBA: MNIST, K=8, 8라운드 / BadFU: CIFAR-10 ResNet-18, 저자 설정 15라운드×5에폭, 시드 42). 경향으로만 읽을 것.
궤적·체크포인트(.pkl/.pt)는 용량 때문에 포함하지 않았다. 실행 명령은 각 .log 첫 줄과 `LOCAL_SMOKE.md` 참조.

## 2. 빼 보기(release map): 요청자가 나머지 전원의 가상 삭제 분포에서 튀는가

### FUBA — 됨
| 버전 | 기준 | 요청자(4) 순위 / z (clean mass) | 비고 |
|---|---|---|---|
| v2 `loc_fuba_v2` | θ_T | 1/8, z 11.6 | 몰린 클래스 = 진짜 타깃 8; ASR 곡선 9→63 |
| v3 `loc_fuba_v3` | 나머지 전원 중앙값 | 1/8, **z 14.0** (shift z 14.2) | 열화 상쇄로 더 날카로움 |
| `loc_fuba_all` / `_grid` | 〃 + L∞/패치/클래스/열거 입력 | 모두 1/8 (z 3.5~12.6) | 어떤 입력으로 봐도 유지 |
| `loc_fuba_kd` | 〃, 증류 보정 연산 | 신호 소멸 (ASR 곡선 9→9) | 작은 노이즈 트리거는 깨끗한 입력 증류로 억제가 복원됨 → 이 연산은 FUBA엔 부적합 |

### BadFU — 아직 안 됨 (요청자 c5 순위 3~6/6)
| 실행 | 무엇을 바꿨나 | 결과 |
|---|---|---|
| `loc_badfu_raw` | 그냥 빼기 (θ_T 기준) | ρ≥0.8 전원 붕괴(클래스 0으로 89%); 정답 ASR은 ρ 0.2~0.6에서 요청자 40~53 vs 정상 4~17 → **신호는 있음** |
| `loc_badfu_bnrecal` | BN 통계 재추정 | 재추정 자체가 모델을 바꿈(삭제 전 ASR 27→48). 폐기 |
| `loc_badfu_v2` | 작동점 ρ* + L∞/패치 탐색 | 패치 탐색이 일반 열화(클래스 2·3·4)를 잡음. 4~5/6 |
| `loc_badfu_v3` | 기준 = 나머지 전원 중앙값 | 개인별 잡음(25~36%)이 남아 요청자 특이점(+26%p, 트리거 입력에서만)이 묻힘. 3~5/6 |
| `loc_badfu_v3small` | ρ 0.1~0.3 | 깨끗한 입력에서 전원 동일. 5~6/6 |
| `loc_badfu_class` | 클래스별 목표 패치(기울기) | 요청자 최대 클래스 6(정답 0). 4/6 |
| `loc_badfu_kd` | 증류 보정 lr 0.01 | 발산(NaN). 폐기 → kd2(lr 0.001·클리핑·복구)로 재실행 중 |
| (대기) `loc_badfu_kd2`, `loc_badfu_grid` | 증류 보정 v2 / 패치 열거(실제 트리거 3×3 모서리가 후보 안) | 이 둘이 BadFU 결론 |

원인 요약: BadNet 패치 트리거는 깨끗한 입력에 안 새고, ResNet은 기여를 1차 근사로 빼면 누구를 빼도 예측이 크게 흔들린다. FUBA(IBA 전역 노이즈, LeNet)는 둘 다 반대라 됐다.

## 3. 진행형 FU (`progressive_fu/loc_fuba.json`): 강도를 올려 가며 탐지, 걸리면 그 자리에서 정화

| 요청자 | plain | end (끝에서 1회) | **progressive** (경보 때만) | always |
|---|---|---|---|---|
| 4 (공격 설계) | ASR 62.9 / ACC 75.0 | 9.7 / 91.0 | **7.8 / 91.9** (경보 ρ=0.2부터, 정화 3회) | 8.6 / 92.2 |
| 7 정상 | 21.7 / 92.6 | 7.6 / 94.4 | 21.7 / 92.6 (경보 0, 정화 **0**) | 6.9 / 94.5 |
| 5 정상 | 22.4 / 92.3 | 7.3 / 94.4 | 22.4 / 92.3 (경보 0, 정화 **0**) | 7.0 / 94.4 |

- 경보는 ρ=0.2에서 z 8.9로 바로 뜸(완전 풀림 전). 정상 요청은 오탐 0·비용 0.
- 정확 제거는 정상 삭제에서도 ASR 9→22로 샘; "나머지 전원 기준으로 되돌리기"가 그것까지 7로 내림 → 백도어 전용이 아니라 정확 제거의 일반 보정으로도 작동.
- MIA(손실 기반)는 이 모델에서 변별력 없음(AUROC ≈0.5, 삭제 전부터).

## 4. 그 밖에 (DISLAB 궤적, 이미 main 쪽에 올라간 것)
`benign_departure/`, `robust_fu/`, `latent_risk/`의 `bd_owner_s*`, `bd_iid_s*`: 정상 이탈 공격은 반례(정상 삭제 9~14 vs 요청자 30~44, KD-FU), FedEraser 보정 경로에선 활성화 없음, 가중치 서명으로 공격자 집중도 AUROC 1.0.
