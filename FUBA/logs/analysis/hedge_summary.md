## 4. 판정

- iid: 전체 0.333 / 중심화 0.833 (짝 특이도 0.0) → 점수 max(전체, min(중심화, 특이도)) = 0.333 → **갈리지 않음** (< 0.7)

해석: 전체 매개변수 판 AUROC 가 0.5 근처면 위장자의 갱신은 운반자와 반대가 아니다 (같은 방향의 학습 갱신). 공통 성분 제거 판이 높아도 짝 특이도가 낮으면 '위장자가 모두와 반대' 일 뿐 짝이 아니다. 그래서 점수는 max(전체, min(중심화, 특이도)).
