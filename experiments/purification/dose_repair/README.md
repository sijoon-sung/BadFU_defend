# 초기 삭제량·복구 제어

**보관**

- **가설:** 삭제량·보정량·복구 단계를 조절해 효용과 위험을 절충할 수 있다.
- **해본 것:** dose/cancel/unified, progressive FU, pipeline 정화를 탐색했다.
- **관측 결과:** 초기 비교 로그가 남아 있다.
- **현재 판단:** 현재 실제 FU 완료 후 정화 성능과 합치지 않는다.
- **보류 이유:** FU 자체 변경과 정화 효과가 섞이며 삭제 효과를 보존했는지 미확인이다.
