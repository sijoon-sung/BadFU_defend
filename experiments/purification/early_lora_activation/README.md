# 초기 LoRA·지연 재활성화

**보관**

- **가설:** 저차원 보정·후속 학습에서 백도어 억제와 재발을 관측할 수 있다.
- **해본 것:** LoRA 설정과 지연 활성화·재학습 시나리오를 시험했다.
- **관측 결과:** 초기 자체 구현의 코드·로그가 남아 있다.
- **현재 판단:** 후속 연구 단서로만 보관한다.
- **보류 이유:** 공식 원본 공격·동일 삭제·정상 대조로 연결되지 않은 결과다.
