# 요청 처리·기여 제어

**초기 방식 보류**

- **가설:** 요청 기여를 제어하면 잔류 위험과 정상 손상을 조절할 수 있다.
- **해본 것:** 기하 제약, 순차 요청 재생, 실제 잔류 기여 검사를 구현했다.
- **관측 결과:** 수치·입출력 연결 검사가 있다. 현재 정화 비교의 성능 결과는 아니다.
- **현재 판단:** 코드·검사는 유지하고 최신 post-FU 비교와 분리한다.
- **보류 이유:** 요청 처리 변경의 망각 품질과 정상 효용을 별도로 검증해야 한다.
