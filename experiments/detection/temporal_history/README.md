# 시계열 GLR

**보류**

- **가설:** 지속되는 기여 관계를 보면 단일 라운드보다 잘 구분할 수 있다.
- **해본 것:** FUBA 20개·BadFU 10개 점수 경로를 재계산했다.
- **관측 결과:** 저장 결과와 일치했지만 FUBA 최대값은 한 라운드 점수로 설명됐다.
- **현재 판단:** 시계열의 우월성 주장을 보류한다.
- **보류 이유:** 시간을 추가한 이득이 단순 변화량 대비 확인되지 않았다.
