# 정상 설명 집합·로짓 이중 차분

**일부 관측 / 가정 실패**

- **가설:** 정상 변화로 설명되지 않는 요청 효과·변형 반응 증가를 찾을 수 있다.
- **해본 것:** 정상 설명 집합과 이중 차분을 11개 사례에서 비교했다.
- **관측 결과:** 비영 기여 1,110개 모두 설명 실패. 실제 BadFU FU의 탐색 패치 반응은 2.78→73.61%.
- **현재 판단:** 설명 집합은 보류. 실제 FU의 패치 반응은 정화 비교의 단서로 사용한다.
- **보류 이유:** 누적 차감은 정상 모델도 붕괴시켰다. 패치 반응 증가만으로 탐지 성공을 입증할 수 없다.
