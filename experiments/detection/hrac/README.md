# HRAC·기여 관계 관측

**추가 이득 미입증**

- **가설:** 요청과 과거 기여 관계를 함께 보면 위험 요청을 우선시할 수 있다.
- **해본 것:** BadFU·FUBA, 공개 입력·패턴 유무, 요청자·표적 순위를 비교했다.
- **관측 결과:** BadFU 요청자는 패턴 관측에서 1위지만 단순 기준선도 1위. FUBA 표적은 HRAC 9/10/9위였다.
- **현재 판단:** 관측 신호는 남기고 우월성 주장은 보류한다.
- **보류 이유:** 긴 이력의 추가 이득과 독립 정상 오탐률이 확인되지 않았다.
