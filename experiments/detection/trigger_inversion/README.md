# 초기 패턴 역탐색

**보관**

- **가설:** 입력 변형에 대한 출력 차이로 잠재 패턴을 찾을 수 있다.
- **해본 것:** 패치·보편 변형·샘플별 역탐색을 비교했다.
- **관측 결과:** 역탐색 및 클래스별 ASR 기록이 남아 있다.
- **현재 판단:** 최신 실제 FU 이중 차분과 분리하여 보관한다.
- **보류 이유:** 발견 패턴의 반응을 원본 트리거 ASR과 혼동할 수 있다.
