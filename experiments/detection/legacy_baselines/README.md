# 초기 탐지 비교군

**보관**

- **가설:** 기존 탐지 점수와 같은 조건으로 비교해야 추가 이득을 판단할 수 있다.
- **해본 것:** MASA·SUBID 및 초기 탐지 기준선 스크립트를 실행·보관했다.
- **관측 결과:** 기존 실행 로그는 남겼으나 현재 실제 FU 비교와 조건이 다르다.
- **현재 판단:** 현재 제안의 우월성 표에 합치지 않는다.
- **보류 이유:** 같은 원본 모델·요청·자료 분할·튜닝 예산으로 다시 맞춰야 한다.
