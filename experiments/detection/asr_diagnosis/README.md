# FUBA ASR 원인 분해

**진단 완료**

- **가설:** 높은 ASR에 독성 학습 외의 입력·클래스 쏠림이 섞일 수 있다.
- **해본 것:** 정상 대조와 같은 생성기 반응, 클래스별 쏠림을 검사했다.
- **관측 결과:** 정상 대조도 같은 생성기에 높은 반응을 보였다.
- **현재 판단:** ASR 전체를 공격 학습의 효과로 해석하지 않는다.
- **보류 이유:** 보류 아님. 실제 FU·정상 대조를 함께 보는 평가가 필요하다.
