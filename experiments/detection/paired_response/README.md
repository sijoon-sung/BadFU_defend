# 짝지은 반응 관측

**보관**

- **가설:** 같은 입력·요청의 대응 반응을 비교하면 혼동을 줄일 수 있다.
- **해본 것:** paired audit와 response audit를 시험했다.
- **관측 결과:** 관측·요약 로그가 남아 있다.
- **현재 판단:** 후속 이중 차분과 별개인 초기 탐색 기록이다.
- **보류 이유:** 공식 공격·독립 정상 요청에서 우월성이 확인되지 않았다.
