# 초기 기여 구조·잔류 위험

**보관**

- **가설:** 상쇄·잔류 기여의 구조로 위험을 설명할 수 있다.
- **해본 것:** ledger, equilibrium, pair 역할, structural guard를 탐색했다.
- **관측 결과:** 여러 탐색 로그가 있으나 현재 기준의 독립 검증과 구분해야 한다.
- **현재 판단:** HRAC 이전의 가설·구현 기록으로 보관한다.
- **보류 이유:** 점수 크기만으로 정상 Non-IID와 공격 의도를 분리할 수 없다.
