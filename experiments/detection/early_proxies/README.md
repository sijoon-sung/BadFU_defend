# 초기 반상관·프록시 탐지

**보관**

- **가설:** 기울기 반대 방향이나 프록시 공간에서 공격을 찾을 수 있다.
- **해본 것:** 반상관·스펙트럼·프록시 탐지 변형을 시험했다.
- **관측 결과:** 초기 코드와 로그가 남아 있다.
- **현재 판단:** 현재 성능 근거에서 제외한다.
- **보류 이유:** 원본 공격·강한 Non-IID·독립 정상 대조로 같은 결론을 검증하지 못했다.
