# 공통 기여 관측·궤적 점검

**공통 도구**

- **가설:** 동일한 저장 궤적에서 기여·입출력 변화를 재계산할 수 있다.
- **해본 것:** 관측 수집기, 정상 탈퇴, 궤적 등록·무결성 도구를 분리했다.
- **관측 결과:** 탐지와 요청 제어가 공유하는 측정·검사 코드다.
- **현재 판단:** 양쪽 브랜치에서 공통 사용한다.
- **보류 이유:** 독립 방어 기법이나 탐지 성능 결과로 세지 않는다.
