# 초기 자체 구현·점검

**보관**

- **가설:** 단순화한 공격·기울기 점검으로 방어 단서를 얻을 수 있다.
- **해본 것:** 초기 자체 구현과 감사 로그를 남겼다.
- **관측 결과:** 공식 원본 재현과 다른 가정·구현이 섞여 있다.
- **현재 판단:** 과정 기록으로만 보관한다.
- **보류 이유:** 22.53→91.24% 등을 원본 BadFU 재현 성능으로 사용할 수 없다.
