# BadFU_defend

FL에서 숨겨진 백도어가 FU의 삭제 요청으로 활성화되는 과정을 연구합니다. 현재는 **궤적을 정리하고, 저장된 이력과 삭제 요청을 이용한 탐지를 검증하는 단계**입니다.

지금 볼 문서는 두 개입니다.

- [궤적 상태](docs/TRAJECTORIES.md): 어떤 파일을 사용할 수 있는가.
- [실행 안내](RUN.md): 현재 코드와 확인 명령.

**FUBA 학습부터 검증까지:** `python reproduction/run_fuba_experiment.py --dataset cifar10 --download`로 원본 학습 → 전체 궤적 검사 → HRAC·기준선 비교 → 작은 결과 ZIP 내보내기를 순서대로 실행합니다. 먼저 `--smoke`를 붙여 2라운드 연결 검사를 할 수 있습니다. 완료된 동일 조건 학습은 재사용하며, 결과는 Git에 추가할 수 있는 `reproduction/validation/exports/`에 복사됩니다. 독립 요청 자료가 없는 intra 채널과 정상 실행으로 보정하지 않은 탐지 판정은 미측정으로 표시합니다. [조건·예상 저장량·업로드 방법](RUN.md).

**공식 소스 복원(2026-10-15):** BadFU와 FUBA를 저자 저장소에서 다시 받아 커밋·파일 해시로 고정했습니다. 학습은 `python reproduction/run.py`로 통일했고, 이전 학습용 셸 스크립트는 제거했습니다. 원본 복사본에 기록용 어댑터를 적용하며, 실제 실행 코드·패치·전체 모델 궤적을 함께 보관합니다. BadFU의 네 FL·두 FU 단계, FUBA MNIST/CIFAR-10 MPI 학습의 축소 검증을 통과했습니다. 본 실험의 공격 성공이나 탐지 정확도 재현을 뜻하지는 않습니다. [변경과 한계](docs/FRESH_UPSTREAM.md).

FUBA MNIST 6개·CIFAR 공격 3개·정상 4개는 기존 이력 분석 자료로 유지합니다. FUBA의 학습 로그와 추가 검증기는 트리거 생성기·평가 모드가 달라 ASR을 같은 조건의 수치로 볼 수 없습니다. 높은 ASR만으로 궤적 생성 오류를 단정했던 설명은 정정했습니다. 로컬 BadFU 15라운드는 실제 파일 해시와 집계를 확인했고, 별도 방어 실행기의 40라운드 결과와 구분합니다. DISLAB 자료는 업로드된 검사 기록 기준입니다.

| 위치 | 역할 |
|---|---|
| `reproduction/` | 고정 원본 검사·새 학습 실행·전체 궤적 기록과 검증 |
| `FUBA/` | 공격 학습·궤적 검증·현재 탐지 비교·기존 FU 실행 지원 |
| `BadFU_src/` | BadFU 원본과 궤적 저장 실행기 |
| `FUBA/logs/`, `artifacts/` | 원시 결과와 로컬 대용량 자료 |
| `legacy/` | 이전 알고리즘·실험 실행기 보관 |
| `docs/archive/`, `docs/paper/` | 이전 설명·계획·논문 초안 |
| `docs/paper_reviews/` | [선행논문 정리](docs/paper_reviews/README.md) |

현재 작업 브랜치는 `codex/structural-latent-defense` 하나입니다. [나머지 브랜치의 용도](BRANCHES.md)를 구분합니다. 진행 중인 실험은 종료 후 코드를 갱신합니다.

이전 결과는 [과거 탐지 결과 정정](docs/EVIDENCE_AUDIT.md)과 [보관 코드](legacy/research_2026-10-15/README.md)에서 찾을 수 있습니다. **이력–요청 기여 일관성(HRAC)**의 제약 최적화·정상 실행 보정을 구현했습니다. [수식과 검증 결과](docs/RESEARCH_SUMMARY.md)에 실제 궤적과 합성 검증을 구분했습니다. FUBA 개발 결과는 기존 점수와 같습니다.

**최근 BadFU 실험:** 기존 15라운드 궤적에서 깨끗한 입력만 사용하면 요청자 5는 5위였습니다. 네 모서리에 미리 정한 무작위 패턴을 붙이고 **같은 이미지의 패턴 유무에 따른 기여 차이**를 기록하자 요청자 5·표적 0이 1위가 됐습니다. 별도의 이미지 80개와 새 패턴 3개에서도 같은 순위를 확인했습니다. 재학습·FU 실행 없이 얻은 결과입니다. 같은 관측의 단순 음의 기여 기준선도 1위여서, HRAC 점수의 추가 이득은 아직 입증하지 못했습니다. 한 공격 궤적의 탐색 결과이며, 독립 정상 실행의 오탐률과 다른 공격 조건은 미검증입니다. [그래프](docs/figures/hrac_probe_comparison.png) · [실행 방법](docs/UNLABELED_PROBES.md).

**관측 가정 완화:** 이미지의 정답 라벨·클래스별 균형 선별·정답 트리거 없이 실행하는 경로도 추가했습니다. 공개 이미지에서 무작위로 뽑은 80개 × 3묶음 모두 같은 요청자·출력이 1위였습니다. 15라운드 수집은 79.9초였으며, 라운드별 저장·재시작과 긴 검사 명령을 제공합니다. 공개 이미지 자체와 모델 전처리는 필요합니다. [라벨 없는 실행 안내](docs/UNLABELED_PROBES.md) · [원본 결과](FUBA/logs/hrac/unlabeled_badfu_v1/analysis.json).
