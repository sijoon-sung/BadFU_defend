# 결과와 검산 기록

| 위치 | 역할 |
| --- | --- |
| `exports/purification/` | 삭제 후 정화 비교. 기존 2R 결과는 연결 검사이며 본 성능과 구분 |
| `exports/deletion_comparison/` | 실제/근사 FU의 차분·정상 설명 집합 관측 |
| `exports/temporal_history/` | 이력 점수의 시계열 관측 |
| `exports/history_relations/` | 요청자/잔류 기여 관계 관측 |
| 나머지 `exports/` | BadFU·FUBA 공격·정상 실행의 작은 자료 |
| `reviews/` | 업로드를 다시 계산한 검토 결과 |
| `*_review*.json`, `*_checks*.json` | 검산·수학·실행 연결 검사 범위 |
| `fresh_*/`, `*_smoke.json` | 축소 실행. 성능 증거가 아님 |

기존 파일과 ZIP 내부를 수정하거나 옮기지 않았습니다. 경로·해시로 묶인 원본 증거이기 때문입니다. 모델·이미지·전체 궤적은 실행 컴퓨터에 남습니다. [현재 해석](../../RESULTS.md).
