# 현재 상태

현재 판단은 [궤적 상태](TRAJECTORIES.md) 한 곳에서 관리합니다. 코드·명령은 [RUN](../RUN.md)을 봅니다.

HRAC의 두 검사와 정상 실행 보정을 구현했습니다. [수식·검증 결과](RESEARCH_SUMMARY.md)에 실제 궤적과 합성 검사를 구분합니다. FUBA 개발 궤적의 기존 식별 결과는 유지됐습니다.

BadFU 15라운드에서는 깨끗한 입력만 쓴 기존 점수가 요청자를 5위로 뒀습니다. 새 실험에서 **패턴 유무에 따른 동일 이미지의 기여 차이**를 사용하자 요청자 5·표적 0이 1위로 올라왔습니다. 정답 트리거를 사용하지 않는 고정 무작위 패턴 네 위치를 모두 검사한 결과입니다. 다른 이미지 80개·새 패턴 3개에서도 각각 1위였습니다. [그래프](figures/hrac_probe_comparison.png).

이후 **검사용 이미지의 정답 라벨과 클래스별 균형 선별을 제거**했습니다. 공개 이미지에서 무작위로 뽑은 서로 다른 80개 × 3묶음에서도 요청자 5·출력 0이 각각 1위였습니다. 저장 궤적 수집은 79.9초였고, 중간 저장·재시작을 포함한 실행기와 [긴 검사 명령](../RUN.md#라벨-없이-공개-이미지로-검사--현재-실행-경로)을 추가했습니다. 라벨 없는 공개 이미지 자체와 모델 전처리는 여전히 필요합니다.

확인한 학습 궤적은 여전히 하나입니다. 같은 관측의 단순 음의 기여 기준선과 마지막 한 라운드도 요청자를 1위로 뒀습니다. HRAC 점수·긴 이력·정상 기준 보정의 추가 이득, 독립 정상 실행의 FPR, 다른 트리거·FUBA에 대한 전이는 미검증입니다. 실제 대내 검사에 필요한 독립 요청 관측도 아직 없습니다. 다음 검증은 이 관측 방법과 단순 기준선을 함께 고정한 정상/공격 실행 비교입니다.
