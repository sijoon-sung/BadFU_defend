# 방어 논문 지형과 우리 자리 (2026-10-11)

축 두 개로 놓는다. **언제** 보는가(학습 중 / 요청 시점 / 배포 후), **무엇을** 보는가(갱신의 기하 / 언러닝 행동 / 샘플 / 모델 출력). 마지막 열은 "학습 중에 심어 두고 제거로 깨어나는 잠복형(BadFU, FUBA, clean-unlearning, 2026 clean-label)"에 통하는가.

| 방어 | 언제 | 무엇을 | 필요한 것 | 잠복형에 |
|---|---|---|---|---|
| 강건 집계 (Median, Trimean, FLAME…) | 학습 중 | 갱신 기하 | 없음 | ✗ BadFU/FUBA 가 우회 (갱신이 정상처럼 보임) |
| MASA (WACV'25) | 학습 중, 매 라운드 | 각 로컬 모델에 언러닝을 걸 때의 손실, 모집단 중앙값 편차 | 깨끗한 라벨 대리 데이터, 클라이언트마다 학습 | **?** 미검증. 반드시 기준선으로 |
| FedSweep | 학습 중 | 트리거 역공학 + 로짓 엔트로피 | 작은 깨끗한 셋 | ✗ 잠복 중에는 트리거가 억제돼 역공학 불가 (BadFU: NC 불안정) |
| Zhang 2023 | 요청 시점 | 요청 샘플의 지니 불순도 / SISA 부분모델 표준편차 | 요청된 샘플 자체 | ✗ FL 서버는 샘플을 못 봄 |
| Qian KDD'23, Liu AAAI'24 | 요청 시점 | 요청 샘플의 기울기 영향, 클래스 메도이드 | 샘플별 기울기 | ✗ 같은 이유 (중앙집중형) |
| FedMUA 방어 | 언러닝 라운드 | 클라이언트 기울기 노름 IQR, λ 축소 | 없음 | ✗ 수동형 FU(빼기/KD)에서는 요청자가 아무 갱신도 안 보냄 |
| SubID (INFOCOM'26) | 언러닝 라운드 | 학습 부분공간 대비 언러닝 갱신의 편차 (SVD) | 마지막 T_r 라운드 갱신 저장 | ✗ 전제(학습 중 갱신은 정상, 공격은 언러닝 중 새 방향)가 깨짐. 대응이 재학습이라 잠복형에선 공격 완성 |
| UnlearnGuard (WWW'25) | 언러닝 라운드 | 이력으로 갱신 예측 후 필터 | 이력 | ✗ 같은 이유 |
| NC, STRIP, UMA | 배포 후 | 모델 출력으로 트리거 스캔 | 트리거 가정, 요청마다 재실행 | △ BadFU: NC 불안정, 2026: STRIP 겹침. 비용 큼 |
| Fine-pruning, NWC/Activeness, TBAR, Backdoor Vectors, Wu&Zhu | 배포 후 | 백도어 제거 (가지치기·언러닝·벡터 빼기) | 깨끗한 라벨 데이터, 학습 | △ 제거기이지 탐지기 아님. 2026: 활성화된 백도어는 ACC 손실 없이 제거 불가 |
| **우리 (dose-controlled FU)** | **요청 시점** | **요청된 제거의 행동 효과 vs 남들의 같은 양 제거 모집단** | 저장된 갱신(FU 가 이미 보유), 라벨 없는 탐침 n 장 | 설계 목표. FUBA 3 시드 확인, BadFU 미해결 |

빈 칸: **요청 시점 × 수동형 FU × 잠복형 × 라벨·학습 없음**. 여기에 있는 방어가 없다.

## 방향
1. 가족 이름을 먼저 정한다: "언러닝으로 깨어나는(잠복형) 백도어". BadFU, FUBA, clean-unlearning(2506.12522), 2026 clean-label(2607.27936), Zhang 2023 의 단계 요청이 구성원. 방어 목표는 정의 2 로 쓴다: 요청자의 영향은 지우되 남들 입력에서의 행동은 남들을 뺐을 때와 구분되지 않게.
2. 논문은 탐지기가 아니라 **강건한 FU 알고리즘** (DOSE_FU.md). 표시 없으면 기본 FU 와 동일(P1), 무너지지 않음(P2), 정의 2(P3), 멀쩡하면 한 단계(P4).
3. 반드시 넣을 기준선: (a) MASA 를 학습 중에 돌려 잠복형 공격자가 잡히는지 — 이 답이 없으면 "왜 학습 때 안 잡나"에 못 버틴다. (b) SubID·UnlearnGuard 를 요청 시점에 돌려 신호 없음 + 재학습 대응의 역효과. (c) 강건 집계(BadFU 표 인용 + 우리 재현). (d) 방어 없는 FU 4 종(빼기, KD, FedEraser, 재학습).
4. 범용성 증거는 가족 구성원 수로 보인다: BadFU, FUBA 에 더해 한 가지(단계 요청 또는 clean-unlearning 의 FL 판) 가 있으면 "정의로 묶인 가족"이라는 주장이 선다.
5. 지금 결정해야 할 것(실험 아님): 탐침 X_p 를 무엇으로 할지(트리거가 안 보이는 공격 대비), 망각을 어디서 잴지(MNIST IID 에선 불가), non-IID 에서 문턱 τ 를 어떻게 둘지.
