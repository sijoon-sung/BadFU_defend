# 관찰을 알고리즘으로: 다른 논문은 어떻게 했고, 우리는 어떻게 할 것인가 (2026-10-13)

전제: 노벨티(새 불변량)와 범용성(그 불변량이 공격 종류와 무관하게 성립)은 공존하기 어렵다. 좋은 방어 논문은 **불변량 하나**를 골라 그것을 좁은 위협 모델 안에서 알고리즘으로 만들고, 그 안에서의 범용성을 증명한다.

## 1. 다른 논문들이 밟은 다섯 단계
| 단계 | 하는 일 | FLDetector (KDD'22) | FoolsGold (2018) | FLAME (USENIX'22) | BaFFLe (2020) | SubID (INFOCOM'26) | MASA (2024) |
|---|---|---|---|---|---|---|---|
| ① 불변량 | 정상은 만족하고 공격은 깰 수밖에 없는 성질 | 정상 갱신은 이전 갱신과 Hessian 으로 **예측 가능** | 공모자는 라운드를 거쳐 서로 **닮음** | 정상 갱신은 방향이 **한 무리** | 정상 전역 모델은 클라 검증 손실이 **안정** | 정상 언러닝 갱신은 학습기 **부분공간 안** | 정상 갱신은 언러닝 손실이 **잘 오름** |
| ② 점수 | 서버가 가진 것만으로 클라마다 계산 | 예측 오차 (Cauchy 평균값 정리) | 쌍 코사인의 **이력 누적** | 코사인 거리 | 손실 변화 투표 | 잔차 부분공간 에너지 | 손실 상승량 |
| ③ 영분포 | "정상이면 이 정도" 를 데이터에서 | Gap statistics + k-means | 최대 유사도 기준 재가중 | HDBSCAN 군집(과반) + 중앙값 노름 | 적응 문턱 | 창(window) 내 비교 | MAD |
| ④ 대응 | 걸리면 무엇을 하나 | 제거 + 되돌리기 | 가중치 축소 | 자름 + 잡음 | 거부 | **재학습** | 제거 |
| ⑤ 보장 | 위협 모델 안에서의 주장 | 일관성 가정하의 탐지 | 시빌 수와 무관 | 잡음 경계 정리 | 경험적 | 능동형 FU 전용 | 경험적 |
공통점: 점수는 **시간을 누적**한다(FLDetector 는 이전 라운드들, FoolsGold 는 이력 전체). 영분포는 모집단에서 만든다. 범용성은 "①의 불변량이 그 공격군 전체에서 깨진다"로 얻고, 노벨티는 ①이 새로우면 생긴다. 그리고 전부 **갱신 하나의 성질** 또는 **갱신들의 유사성**이다. "갱신들이 서로 **지운다**"는 불변량은 없다.

## 2. 우리가 잰 것 (논문 설정 6 궤적, R-012)
클래스별 누적 밀기 P_j(c) = Σ_t mean_x [f_c(x; θ_{t−1} + u_j^t) − f_c(x; θ_{t−1})] (공개 입력, 참여 라운드만, 역할 정보 없음).
| | 클래스 8 (진짜 타깃) | 클래스 3 (owner 조건의 소유 클래스) |
|---|---|---|
| 위장자 | −30 ~ −39 (6/6 궤적에서 가장 음수) | −30 ~ −39 |
| 운반자 넷 | +3 ~ +16 (각자) | +0.5 ~ +6 |
| 소유자 (owner 조건) | +0.2 ~ +3.8 | **+30 ~ +35** |
| 정상 | −4 ~ +5 | — |
| 순/총 밀기 | 0.07–0.12 (IID), 0.15–0.16 (owner) | — |
읽기: (a) 평형의 균형식이 성립한다 — 합은 거의 0, 개별은 크다. (b) 위장자는 **두 클래스 모두**의 음의 다리다: 운반자들의 8 밀기도, 소유자의 3 밀기도 되민다 (위장자의 방어 벡터가 전역 모델의 흐름을 통째로 되돌리기 때문). (c) 그래서 "분산이 가장 큰 클래스"는 owner 조건에서 3 이 되고, 타깃 추정이 0/3 로 틀린다. 그러나 **위장자 식별은 6/6** 이고, 운반자와 소유자는 **구조가 다르다**: 운반자는 여러 명이 조금씩(coalition), 소유자는 한 명이 크게.

## 3. 알고리즘: 균형 장부 (Balance Ledger) — 제안
불변량 (①): **정상 학습에는 "큰 음의 다리 하나가 여러 양의 다리와 합쳐 0 이 되는 클래스" 가 없다.** 잠복 백도어는 이것을 반드시 만든다 (운반자 = 양의 다리들, 위장자 = 음의 다리). 소유자처럼 큰 양의 다리 하나는 생길 수 있지만, 그것을 되미는 음의 다리는 정상 학습에서는 생기지 않는다 — 생긴다면 그 음의 다리가 위장자다.

점수 (②, 학습 중 매 라운드 갱신, 참여자당 순전파 1 회):
```
장부   P_j(c) ← P_j(c) + mean_x [ f_c(x; θ_{t−1} + u_j^t) − f_c(x; θ_{t−1}) ]      (참여자 j, 모든 c)
헤지   H(c) = 1 − |Σ_j P_j(c)| / Σ_j |P_j(c)|                                       (1 에 가까울수록 '합은 0, 개별은 큼')
다리   neg(c) = argmin_j P_j(c),  Pos(c) = { j : P_j(c) > κ·MAD_j P_·(c) }            (음의 다리 하나, 양의 다리들)
```
영분포 (③): P_j(c) 의 정상 범위는 같은 클래스의 나머지 클라이언트들(MAD). 음의 다리 점수 z_neg(c) = (P_neg(c) − median) / MAD. 클래스는 모두 본다 (추정 하나에 걸지 않는다).
판정 (③'): 클래스 c 가 **헤지 클래스**다 ⇔ H(c) ≥ h₀ 이고 z_neg(c) ≤ −τ (음의 다리가 뚜렷). 헤지 클래스가 하나라도 있으면 neg(c) 가 위장자 후보.
귀속: 헤지 클래스마다 양의 다리 집합 Pos(c). |Pos(c)| ≥ 2 이면 **공모 후보**(운반자), |Pos(c)| = 1 이면 **정상 큰손**(소유자). owner 조건: 클래스 8 → Pos = 운반자 넷, 클래스 3 → Pos = 소유자 한 명.
대응 (④): 공모 후보 클래스가 있으면 → 삭제 요청이 오기 전이라도 DOSE(부분 제거)로 그 클래스가 실제로 깨어나는지 확인(비선형 확인) → 깨어나면 Pos(c) 제외 재학습(R-010: ASR 0.5). 소유자 다리는 손대지 않는다.
보장 (⑤, 위협 모델 안): 백도어가 타깃 c* 로 몰리고 학습 중 전역 모델이 깨끗하면(잠복), Σ_j P_j(c*) ≈ 0 이면서 위장자의 P 는 운반자 합의 음수여야 한다 → H(c*) ≈ 1 이고 neg(c*) = 위장자. 공격자가 이것을 피하려면 운반자 합을 작게(= 백도어 약하게) 하거나 음의 다리를 여러 명에 나눠야 한다 → 후자는 Pos/Neg 가 둘 다 집합이 되는 경우로, |Neg(c)| 를 세면 된다 (sup2 궤적에서 시험).

왜 노벨티인가: ① 이 "갱신들이 서로 지운다"는 **관계** 불변량이고, 기존 여섯 논문은 전부 갱신 하나의 성질이나 유사성이다. 왜 범용인가: BadFU·FUBA 는 물론, 상쇄로 숨는 어떤 백도어도 균형식을 피할 수 없다. 좁힌 것: 서버가 라운드별 갱신을 저장하고 공개 입력을 갖는다; 백도어가 한 타깃으로 몰린다.

비용: 라운드마다 참여자 수만큼 순전파 (8 × 500 장). 모델 생성 없음. 요청 시점 검사(DOSE)는 확인용으로만.
