# 2026-10-17 코드·브랜치 정리

## 실제 이동

65개 파일을 이동했다. `reproduction/`의 구현·테스트 40개는 training, common, detection,
purification, audit, tests로 분리했다. 정화 설정은 purification/example.json, 그림 도구는 tools/figures/로 옮겼다.
FUBA에 추가했던 분석 코드 23개는 FUBA/research/로 분리했다. 원본 공격 코드의 내부 배치는 고정 해시와 함께 유지한다.
[전체 이전→이후 경로](code_layout_20261017.json).

import, 동적 모델 팩터리, 하위 실행 명령, 저장소 기준 경로, 소스 해시 경로와 현재 실행 문서를 함께 수정했다.
새 학습 기록기는 패키지 하위 폴더까지 사본으로 저장하며, 기존 평면 구조의 사본도 읽을 수 있다.
구형 실행 파일을 최상위에 다시 만드는 방식의 호환 래퍼는 두지 않았다.

## 검증 범위

- 연구 테스트 124개 통과. 새 하위 폴더 사본만으로 별도 Python 프로세스에서 어댑터가 가져와지는지 포함한다.
- FUBA 연구 테스트 105개 통과.
- 원본 해시: BadFU 223개, FUBA 145개 일치.
- 원본·업로드 증거·기존 논문 등 보호 파일 1,077개 바이트 불변 확인.
- 기존 2R BadFU 저장 모델의 dry-run 통과. 실제 pre/post 경로·기록기 사본·manifest·원본 공격 record 연결 검사다.
- 기존 시계열 결과를 현재 코드로 재계산하여 수치 일치를 검사한다. 과거 소스 해시는 비실행 보관본으로 검증한다.

이 검증은 코드 재배치의 회귀 검사다. 새 공격·탐지·정화 성능 실험을 수행하거나 기존 결과를 개선 결과로 바꾸지 않았다.
처음 실행한 검사에서는 샌드박스 임시 경로 권한 오류와 예전 소스 경로 의존성이 발견됐다.
임시 경로를 작업 폴더로 지정하고 출처 검증을 경로와 분리한 뒤 전체 검사를 통과했다.

## 브랜치와 작성자 기록

활성 브랜치는 main, detection, purification 세 개다. main에도 정리된 코드가 들어간다.
다른 다섯 원격 브랜치는 원래 끝 커밋을 가리키는 보관 태그로 전환한다.
원격의 정리 전 끝 커밋과 보관 태그는 [보관 목록](branch_archive_20261017.json)에 기록한다.

기여자 표기 수정은 AI 공동 작성자 줄과 자동 작성자 별칭에 한정한다. 사람의 작성자 정보, 날짜, 파일 tree는 유지한다.
변경된 부모를 가리키는 후속 커밋도 ID가 달라진다. 강제 갱신은 확인한 이전 원격 ID와 일치할 때만 수행한다.
이전 기록은 보관 태그와 `artifacts/layout_20261017/before-cleanup.bundle`에서 복구 가능하다.
기존 결과 속 커밋·소스 해시는 원래 실행을 가리키므로 다시 쓰지 않는다.
