첫 정리는 문서와 legacy 위주여서 Python 실행 코드가 평면 구조에 남았고, main의 초기 코드도 그대로였다.
후속 정리에서 코드까지 폴더로 이동하고 세 활성 브랜치에 반영했다. 원본 공격 파일·업로드 결과·논문 TeX는 보존한다.

기여자에 관한 이전 설명도 정정한다. REST API에는 소유자만 나왔지만 GitHub 화면에는 Claude 공동 작성자가 표시됐다.
`.mailmap`만으로 해결된 것이 아니었다. 활성 브랜치 이력의 AI 작성자 별칭과 Claude 공동 작성자 표기를 수정하고
원래 이력은 보관 태그와 로컬 bundle에 남긴다. GitHub 화면의 갱신은 별도로 확인해야 한다.
