# 연구 문서 안내

현재 읽는 순서는 다음과 같다.

1. [연구 요약](RESEARCH_SUMMARY.md): 문제, 수식, 결과, 한계, 다음 실험.
2. [출처 감사](EVIDENCE_AUDIT.md): 초기 구현·공식 코드·새 업로드를 구분한 근거.
3. [논문 정리](paper_reviews/README.md): 원문 링크와 다섯 항목별 리뷰.
4. [현재 상태](STATUS.md), [실행 안내](../RUN.md), [알고리즘 상세](paper/TENSION_CONTROL.md).
5. [원고 v7](paper/draft_v7.tex): 연구 초안이며 출판·효과 검증을 의미하지 않는다.

`EXPERIMENT_LOG.md`는 자동 생성 원시 장부다. 체크 표시의 의미와 사후 문턱 변경은 출처 감사를 함께 읽는다. `RESULTS_LOG.md`는 과거와 현재의 실행 이력을 보존한다. `paper/`의 이전 방법명·초안·계획은 발전 과정의 기록이며 최신 결론보다 우선하지 않는다.
