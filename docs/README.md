# 문서 안내

먼저 [한 장 결과표](../RESULTS.md)를 읽고, 세부 내용이 필요할 때 아래 폴더로 들어갑니다.

| 폴더 | 용도 |
| --- | --- |
| [current/](current/README.md) | 현재 문제 정의·탐지·정화 |
| [experiments/](experiments/README.md) | 완료한 관측, 실패 원인, 이전 연구 과정 |
| [operations/](operations/README.md) | 원본 재현, 궤적, 정리 이력 |
| [paper_reviews/](paper_reviews/README.md) | 선행논문과 기존 방어의 논리 |
| paper/ | 이전 논문 초안. 정리 과정에서 수정하지 않음 |
| [archive/](archive/README.md) | 과거 설계·상태 문서 |
| figures/ | 기존 실험 그래프. 수치의 해석은 RESULTS.md와 해당 실험 문서를 따름 |

`EVIDENCE_AUDIT.md`와 `RESULTS_LOG.md`는 옛 논문 초안의 경로를 위한 안내 파일입니다. 실제 문서는 분류된 폴더에 있습니다.
