# 논문 설정(K=20, 100 라운드, 참여 0.4)에 맞춘 방어 설계 제안 (2026-10-12)

근거가 된 로그: `docs/EXPERIMENT_LOG.md` (k20_paper 6 개), REPORT §13–16, `FUBA/logs/analysis/*`.
기호: θ_T 최종 모델, U_k = Σ_t U_k^t 요청자 k 의 누적 기여 (참여 0.4 → 약 40 라운드 조각), E_j = [f(X; θ−εU_j) − f(X; θ)]/ε 기능 효과, ρ 제거 비율, X_act 활성화 입력, c* 타깃, h 백도어 방향.

## 로그가 말하는 세 가지 사실
1. **전량 빼기는 붕괴한다.** θ_T − U_k 는 정확도가 50 아래로 떨어진다. ρ=0.2 에서 ASR 46–93 (ACC 68.7–97.6). 100 라운드 누적 기여는 1 차 근사의 범위를 벗어난다.
2. **ρ=0.2 면 이미 깨어난다.** 공격 신호는 작은 ρ 에서 충분히 크다. 판정은 첫 단계에서 끝낼 수 있다.
3. **K=20 이면 모집단이 15 명(정상)이다.** conformal p 의 바닥이 1/20 = 0.05 라 p 값을 주 판정으로 쓸 수 있다. 운반자 4 는 소수(20 %).

## 제안 1. 역순 단계 제거 (DOSE 의 연산자 교체) — 먼저 할 것
문제: 누적 기여 U_k 를 비율 ρ 로 빼는 것은 "모든 라운드를 ρ 만큼" 빼는 것이다. 그런데 초반 라운드의 조각은 이후 학습에 덮여서 θ_T 에 선형으로 남아 있지 않다. 그것을 빼면 모델이 깨진다.
```
R_rev(θ, k, m) = θ − Σ_{t ∈ 마지막 m 라운드, k 참여} U_k^t          (최근 조각부터 통째로)
```
- 단계 = 라운드 수 m (0.2 비율 대신). 건강 상한 c 로 m 을 고른다. 다 빼면 (m = 전체) 전량 제거가 되지만, 붕괴하는 조각은 "이미 덮인 조각" 이므로 거기서 멈추는 것이 정당하다 (그 조각은 θ_T 에 없다).
- 시험: 저장된 k20_paper 궤적에서 m = 5, 10, 20, 40 으로 chg·ACC·ASR 곡선을 그린다 (학습 없음, 순전파만). ρ 곡선(0.1~1.0)과 나란히. 붕괴 없이 ASR 이 오르면 채택.
- 위험: 공격자가 억제를 초반 라운드에 몰아 두면 최근 조각만 빼서는 안 깨어난다 → 그러면 공격도 약해진다 (초반 억제는 덮인다). 적응형 절에 적는다.

## 제안 2. 기능 공간 제거 (붕괴 없는 '요청자 효과만 지우기')
매개변수를 빼지 않고, 요청자의 **기능 효과**만 지운 모델을 짧게 맞춘다.
```
목표 로짓  z*(x) = f(x; θ_T) − ρ·E_k(x)            (E_k 는 ε=0.2 로 안전하게 측정)
θ' = argmin_θ Σ_{x∈X} KL( softmax(z*(x)) ‖ p(x; θ) ),  θ 초기값 θ_T, 50 걸음
```
- 요청자 지식이 든 교사를 쓰지 않는다 (교사가 θ_T 에서 E_k 를 뺀 것). 재주입 α 는 기능 공간에서 0 (목표 자체가 k 의 효과를 뺀 것).
- 비용: 증류 50 걸음 (KD 연산자와 같음). 깊은 망(BadFU)에서도 같은 식.
- 위험: X 밖(트리거 입력)에서의 제거는 보장 안 됨 → 그래서 X 에 지울 데이터를 넣는다 (BadFU). FUBA 는 누출이 X_p 에 있으니 됨.
- 시험: k20_paper 에서 R_rev 와 나란히 ASR/ACC/자기 데이터 acc.

## 제안 3. 판정을 p 값으로 (K=20 전용)
첫 단계(ρ=0.2 또는 m 조각)에서 통계 s ∈ {flow, 타깃 몰림, 상쇄 비율} 을 모든 j 에 대해 계산하고
```
p_k^{(s)} = (1 + #{j ≠ k : s_j ≥ s_k}) / K,   F = −2 Σ_s log p_k^{(s)} ~ χ²_{2·3},   경보 ⇔ F 의 p ≤ 0.05
```
- K=8 에서는 바닥 0.125 라 못 썼다. K=20 이면 세 통계가 모두 1 위일 때 p ≈ 0.001.
- 오탐률 문장이 생긴다 (교환 가능하면 P(오탐) ≤ 0.05). owner 소유자 오탐이 "통계 하나 1 위" 로는 안 나게 결합.
- 시험: k20_paper 6 궤적의 cancel 결과(JSON 에 pvals 있음)로 바로 계산. 코드는 `--purify_on either` + 결합 규칙 한 줄.

## 제안 4. TRACE 를 단계마다 반복해 일관된 짝만
10 라운드 스모크에서 회전 2 의 짝에 정상 5·7·9 가 섞였다. 100 라운드에서도 섞일 수 있다. 활성화가 단계마다 커지므로 정렬도 단계마다 잰다.
```
S = { j : align_j^{(s)} ≤ −a  for all s = 1..n_step }  ∩  { j : conformal p_j(align) ≤ 0.1 among others }
```
- 운반자의 정렬은 단계에 무관하게 −0.9 (K=8 확인), 정상은 흔들린다 → 교집합이 정상을 걸러 낸다.
- 비용: 단계마다 K−1 순전파 (이미 하는 것). 시험: k20_paper cancel 의 `pair_act.iters` 와 단계별 align 을 저장하도록 한 줄 추가.

## 제안 5. DEFUSE 뒤에 제거를 끝까지 (해제 → 완전 삭제)
ρ=0.2 에서 경보 → 짝 S 의 h 성분 제거 (λ 띠 안 최소) → 남은 0.8 을 제안 1 또는 2 로 계속 뺀다. 백도어가 해제됐으면 남은 제거에서 다시 깨어나지 않아야 한다 (재경보 0). 끝에 α=0, 자기 데이터 acc = 전량 제거 값.
```
θ'' = R(θ_T, k, ρ₁) − λ Σ_{j∈S} proj_h(U_j);   θ''' = R(θ'', k, 1−ρ₁)   (R 은 제안 1 또는 2)
```
- 지금 코드는 remainder 를 같은 빼기로 계속하는데, 붕괴 때문에 `partial` 로 끝날 수 있다. 연산자를 바꾸면 완전 삭제가 된다.
- 비교 기준: FUBA Table VIII 의 서버 clean 미세조정 (ASR 0.15, 라벨·학습 필요). 우리는 라벨 없이, 50 걸음 이하로 그보다 낮아야 한다.

## 제안 6. 집계 방어 궤적 위에서의 주의 (tdef)
Krum·FLAME 은 일부 갱신을 버린다. 저장 기여 U_j^t 는 **집계에 실제 반영된 것**이어야 TRACE 가 맞다 (버려진 갱신은 θ_T 에 없다). 로더가 로컬 모델 차이를 그대로 쓰면 버려진 갱신도 포함된다 → 검증기의 "집계 검사" 로 반영 여부를 확인하고, 필요하면 방어가 선택한 클라이언트만 U 에 넣는다 (main.py 의 선택 로그를 저장).

2. 제안 5 (해제 → 완전 삭제) — 1 이 되면 자동으로 됨.
3. 제안 4 (단계 일관성) — 100 라운드 결과에서 정상이 섞이면.
