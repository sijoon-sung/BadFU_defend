# 논문 초안 기획 (갱신 2026-10-12)

전에 세운 기획(EXPERIMENT_DESIGN.md 5 절의 RQ 표, POSITIONING.md 의 자리매김, THREAT_MODEL.md 의 공격 틀)을 한 장으로 합친다. 중심은 **두 공격의 공통 부분**이고, 방어는 그 공통 부분에서 나온다.

## 0. 두 공격의 공통 부분 (여기서 전부 나온다)
두 공격 다 사람이 둘이다. **심는 사람**과 **억누르는 사람**. 억누르는 사람의 몫은 트리거 입력에서 심는 사람의 몫을 정확히 거꾸로 민다. 그래서 학습이 끝난 모델은 깨끗하고, 억누르는 사람이 "나 빼 줘" 하면 거꾸로 밀던 힘이 사라져 백도어가 깨어난다.
- FUBA: 억누르는 힘이 커서 공개 사진에서도 샌다.
- BadFU: 억누르는 힘이 트리거 사진에만 있다. 그 사진이 곧 지워 달라는 사진이다.
공통 부분 = "**억누르는 사람의 몫은, 어떤 입력에서, 어떤 클래스로 가는 힘을, 매 라운드 일관되게, 다른 누군가와 반대로 민다.**"

## 1. 제목·한 문단
제목 후보: "Trial Removal: Accepting Unlearning Requests under Dormant Backdoors in Federated Learning"
첫 문단: 잠복 백도어는 두 몫의 상쇄로 숨는다. 상쇄는 몫 하나로는 안 보이고, 한쪽을 빼야 보인다. 우리는 삭제 요청을 그 자리에서 빼 보는 시험으로 바꾼다. 시험을 피하려면 공격은 깨어나기를 포기해야 한다. 시험이 보는 입력이 공개 입력뿐이면 억제가 새는 공격까지, 지울 입력까지 보면 자기 데이터에만 숨는 공격까지 잡힌다. 걸린 요청에서는 억누르는 사람의 몫을 지도로 삼아 심은 사람을 찾고 백도어를 지운다.

## 2. 절 구성
1. 서론 — 위 한 문단 + 기여 4 개 (문제 정의, 상쇄 구조와 경계, 역할 지도·진짜 제거, 적응형 방법론)
2. 배경과 위협 모델 — THREAT_MODEL.md 1–3 절. 수동형 FU, 저장된 몫, 공격 가족, "해로운 요청" 정의
3. 왜 기존 방어가 못 보나 — THREAT_MODEL.md 4 절. 몫 하나만 보는 통계는 상쇄를 못 본다 (MASA·SubID 표로 증거)
4. 방법 — 하나의 절차, 두 겹
   - 4.1 거름망 (궤적 지표): 라운드별 몫이 입력 X 위에서 클래스별 손실을 미는 방향 v_k^t. 크기·일관성(FUBA 가 보임), 동일 부호·반대 짝(BadFU 가 보임). 서로 보완. 비용: 역전파 열 번.
   - 4.2 확정 (빼 보기): 걸린 요청만 실제로 빼서 "다른 사람을 같은 양만큼 뺀 것"과 비교. 입력 X = 공개 + 지울 입력. 큰 모델은 단계로 빼고 무너지면 멈춤(보호 장치, 부록).
   - 4.3 정화 — 공통 부분에서 바로: 억누르는 사람의 몫 U_k 가 "무엇을 거꾸로 밀었는지"의 증거다. (i) 반대 짝으로 심은 사람 집합 A 를 찾고, (ii) A 의 몫 중 U_k 와 반대로 정렬된 성분만 뺀다. U_k 는 되살리지 않는다(α=0). 이것이 "재우기"가 아니라 "지우기".
   - 4.4 보장: 정상 요청은 기본 FU 와 동일(P1), 오탐률은 모집단 보정으로, 피할 수 없음은 공격 정의에서.
5. 실험 — EXPERIMENT_DESIGN.md 5 절의 RQ1–RQ6. 두 메커니즘 비교(경계), 비교군(exp/baselines 브랜치), 적응형 5 종, 비용, 소거
6. 한계 — 지울 입력을 봐야 BadFU 류까지; 깊은 망의 빼기 연산자; K=8/공격자 50 % 설정(주 설정을 K=20 으로); 1 차 근사의 한계
7. 관련 연구 — Qian/Liu(중앙 샘플 심사), SubID·FedMUA 방어(언러닝 라운드 갱신), MASA(학습 중), 검증(VeriFi), 집계 방어. 도구가 표준임을 먼저 인정
