# 방법 v3: 상쇄 귀속 — "어디서·누가" 하나의 문제 (2026-10-12)

한 줄: 언러닝 요청 하나를 받으면 서버는 **"이 요청자의 기여는 어디서(어느 입력에서), 누구의 기여와 서로 지우고 있었나"** 를 푼다. 그 해(입력·짝·방향)가 곧 탐지 결과이고, 정화는 그 해를 짝의 기여에서 빼는 것이다. 요청자의 데이터는 지워진 채로 남는다.

코드: `FUBA/cancel_fu.py` (한 파일), 집계 `aggregate_cancel.py`, run_all 단계 `cancel`. 이전 판(궤적 거름망 → 빼 보기 → 해독제)은 `docs/archive/design/METHOD_v2_2026-10-12.md`, 코드 `unified_fu.py`.

## 0. 기호
- 클라이언트 j = 1..K, 저장된 기여 U_j (누적) 와 U_j^t (라운드별). 최종 모델 θ_T.
- 요청 (k, X_f): k 가 자기 데이터 X_f 를 지워 달라고 한다. 서버의 공개 입력 X_p.
- f(x; θ) ∈ R^C 로그확률. 기능 효과 E_j = [f(X; θ − εU_j) − f(X; θ)]/ε (입력 × 클래스; "j 를 빼면 각 입력의 각 클래스가 얼마나 바뀌나"). 공통 성분을 지운 것이 Ẽ_j. 라벨·트리거·역할 정보 없음.

## 1. 공격의 정의 = 상쇄
운반자 A 가 백도어를 심고 요청자 k 가 같은 입력에서 거꾸로 민다. 어떤 입력 집합 X* 위에서
```
J_{X*}( U_k + Σ_{j∈A} w_j U_j ) ≈ 0,   J_{X*} U_k ≠ 0.
```
k 가 빠지면 X* 에서 백도어가 깨어난다. FUBA 와 BadFU 는 X* 가 어디 있느냐만 다르다 (BadFU: 트리거 그림 = 요청자가 넘긴 X_f 자체. FUBA: 트리거 입력, 서버는 못 봄; 억제가 깨끗한 입력으로 새어 나옴).

## 2. 서버가 푸는 문제 (목적식 하나)
미지수는 둘이다. **어디서** = 입력 가중치 ω(x) ≥ 0, **누가** = 짝 집합 S 와 가중치 w.
```
max_{ω, S, w}   Σ_x ω(x) · [ ‖Ẽ_k[x]‖² − ‖Ẽ_k[x] + Σ_{j∈S} w_j Ẽ_j[x]‖² ]        s.t. 0 ≤ w ≤ w_max, |S| ≤ r
```
괄호 안은 입력 x 에서의 **상쇄 에너지**: k 의 효과가 크면서 몇 명을 더하면 사라지는 정도. 정상 요청은 이 값이 어디서도 크지 않다. 공격이면 X* 근처에서 크고, 그 S 가 운반자다.

풀이는 교대 반복이다 (좌표 상승).
- ω 고정 → (S, w): 그램 행렬 G_ij = Σ_x ω(x)⟨Ẽ_i[x], Ẽ_j[x]⟩ 위에서 전진 선택 + 상자 제약 최소제곱.
- (S, w) 고정 → ω: 상쇄 에너지가 양수인 입력.
이 반복의 시작값과 둘째 회전의 ω 갱신 방법이 아래 절차다.

## 3. 절차 (요청 하나)

### 회전 1 — 저장된 기여 위, θ_T, ω⁰ = 공개 입력 ∪ 요청자가 낸 데이터        (모델 생성 0, 순전파 K)
```
Ẽ_j ← 중심화[ E_j ]  on X = X_p ∪ X_f            (공개 부분은 모델 버전당 1 회 공유)
(S¹, w¹) ← argmin_{S,w} ‖Ẽ_k + Σ_{j∈S} w_j Ẽ_j‖²      (그램 행렬 위)
어디서: e(x) = ‖Ẽ_k[x]‖² − ‖Ẽ_k[x] + Σ w_j Ẽ_j[x]‖²  → 에너지가 공개 입력에 사는지, 지울 데이터에 사는지의 비율
타깃 c¹ = argmax_c mean_x Ẽ_k[x,c]
통계 (모든 j 에 같이): 상쇄 비율 c_j, 타깃 몰림 g_j, 크기 m_j, 라운드 반대 정렬 a_j (궤적, 선택)
요청자 k 의 각 통계를 나머지에 비추어 conformal p, z. Fisher 결합. 경보₁ ← p ≤ α_p 또는 z > τ_a
```
- BadFU: 에너지가 지울 데이터에 산다. 짝 [0], 타깃 0, 상쇄 0.38 (지울 데이터만) — **여기서 수렴**.
- FUBA: 깨끗한 입력에는 상쇄가 안 산다 (백도어가 잠들어 있어 운반자 효과가 작고, 정상도 운반자와 "상쇄"됨). 크기·몰림 z 만 튄다 (억제의 누출). 회전 2 로.

### 빼 보기 — 비선형 확인, ω 갱신의 재료                                       (모델 버전당 K 개 공유)
```
θ' ← θ_T − ρU_k   (ρ: 모두가 견디는 양; 깊은 망은 단계 + --op kd)
P ← { θ_T − ρU_j : j≠k, 건강 },  ref ← 저장 확률의 중앙값(LOO),  z ← flow 통계의 모집단 z
X_act ← { x : θ'(x) = c* ≠ ref(x) },  c* ← 답이 가장 몰린 클래스
경보₂ ← z > τ
```
같은 목적식을 선형화 없이 진짜 모델로 잰 것이다. 경보₂ 가 없으면 **수락** (θ' 그대로, 기본 FU 와 동일). 경보₁ 만 있으면 수락하되 기록.

### 회전 2 — 활성화 입력 위, θ', ω¹ = 1[x ∈ X_act], 타깃 열                      (순전파 K−1)
```
활성화 A ← f(X_act; θ')[·,c*] − log ref(X_act)[·,c*]
효과   E'_j ← (f(X_act; θ' − ε₂U_j) − f(X_act; θ'))[·,c*] / ε₂    (ε₂ = 0.5ρ; 비활성 입력을 cap 이상 바꾸는 후보 제외)
정렬   align_j ← ⟨A, E'_j⟩ / (‖A‖‖E'_j‖)
(S², w²) ← 정렬 오름차순에서 가장 큰 간격 아래쪽 전부 (정렬 ≤ −0.3), 가중치는 상자 최소제곱
```
- FUBA: 운반자 넷 −0.87~−0.90, 정상 셋 +0.67~+0.84 → 짝 = 운반자 넷 전부 — **여기서 수렴**. 중심화는 하지 않는다 (남들 중 운반자가 다수면 중앙값이 운반자).
- BadFU: 0 이 −0.90, 정상 −0.25~−0.61 (깊은 망은 누굴 빼도 조금 음수) → 간격에서 잘려 짝 = [0]. 회전 1 과 일치.

### 회전 3+ (선택, `--iters`) — ω 정련
(S², w²) 고정 → X_act 안에서 상쇄 에너지 A[x]² − (A[x] + Σ w_j E'_j[x])² 가 양수인 입력만 남김 → (S, w) 다시. 바뀌지 않으면 멈춤. 로컬에서는 회전 2 에서 이미 고정이다 (아래 7 절).

### 정화 — 해에서 바로
```
h ← ∇_θ mean_{x∈X_act} log p(c* | x; θ')            (백도어가 미는 방향; 역전파 1 회)
θ'' ← θ' − λ Σ_{j∈S} proj_h(U_j),   λ 작은 값부터, z ≤ z_target 이 되는 첫 값
건강: 비활성 입력 X ∖ X_act 에서 θ' 대비 바뀐 비율 ≤ cap
(선택) 직교 증류: ref 쪽으로 짧게 증류하되 기울기에서 U_k 성분을 매 걸음 제거 → 정확도 회복, α 그대로
실패 → 재억제(KD, α>0) 로 대체 → 그래도 실패면 거부. 남은 양(1−ρ)은 같은 규칙으로 계속
```
U_k 는 되살리지 않는다: α = ⟨θ'' − θ', U_k⟩/‖U_k‖² ≈ 0. 빼는 것은 짝의 몫 중 h 성분(로컬 4–5 %).

## 4. 왜 하나인가
- 두 공격은 **같은 반복의 수렴 회전이 다를 뿐**이다. 상쇄가 요청자가 넘긴 데이터에 살면 회전 1 에서, 깨어나야 보이면 회전 2 에서 끝난다. 절차는 공격을 구분하지 않는다. 출력의 "어디서" 비율이 그 차이를 사후에 말해 준다.
- 빼 보기는 별도의 탐지기가 아니라 같은 목적식의 비선형 확인이자 ω 갱신의 재료다.
- 정화는 찾은 해(ω, S, w, h)를 그대로 쓴다. 탐지·귀속·정화가 하나의 해에서 나온다.
- 적응형 공격도 같은 표 안에 들어간다: 위장자 분산 = k 의 효과가 작아짐(크기 z 하락), 운반자 분산 = S 가 커짐, 미끼 = 라운드 반대 정렬 a_j 가 낮음. 모두 해의 모양으로 읽힌다.

## 5. 성질
- P1 정상 요청 = 기본 FU. 경보₂ 가 없으면 손대지 않는다. 비용은 순전파뿐.
- P2 무너진 모델 불출. P3 내보낸 모델은 X 위에서 모집단 띠 안.
- P4 요청자 몫을 되살리지 않는다 (α≈0). 오탐이어도 요청자 데이터는 지워진 채다.
- P5 출력에 **귀속**이 있다: 짝 S, 타깃 c*, 입력 X_act, 방향 h. 수락/거부만 내는 방법과 다른 점.

## 8. 정할 것 (실험 전)
1. 정화 조건: 경보₂ 만(기본 `--purify_on sim`) / 경보₁ 도(`either`). K=20 에서 conformal p 가 의미를 가지면 `either`.
2. z_target: 경보 문턱 τ(3) 인지 정상 띠 1 인지. ACC 와 맞바꿈.
3. 직교 증류 기본화 (`--polish kd_orth`): owner 에서 ACC 회복이 확인되면.
4. 회전 3+ 를 본문에 둘지 부록에 둘지: 로컬에서는 바뀌는 게 없다. K=20·적응형(운반자 분산)에서 바뀌면 본문.
