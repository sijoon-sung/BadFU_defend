# 알고리즘 v2: 상쇄 구조에서 나온 수락·정화 절차 (2026-10-12)

지금까지의 이야기를 하나로 다시 짠 것. 중심은 두 공격의 **공통 부분**이고, 궤적 지표와 빼 보기는 서로 보완한다.

## 0. 공통 부분 (THREAT_MODEL.md 2 절)
심는 사람 A 와 억누르는 사람 S. 트리거 입력 X* 에서 S 의 몫이 A 의 몫을 거꾸로 민다 (J_X*(U_A + U_S) ≈ 0, J_X* U_S ≠ 0). S 가 빠지면 깨어난다.
방어가 쓰는 세 가지 사실:
1. 상쇄는 몫 하나로는 안 보이고, S 의 몫을 **빼야** 보인다 → 요청 시점에 본다.
2. 깨어나는 자리는 X* 이고, X* 는 공개 입력에 새거나(FUBA) 지울 입력 안에 있다(BadFU) → 보는 입력 = 공개 ∪ 지울 입력.
3. S 의 몫은 "무엇을 거꾸로 밀었는지"의 증거다 → A 를 찾고, A 의 몫 중 그 부분만 뺀다.

## 1. 입력·출력
입력: {U_j^t} (저장 몫), θ_T, 요청 (k, X_f), 공개 입력 X_p. 라벨·트리거·역할 정보 없음.
출력: 수락(θ' = R(θ_T,k) 그대로) / 정화 후 수락(θ'') / 거부(판단 불가·정화 실패). 그리고 기록(z, A, α, 단계).

## 2. 절차 (3 단계)

### A. 거름망 — 궤적 지표 (역전파 10 회, 모델 생성 없음)
```
X ← X_p ∪ X_f ; ŷ(x) ← argmax θ_T(x)                       # 가짜 라벨
g_c ← ∇_θ mean CE(θ_T; {x : ŷ(x)=c})  (c = 1..C)
v_j^t ← (⟨U_j^t, g_c⟩)_c   for all j, t ;  v_j ← Σ_t v_j^t
지표(k):  mag = ‖v_k‖,  consist = mean_t cos(v_k^t, v_k),  spread = |mean_c sign v_k[c]|,  partner = min_j cos(v_k, v_j)
각 지표를 모집단 {v_j} 에서 z 로. 문턱은 LOO 보정(멤버 각자의 z 최댓값 + 1).
suspect ← (mag 또는 consist 가 문턱 초과)  OR  (X_f 위에서 spread 또는 partner 가 문턱 초과)
```
- FUBA 류는 mag·consist 에서, BadFU 류는 X_f 위의 spread·partner 에서 걸린다 (로컬 1 시드 확인; BadFU 는 방향만 맞고 K=6 에서 문턱 미달 → 거름망은 보수적으로, 놓치면 B 가 잡는다).
- suspect 가 아니면 **수락**: θ' = R(θ_T, k). 기본 FU 와 동일 (P1). 비용 끝.

### B. 확정 — 빼 보기 (걸린 요청만)
```
X_eval ← X_p ∪ X_f
θ' ← R(θ_T, k, δ)  (δ: 모두가 견디는 양; 멀쩡하면 1)
P ← { R(θ_T, j, δ) : j ≠ k, 건강 }, ref ← median-ensemble(P), s_j ← a(P_j ; ref_{-j})
   a = flow 통계: 클래스 흐름 행렬 F[i→j] 에서 가장 많이 받은 열의 양 × 출발 클래스 다양성 (2.5 절, BaFFLe 에서 빌림)
       백도어 활성화(여러 출발 → 한 타깃)는 크고, 소유자 망각(한 출발 → 여러 곳)은 작다 → '남들 입력' 을 따로 고를 필요가 없다
   (보조) flip_conf: 바뀐 입력의 새 답 확신 (STRIP 에서 빌림). 미끼·망각은 낮고 활성화는 높다
z ← (a(θ';ref) − median s_j) / std s_j
z ≤ τ → 수락(θ').   z > τ → C 로.   무너짐(모두 비건강) → 거부.
```
- flow 통계는 non-IID 소유자 오탐(3 시드 중 2)을 겨냥한 **가설**이다. 로컬 FUBA 1 시드: 위장자 z 12.5, 정상 0.45 / 0.48 (mass 와 같음). owner 궤적(DISLAB)에서 `DOSE_EXTRA="--stat flow"` 로 확인해야 한다. (대안: 요청자 소유 클래스 제외 규칙 Own(k) — 기여 비율로 추정. flow 가 안 되면 이것.)

### C. 정화 — 해독제 방향 (공통 부분 3 에서)
```
c* ← θ' 에서 답이 몰린 클래스 ;  X_act ← { x ∈ X_eval : θ'(x) = c* ≠ ref(x) }
A ← 지도 순위 선택: Δ_j = a(θ') − a(θ' − U_j) 양수 순으로 z ≤ τ 까지 (pair_roles ranked)
h ← ∇_θ mean_{x∈X_act} log p(c* | x ; θ')                    # 백도어가 미는 방향
U_j^∥ ← (⟨U_j, h⟩/‖h‖²) h   (j ∈ A)
θ'' ← θ' − λ Σ_{j∈A} U_j^∥ ,  λ 를 작은 값부터 올려 z ≤ τ 가 되는 첫 값 (θ' 대비 변화 ≤ c 이면)
실패(λ 상한까지 z > τ 또는 무너짐) → 운반자 통째 제거 θ' − Σ_A U_j 로 대체, 그래도 실패 → 거부
```
- U_k 를 되살리지 않는다. 빼는 것은 **운반자 몫의 h 성분**뿐. α = ⟨θ''−θ', U_k⟩/‖U_k‖² 를 함께 보고한다 (h 가 U_k 와 반대로 정렬돼 있으면 α > 0 일 수 있다. 그래도 빠지는 것은 운반자의 몫이지 요청자 몫의 복원이 아니다 — 이 구분을 표로 보인다: '운반자 몫 중 뺀 비율' 열).
- 비교 팔: 요청만 / 운반자 통째 제거 / 재억제 수정(KD) / 해독제(λ). 코드: `FUBA/antidote.py`.

### D. 순차 요청
한 클라의 조각 요청은 누적 장부, 여러 클라의 순차 요청은 "정상 n 명 제거" 띠(schedule_fu). 변경 없음.

## 2.5 둘을 하나로 묶는 원리 — 다른 논문에서 빌린 것
FUBA 와 BadFU 를 따로 푸는 방법은 각각 있다(FUBA: 공개 입력 빼 보기, BadFU: 지울 입력 탐침 + 단계 + 증류 연산자). 하나로 묶으려면 "두 공격이 **반드시** 같이 건드리는 양"을 통계로 삼고, 그 양의 정상 분포를 서버가 만들 수 있어야 한다. 공격 종류를 가리지 않는 방어 논문들이 한 방식이 그것이다.

| 논문 | 공격을 가리지 않게 만든 불변량 | 우리가 빌린 것 |
|---|---|---|
| BaFFLe (FL 백도어 피드백 검증) | 연속 전역 모델 사이의 **클래스별 오류 변화** 패턴이 정상 때와 다르다 | 통계를 스칼라가 아니라 **클래스 흐름 행렬** F[i→j] 로. 백도어 활성화 = 여러 출발 클래스 → 한 타깃(열 집중 + 출발 다양성). 소유자 망각 = 한 출발 클래스 → 여러 곳(행 집중). 이 둘을 가르는 통계 `flow` = 타깃 열의 양 × 출발 다양성 |
| STRIP | 트리거 입력의 답은 섞어도 안 흔들리고 **확신이 높다** (지름길) | 바뀐 입력의 새 답 확신 `flip_conf`. 백도어 활성화는 높고 망각은 낮다. 둘째 불변량으로 미끼·소유자 구분에 보조 |
| MASA | 각 모델을 **모집단 중앙값 대비 편차**로 본다 | 같은 양 제거 모집단의 z (이미 사용) |
| Backdoor Vectors / 작업 산술 | 백도어 = 벡터, **빼면 사라진다**, 세기 λ | 해독제 정화: 활성화가 드러낸 방향으로 운반자 몫을 투영해 λ 만큼 뺀다. 깨끗한 미세조정이 필요 없음 |
| Zhang 2023 / Qian / Liu | 요청을 **실행 전에 심사** | A 거름망 → B 확정의 2 단계 |
| CrowdGuard | 라벨 대신 **표현 변화** 로 본다 | (선택) 작은 단계에서 argmax 가 안 바뀔 때 표현 공간 거리로 대체 |

묶는 원리 한 줄: **두 공격 모두 "억누르는 사람을 빼면, 어떤 입력들이 한 클래스로 확신 있게 몰린다"를 피할 수 없다.** 입력이 어디 있는지(공개 / 지울 입력)만 다르므로 탐침을 합집합으로 두고, 통계는 "몰림의 양 × 출발 다양성 × 확신"으로 둔다. 정상 삭제(망각)는 몰림이 아니라 흩어짐이라 이 통계에 안 걸린다.

로컬 확인 (FUBA loc_fuba, 1 시드, `--stat flow`): 아래 코드 상태 표 참조.

## 3. 성질
- P1 정상 요청 = 기본 FU (A 에서 통과하거나 B 에서 z ≤ τ 면 손대지 않음).
- P2 무너진 모델 불출.
- P3 내보낸 모델은 X_eval 에서 모집단 띠 안.
- P4 정화는 요청자 몫을 되살리는 대신 운반자 몫의 백도어 성분을 뺀다 (재우기 → 지우기).
- 비용 (2026-10-12 구현 후):
  - 가상 제거 모델 θ_T − U_j 는 **요청자와 무관**하므로 모델 버전마다 한 번만 만들고 모든 요청이 공유한다. 요청 한 건의 새 모델 수 = 0 (로컬 확인: 첫 요청 8, 이후 0).
  - LOO 기준은 저장된 확률의 중앙값으로 계산한다 (앙상블 재추론 없음). 모집단 비용 = K 순전파 (전에는 K²).
  - 요청 한 건의 추가 비용: 요청자 모델 순전파 1 회 + (지울 입력이 있으면) 그 위의 K 순전파. 학습 없음. 이것이 '그냥 빼기' 대비 추가분 전부다.
  - 안전한 대안(FedEraser 보정, 재학습)은 클라이언트 재참여와 학습이 든다. 우리는 가장 싼 연산자(빼기)를 안전하게 만든다.
  - A 거름망: 역전파 C 회(모델 버전당 1 회) + K·T 내적. C 정화: 기울기 1 회 + |A| 투영.
