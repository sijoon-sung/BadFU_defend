# 방법 v3: 상쇄 짝 찾기 (2026-10-12)

한 줄: 서버가 묻는 것은 "지우면 모델이 나빠지나"가 아니라 **"이 요청자는 누구의 기여를 지우고 있었나"** 다. 짝을 찾으면 정화는 짝의 기여에서 그 부분만 빼는 것이고, 요청자의 데이터는 지워진 채로 남는다.

코드: `FUBA/cancel_fu.py` (한 파일), 집계 `aggregate_cancel.py`, run_all 단계 `cancel`. 이전 판(궤적 거름망 → 빼 보기 → 해독제)은 `docs/archive/design/METHOD_v2_2026-10-12.md`, 코드 `unified_fu.py`.

## 0. 기호
- 클라이언트 j = 1..K, 저장된 기여 U_j (누적) 와 U_j^t (라운드별). 최종 모델 θ_T.
- 요청 (k, X_f): k 가 자기 데이터 X_f 를 지워 달라고 한다. 서버의 공개 입력 X_p. 탐침 X = X_p ∪ X_f.
- f(x; θ) ∈ R^C 로그확률. 자코비안 J_X. 라벨·트리거·역할 정보 없음. 가짜 라벨 ŷ(x) = argmax f(x; θ_T).

## 1. 공격의 정의 = 상쇄
운반자 A 가 백도어를 심고 억제자(요청자) k 가 같은 입력에서 거꾸로 민다. 입력 집합 X* 위에서
```
J_{X*}( U_k + Σ_{j∈A} w_j U_j ) ≈ 0,   J_{X*} U_k ≠ 0.
```
k 가 빠지면 X* 에서 백도어가 깨어난다. FUBA 와 BadFU 는 이 식의 두 경우다.
- **BadFU**: X* = 트리거 그림 = 요청자가 "지워 달라"고 넘긴 X_f 그 자체.
- **FUBA**: X* = 트리거 입력. 서버는 못 본다. 대신 억제가 깨끗한 입력으로 새어 나온다 (k 를 빼면 공개 입력의 답이 타깃 클래스로 몰린다).

## 2. 짝은 어디서 보이는가 (로컬 확인, REPORT 14 절)
기능 효과 E_j = J_X U_j (입력 × 클래스, 유한차분 ε 로 계산) 를 공통 성분을 지우고 보면:
- **BadFU, X_f 위**: 요청자 5 의 짝 = 운반자 0 (상쇄 비율 0.38), 0 의 짝 = 5 (서로가 서로의 짝), 타깃 클래스 0, 정상 ≤ 0.11. 깨끗한 입력 위에서는 0 과 5 가 **같은 방향**(코사인 +0.9) — 둘 다 트리거를 보고 학습했기 때문. 즉 짝은 **지울 데이터 위에서만** 보인다.
- **FUBA, 깨끗한 입력 위**: 운반자 넷이 한 무리, 나머지 넷이 한 무리. 누구든 운반자와 "상쇄"되어 나온다 (정상 7 의 상쇄 0.40, 위장자 4 는 0.37). 백도어가 잠들어 있어 운반자의 효과가 작고, 보이는 것은 무리 구조뿐이다. 위장자를 가르는 것은 **크기**(9.6 vs 2.5–3.0)와 **타깃 몰림**(3.5 vs 1.6) — 억제의 누출이다.
- **FUBA, 활성화 입력 위** (k 를 뺀 θ' 에서, 답이 타깃으로 바뀐 입력 X_act): 운반자 넷의 효과는 활성화와 정렬 −0.87~−0.90, 정상 셋은 +0.67~+0.84. 여기서는 짝이 완전히 갈린다.

그래서 짝을 **두 번** 찾는다. 저장된 기여만으로 한 번(BadFU 는 여기서 끝), 요청자를 빼서 활성화된 입력 위에서 한 번(FUBA 는 여기서 끝). 빼 보기는 두 번째 짝 찾기를 위한 수단이지 판정의 전부가 아니다.

## 3. 절차 (요청 하나)

### 1 단계. 저장된 기여 위 짝 찾기 — θ_T, X = X_p ∪ X_f, 모델 생성 0
```
Ẽ_j ← 중심화[ (f(X; θ_T − εU_j) − f(X; θ_T)) / ε ]        j = 1..K        (순전파 K; 공개 부분은 모델 버전당 1 회 공유)
G ← [⟨Ẽ_i, Ẽ_j⟩]  (K×K 그램 행렬; 이후 모든 계산은 이 위에서)
짝(k): S_k, w_k ← argmin_{0≤w≤w_max, |S|≤r} ‖Ẽ_k + Σ_{j∈S} w_j Ẽ_j‖²     (전진 선택 + 상자 제약 최소제곱)
통계(j, 모든 j): 상쇄 c_j = 1 − 잔차/‖Ẽ_j‖²,  타깃 몰림 g_j = max_c mean_x Ẽ_j[x,c] × 출발 다양성,
                 크기 m_j = ‖Ẽ_j‖/√N,  반대 정렬 a_j = mean_t −cos(Ẽ_j^t, Σ_{i∈S_j} w_i Ẽ_i^t)  (궤적, 선택)
요청자 k 의 각 통계를 나머지 {j≠k} 에 비추어 conformal p 와 z.  Fisher 결합.
경보_1 ← Fisher p ≤ α_p  또는  어느 z > τ_a
출력: S_k, w_k, 타깃 c_k = argmax_c mean_x Ẽ_k[x,c]
```
- BadFU 는 c_k(상쇄)·g_k 에서, FUBA 는 m_k·g_k 에서 걸린다. K 가 작으면(6, 8) conformal p 의 바닥이 1/K 라 z 를 병기한다.
- 비용: 요청당 순전파 K (지울 데이터 부분) + 행렬 연산. 라운드 반대 정렬을 켜면 K·T 순전파.

### 2 단계. 빼 보기 — 가상 제거, 모델 버전당 K 개 공유
```
θ' ← θ_T − ρU_k   (ρ: 모두가 견디는 양; 멀쩡하면 1, 깊은 망은 단계 + --op kd)
P ← { θ_T − ρU_j : j≠k, 건강 },  ref ← 저장 확률의 중앙값(LOO),  z ← flow 통계의 모집단 z
X_act ← { x ∈ X : θ'(x) = c* ≠ ref(x) },  c* ← 답이 가장 몰린 클래스
경보_2 ← z > τ
```
경보_2 가 없으면 **수락** (θ' 그대로, 기본 FU 와 동일). 경보_1 만 있으면 수락하되 기록(accept(attr_suspect)).

### 2' 단계. 활성화 입력 위 짝 찾기 — θ', X_act, 순전파 K−1
```
활성화  A ← f(X_act; θ')[·, c*] − log ref(X_act)[·, c*]                      (타깃 열만)
효과    E'_j ← (f(X_act; θ' − ε₂U_j) − f(X_act; θ'))[·, c*] / ε₂       (ε₂ = 0.5ρ; 비활성 입력을 cap 이상 바꾸는 후보는 제외)
정렬    align_j ← ⟨A, E'_j⟩ / (‖A‖‖E'_j‖)
짝      S' ← 정렬을 오름차순으로 늘어놓고 가장 큰 간격에서 잘라 아래쪽 전부 (단 정렬 ≤ −0.3)   (운반자는 각자 백도어 몫을 가지므로 희소 선택이 아니라 전부),  없으면 전진 선택
        로컬: FUBA −0.88 | +0.67 에서 잘림 → 운반자 넷. BadFU −0.90 | −0.60 → 운반자 0 (깊은 망은 누굴 빼도 조금 음수라 고정 문턱은 정상을 끌어들인다)
        w' ← 상자 최소제곱 (보고용; 정화 가중치는 기본 균등)
일치    S' vs S_k (자카드), c* vs c_k
```
- 중심화를 하지 않는다: 남들 중 운반자가 다수(IID K=8)면 중앙값이 운반자를 지운다. 타깃 열만 보면 일반 열화는 정렬에 거의 안 들어온다.

### 3 단계. 정화 — 짝의 상쇄 성분만, 학습 없음
```
h ← ∇_θ mean_{x∈X_act} log p(c* | x; θ')                       (백도어가 미는 방향; 역전파 1 회)
U_j^∥ ← (⟨U_j, h⟩/‖h‖²) h   (j ∈ S')
θ'' ← θ' − λ Σ_{j∈S'} U_j^∥ ,   λ ∈ {0.25, 0.5, …, 8} 작은 값부터, z ≤ z_target 이 되는 첫 값
건강: 비활성 입력(X ∖ X_act)에서 θ' 대비 바뀐 비율 ≤ cap   (정화가 엉뚱한 곳을 건드리지 않는가)
(선택) 직교 증류: θ'' 를 ref 쪽으로 짧게 증류하되 기울기에서 U_k 성분을 매 걸음 제거 → 정확도 회복, α 그대로
실패 → 재억제 수정(KD, α>0) 로 대체 → 그래도 실패면 거부
```
- U_k 는 되살리지 않는다: α = ⟨θ'' − (θ_T − ρU_k), U_k⟩/‖U_k‖² ≈ 0 을 보고한다. 빼는 것은 짝의 몫 중 h 성분(로컬: 운반자 몫의 4–5 %).
- 남은 양(1−ρ)은 같은 규칙으로 계속 뺀다.

## 4. 성질
- P1 정상 요청 = 기본 FU. 2 단계 경보가 없으면 손대지 않는다. 비용은 순전파뿐.
- P2 무너진 모델 불출 (건강 상한, 단계 제거).
- P3 내보낸 모델은 X 위에서 모집단 띠 안.
- P4 정화는 요청자 몫을 되살리지 않고 짝의 상쇄 성분을 뺀다 (α≈0). 오탐이어도 요청자 데이터는 지워진 채다.
- P5 출력에 **귀속**이 있다: 짝 S', 타깃 c*, 활성화 입력 X_act. 수락/거부만 내는 방법과 다른 점.

## 5. 비용 (요청 한 건, 학습 없음)
| 단계 | 모델 생성 | 순전파 (탐침 크기 배치) | 역전파 |
|---|---|---|---|
| 1 짝 찾기 | 0 | K (지울 데이터 위) [+ K·T 궤적] | 0 |
| 2 빼 보기 | 0 (모델 버전당 K, 공유) | K (지울 데이터 위) + 1 | 0 |

| 3 정화 | λ 후보 수 | λ 후보 수 | 1 (+ 직교 증류 50 걸음, 선택) |

## 6. 다른 방법과의 차이 (POSITIONING.md 와 같이)
- 요청 심사 방법들(Zhang 2023, Qian, Liu)은 **수락/거부**를 낸다. 우리는 **짝·타깃·입력**을 내고 그것으로 고친다.
- 재억제(KD)·재학습은 요청자 몫을 다시 넣는다(α 0.16). 우리는 넣지 않는다(α 0).
- 학습 중 집계 방어(Krum, FLAME, FLDetector)는 억제자가 있는 동안 백도어가 안 보여 못 잡는다 (BASELINES.md).
- SVD 정화 류는 모델 전체에서 저차원 성분을 깎는다. 우리는 짝의 기여에서, 활성화가 가리킨 방향만 깎는다.

## 8. 정할 것 (실험 전)
1. 2 단계 경보만으로 정화할지(기본 `--purify_on sim`), 1 단계 경보도 넣을지(`either`). K=20 에서 conformal p 가 의미를 가지면 `either` 로.
2. 정화 목표 z_target: 경보 문턱 τ(3) 인지 정상 띠 1 인지. ACC 와 맞바꿈.
3. 직교 증류를 기본으로 켤지 (`--polish kd_orth`). 로컬 FUBA: ASR 10 → 10, z 2.2 → 0.2, ACC 같음. owner 에서 ACC 회복이 확인되면 기본.
