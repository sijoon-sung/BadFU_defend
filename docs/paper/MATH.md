# 수식으로 본 절차 (2026-10-12)

"거름망"이라는 말을 버리고, 서버가 재는 양을 정의하고, 거기에 쓸 수 있는 기법들을 나열한다. 모두 학습 없음·라벨 없음. 실험 전에 글로 정하는 단계.

## 0. 기호
- 클라이언트 j = 1..K, 라운드 t = 1..T. 저장된 라운드별 기여 U_j^t ∈ R^d, 누적 U_j = Σ_t U_j^t. 최종 모델 θ_T.
- 입력 집합 X = X_p ∪ X_f (공개 입력 ∪ 요청이 지우려는 입력), |X| = N. 가짜 라벨 ŷ(x) = argmax_c f_c(x; θ_T).
- f(x; θ) ∈ R^C 로그확률. 자코비안 J_X : R^d → R^{N×C},  J_X u = [∂f(x;θ_T)/∂θ · u]_x.
- 요청: (k, ρ) — k 의 기여를 비율 ρ 만큼 뺀다. 결과 모델 θ(ρ) = θ_T − ρU_k (빼기 연산자 기준).

## 1. 재는 양: 기능 공간 효과
**정의.** 클라이언트 j 의 기능 효과 E_j = J_X U_j ∈ R^{N×C}. 선형화된 "j 를 빼면 각 입력의 각 클래스 로그확률이 얼마나 변하나".
- 계산: 순전파 하나. E_j ≈ [f(X; θ_T − εU_j) − f(X; θ_T)] / ε, ε 작게 (유한차분 = 자코비안-벡터곱). 전량 제거가 무너뜨리는 깊은 망에서도 ε 가 작아 안전.
- 지금 코드의 클래스별 손실 내적 v_j[c] = ⟨U_j, ∇_θ L_c⟩ 는 E_j 를 클래스별로 평균한 10 차원 요약이다 (손실 = −로그확률이므로 v_j[c] = −mean_{x: ŷ=c} E_j[x,c]). E_j 는 입력 단위 정보를 보존한다.

**공격의 정의 (상쇄).** 운반자 A 와 억제자 S 에 대해 입력 집합 X* 에서
  J_{X*}(Σ_{j∈A} U_j + Σ_{s∈S} U_s) ≈ 0,   J_{X*} U_s ≠ 0.
즉 **E_S|_{X*} + E_A|_{X*} ≈ 0** — 효과 행렬의 행들이 X* 위에서 서로 지운다. 이것이 두 공격의 공통 부분이고, 이 절차가 재는 것은 전부 이 식의 흔적이다.

## 2. 통계 (하나가 아니라 여럿, 서로 다른 면)
각 통계 s(j) 는 모든 j 에 대해 계산되고, 요청자 k 의 값은 나머지 {s(j)}_{j≠k} 의 분포에 비추어 판단한다.

| 통계 | 식 | 무엇의 흔적 | 어느 공격 |
|---|---|---|---|
| 크기 | m_j = ‖E_j‖_F / √N | 빼면 많이 바뀜 (억제자는 큰 기여) | FUBA (공개 입력) |
| 타깃 몰림 | g_j = max_c mean_x E_j[x,c] × D_j(c),  D_j(c) = 상승 기여 입력들의 ŷ 엔트로피(정규화) | 여러 출발 클래스 → 한 타깃 (백도어). 한 출발 → 여러 곳 (망각)은 작음 | FUBA·BadFU (BadFU 는 X_f 에서) |
| 부분집합 상쇄 | c_j = 1 − min_{S⊂others, |S|≤r} ‖E_j + Σ_{i∈S} E_i‖² / ‖E_j‖²  (탐욕) | 몇 명을 더하면 효과가 사라지는가 = 상쇄 짝의 존재. S 가 운반자 후보 | 둘 다 (X* ⊂ X 일 때) |
| 입력 단위 상쇄 | e_j(x) = E_j[x, ŷ(x)];  q_j = |{x ∈ Top10%|e_j| : e_j(x)·Σ_{i∈S} e_i(x) < 0}| / |Top| | 상쇄가 **어느 입력**에서 일어나는가 → X*_hat (정화·귀속에 쓴다) | 둘 다 |
| 라운드 일관성 | r_j = mean_t cos(E_j^t, Σ_t E_j^t) | 억제는 매 라운드 같은 방향 | FUBA; 적응형(미끼) 구분 |
| 확신 | h_j = mean 확신(θ−U_j 의 바뀐 답) | 지름길(백도어)은 확신 높음, 망각은 낮음 | 보조 |

## 3. 판정: 문턱 하나가 아니라 분포·결합·순차
1. **분포 가정 없는 p 값 (conformal).** p_k^{(s)} = (1 + #{j≠k : s(j) ≥ s(k)}) / K. 정상 요청자가 모집단과 교환 가능하면 P(p ≤ α) ≤ α 가 유한 표본에서 성립한다. z 와 달리 분포 가정이 없다. 단점: K 가 작으면 해상도 1/K (K=8 이면 최소 0.125). → K=20 이상에서 쓰고, 작은 K 에서는 z 와 병기.
2. **결합.** 통계 m 개의 p 값을 Fisher 로 합친다: F = −2 Σ_s log p^{(s)} ~ χ²_{2m}. 또는 지표 벡터 z ∈ R^m 의 Mahalanobis 거리 (모집단 공분산, 축소 추정). 한 지표만 넘어도 걸리게 하려면 max 결합, 여러 지표가 동시에 약하게 밀릴 때 잡으려면 Fisher.
3. **라운드 단위 순열 검정.** 라운드 조각 U_j^t 를 클라이언트 간에 무작위로 섞어 r_j 의 영분포를 만든다 (일관성 통계의 유의성). 비용 = 순열 수 × K·T 순전파 (작은 모델에서만).
4. **투여량에 걸친 순차 검정 (SPRT/CUSUM).** 단계 ρ_1 < ρ_2 < … 에서 통계 s(ρ) 를 얻으면 로그가능도비를 누적: Λ_n = Σ_i log [p_1(s(ρ_i)) / p_0(s(ρ_i))]. 문턱 A, B 로 '수락/계속/표시'. 조각 요청·순차 요청(장부)에도 같은 틀. 단계마다 독립 문턱보다 오탐이 낮다.
5. **투여량 곡선 외삽.** a(ρ) 를 ρ ∈ {0.2, 0.4, 0.6} 에서 재고 2 차로 맞춰 a(1) 을 예측한다. 전량 제거가 무너지는 모델에서 "다 빼면 어떻게 될지"를 가 보지 않고 추정. 선형화(E_j)의 ρ-스케일 판.

## 4. 정화: 공통 부분에서
표시된 요청 k, 운반자 후보 S (3 절의 상쇄 집합), 상쇄 입력 X*_hat (입력 단위 상쇄), 타깃 c* (타깃 몰림의 argmax).
- 방향 h = ∇_θ mean_{x∈X*_hat} f_{c*}(x; θ_T − U_k).  (백도어가 미는 방향, 활성화된 모델에서)
- 운반자 몫의 그 성분: U_j^∥ = (⟨U_j, h⟩/‖h‖²) h,  θ'' = θ_T − U_k − λ Σ_{j∈S} U_j^∥.
- λ 는 건강 상한 안에서 최대. U_k 는 되살리지 않는다 (α = ⟨θ'' − (θ_T − U_k), U_k⟩/‖U_k‖² 로 확인).
- 더 정밀한 판(미구현): h 를 한 방향이 아니라 X*_hat 위의 자코비안 행공간으로 잡고 U_j 를 그 공간에 투영 (저차원 부분공간 제거). 비용 = 자코비안 행 |X*_hat|·C 개.

## 5. 깊은 망에서의 제거 연산자 (무너짐)
빼기 θ_T − U_k 가 ResNet 에서 무너지는 것은 선형화가 깨지는 큰 걸음 때문이다. 선택지:
1. 단계 + 증류 (지금): 작은 걸음 뒤 직전 모델로 짧게 되돌림. 요청자 기여 일부 복원(α>0)이 대가.
2. **선형화 제거**: θ_T − U_k 대신 기능 공간에서 f − E_k 를 목표로 짧게 맞춤 (E_k 는 ε 로 안전하게 추정). 무너지지 않으면서 '요청자 효과만' 지운다. 미구현.
3. FedEraser 보정(원 논문의 연산자): 클라이언트 재참여 필요.

## 6. 비용 (요청 한 건)
- E_j 전부: 모델 버전당 K 순전파 (요청자 무관, 공유). 라운드 일관성: K·T 순전파 (선택).
- 요청 시: X_f 위의 K 순전파 + 통계·p 값 (행렬 연산). 모델 생성 0.
- 정화: 기울기 1 회 + |S| 투영.

## 8. 먼저 정할 것 (실험 아님)
1. 통계 집합: 2 절의 여섯 중 본 논문에 넣을 것. 제안: 크기·타깃 몰림·부분집합 상쇄 세 개 + 라운드 일관성(적응형 절).
2. 판정: conformal p + Fisher 를 본으로, z 를 병기. K=20 주 설정.
3. 제거 연산자: 깊은 망은 선형화 제거(5.2) 를 시도할지, 단계+증류로 갈지.
4. 정화: 한 방향 h 로 갈지 부분공간으로 갈지.
