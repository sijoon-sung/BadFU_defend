# 자리매김: 문제는 새롭고 도구는 표준일 때 (2026-10-12)

전제: "빼 보기 / 1 차 영향 내적"은 표준 도구다(LOO, 영향 함수, TracIn, Qian/Liu). 기여는 도구가 아니라
(1) 새로 정의한 문제, (2) 그 문제에서 도구가 드러내는 구조, (3) 문제 특유의 쓰임새, (4) 도구 밖의 건설적 부분에 둔다.

## 1. 문제를 새로 정의한다 — "연합 언러닝 요청의 수락 문제"
- 입력: 저장된 라운드별 기여 {U_j}, 현재 모델 θ_T, 요청 (k, 지울 데이터 D_k). 서버는 샘플을 못 보고(선택: D_k 의 입력만, 지울 때만), 학습을 못 한다.
- 출력: 수락/거부(또는 조건부 수락) + 내보낼 모델.
- 적대자: 요청을 들어주면 **남들의 입력**에서 모델 행동이 바뀌게 만드는 모든 요청. 잠복 백도어(BadFU, FUBA)는 가장 교묘한 사례, 삭제로 남의 샘플을 틀리게 만드는 공격(FedMUA 류)은 같은 정의의 다른 사례.
- 수동형 FU(빼기, 증류, FedEraser)에서 이 문제를 세운 논문이 없다. 선행은 중앙집중형 샘플 심사(Zhang 2023, Qian KDD'23, Liu AAAI'24)와 언러닝 라운드 갱신 심사(SubID, FedMUA 방어)뿐.

## 2. 도구가 이 문제에서 드러내는 구조 — "상쇄"
- 잠복 백도어 = 심은 몫 Σ_A U_j 와 억누른 몫 U_k 가 입력 X* (트리거 입력) 위에서 상쇄: J_X*(U_k + Σ_A U_j) ≈ 0, J_X* U_k ≠ 0.
- 따름 1 (보이지 않음): 몫 하나만 보는 통계(노름, 코사인, 부분공간)는 상쇄를 못 본다. 상쇄는 두 몫의 관계이기 때문. 증거: MASA 는 운반자만 잡고 위장자는 0.0~0.1, SubID 식은 non-IID 에서 소유자에 밀림.
- 따름 2 (피할 수 없음): 공격의 목표가 "빼면 X* 에서 깨어남"이므로, 서버가 X* 를 포함하는 X 에서 제거 효과를 재면 1 차 효과 −J_X U_k 가 0 이 아니다. 피하려면 X 에서 깨어나기를 포기해야 한다.
- 따름 3 (경계): X 가 공개 입력뿐이면 억제가 공개 입력까지 새는 경우(FUBA)만 보인다. X 에 지울 입력을 넣으면 억제가 자기 데이터에만 있는 경우(BadFU)까지 보인다. 두 메커니즘 비교가 이 경계를 실험으로 그린다.
→ 이 셋이 "왜 요청 시점에, 왜 제거 효과로, 왜 지울 입력에서" 에 대한 답이고, 도구가 표준이라도 이 구조를 말한 논문은 없다.

## 3. 문제 특유의 쓰임새 (같은 도구, 다른 쓰임)
- **대조군**: 영향 함수는 절대값을 쓰지만, 여기서는 "다른 클라이언트를 같은 양만큼 뺀 효과"가 영(null) 분포다. 정상 요청도 모델을 바꾸므로 절대 문턱은 없고 상대 문턱만 있다. 문턱은 모집단에서 보정(LOO conformal) → 오탐률 문장.
- **평가 입력**: 공개 입력 ∪ 지울 입력. 선행 어느 것도 요청 데이터를 평가 입력으로 쓰지 않는다.
- **통계**: 클래스별 효과 벡터 v_k = (⟨U_k, g_c(X)⟩)_c 의 패턴. 정상 = 자기 클래스에만 큼, 위장자 = X_f 위에서 전 클래스 같은 부호. 스칼라(노름·코사인·잔차)로는 안 나온다. non-IID 소유자 오탐도 이 패턴으로 가른다.
- **2 단계**: v_k 로 거르고(역전파 10 회), 걸린 요청만 실제로 빼서 확정·수정(K 모델). 정상 요청은 기본 FU 와 동일 (P1).

## 4. 도구 밖의 건설적 부분 — 역할 지도와 진짜 제거
- 걸린 요청자의 U_k 는 "무엇을 억눌렀는지"의 증거. Δ_j = a(θ_S) − a(θ_S − U_j) 로 운반자 집합 A 를 찾고(순위 선택), 혼자 빠져도 이상한 j 를 공동 위장자로.
- 진짜 제거: U_k 를 되살리지 않고(재억제, α 로 측정), A 의 기여 중 U_k 와 반대로 정렬된 성분(상쇄되던 방향)만 뺀다. 억제자를 '지도'로 써서 백도어를 지우는 것은 선행에 없다.

## 5. 평가 방법론
- 두 메커니즘 비교(억제가 새는 정도 = 경계), 저장 몫만으로 만드는 적응형 공격 5 종(재학습 없음), 집계 방어 4 종 위 궤적, MASA·SubID 식·FedEraser-R·FU 4 종 비교군.

## 6. 빼거나 뒤로 보낼 것
- 조금씩 빼기: "무너진 모델을 내보내지 않는 보호 장치"로 부록. 탐지 이득 주장 안 함.
- 격자/패치 탐침: 부정 결과 한 줄.
- 재억제 수정: 선택지로만, α 와 함께. 본 정화는 4 절.

## 7. 제목·첫 문단 후보
- 제목: "언러닝 요청은 시험이다: 연합 언러닝에서 상쇄형 백도어의 수락 기준" / "Trial Removal: Accepting Unlearning Requests in FL under Dormant Backdoors"
- 첫 문단: 잠복 백도어는 두 몫의 상쇄로 숨는다. 상쇄는 몫 하나로는 안 보이고 한쪽을 빼야 보인다. 우리는 삭제 요청을 그 자리에서 빼 보는 시험으로 바꾼다. 시험을 피하려면 공격은 깨어나기를 포기해야 한다. 시험이 보는 입력이 공개 입력뿐이면 억제가 새는 공격까지, 지울 입력까지 보면 자기 데이터에만 숨는 공격까지 잡힌다. 걸린 요청에서는 억제자의 몫을 지도로 삼아 심은 자를 찾고 백도어를 지운다.

## 8. 심사자가 그래도 "incremental" 이라 할 때의 답
- 문제 정의가 처음(수동형 FU 요청 수락), 경계 결과(두 메커니즘), 역할 지도·진짜 제거, 적응형 방법론. 도구는 표준임을 먼저 인정하고 Qian/Liu 와의 차이(샘플 vs 저장 몫, 절대 vs 대조군, 평가 입력)를 표로.
