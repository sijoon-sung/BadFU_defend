# 공격의 틀: 상쇄형(잠복) 백도어와 해로운 삭제 요청 (2026-10-12)

> 초기 기록. 현재 위협·수학은 `draft_v7.tex` 본문을 따른다. FUBA와 원래 BadFU는 같은 주입–억제–선택적 삭제 구조다. 아래 BadFU 클라이언트0/5 표는 로컬 변형이며 원래 공격은 같은 클라이언트 내부 표본 역할이다. ‘모든 정상 효과는 작다’, ‘모든 잠복 공격이 선형 상쇄를 반드시 만든다’, ‘관측 입력이 항상 트리거를 포함한다’는 보편적 주장은 채택하지 않는다.

## 1. 설정
- 연합학습 K 명, 라운드 t = 1..T. 서버는 라운드별 클라 기여 U_j^t 를 저장한다 (FedEraser 류 FU 의 전제). 누적 기여 U_j = Σ_t U_j^t. 최종 모델 θ_T.
- 수동형 FU: 요청 (k, D_k) 가 오면 서버가 저장된 기여로 R(θ_T, k) 를 만들어 내보낸다. 클라는 참여하지 않는다.
- 서버가 보는 것: {U_j^t}, θ_T, 공개 입력 X_p (라벨 없음), 그리고 선택적으로 요청이 지우려는 데이터의 **입력** X_f (라벨 없음, 지울 때만, 학습 때 해시로 봉인).

## 2. 공격 가족: 상쇄형 백도어
공격자 집단 M 은 두 역할로 나뉜다.
- **운반자(carrier) A ⊂ M**: 트리거 입력 X* 에서 타깃 클래스로 보내는 성분을 기여에 심는다.
- **위장자(suppressor) S ⊂ M**: 같은 입력 X* 에서 그 성분을 상쇄하는 성분을 기여에 심는다.

정의 (상쇄). 입력 집합 X* 와 모델의 자코비안 J_X* 에 대해
  J_X* (Σ_{j∈A} U_j + Σ_{s∈S} U_s) ≈ 0   이지만   J_X* Σ_{s∈S} U_s ≠ 0.
즉 학습이 끝난 θ_T 는 X* 에서 깨끗하고, S 의 기여를 빼면 X* 에서 타깃으로 쏠린다.

활성화. S (전부 또는 일부) 가 삭제를 요청하고 R 이 적용되면 θ' = θ_T − Σ_S U_s 가 되어 백도어가 깨어난다.

사례.
| 공격 | A | S | X* | 억제가 새는 범위 |
|---|---|---|---|---|
| FUBA | 공격자 클라 0–3 | 적대적으로 학습된 '방어자' 클라 4 | 트리거 생성기 입력 | 공개 입력까지 샘 (크고 넓은 억제) |
| BadFU | 백도어 샘플을 든 클라(코드: 0) | 위장 샘플 D_c = {(x+τ, y)} 를 든 클라(코드: 5) | 트리거 붙은 사진 | 자기 데이터(D_c)에서만 보임 |
| clean-unlearning (2506.12522), clean-label (2607.27936) | 분산 | 분산 / 샘플 | 트리거 | 미확인 |
| Zhang 2023 단계 요청 | — | 샘플 단위, 여러 번 | 트리거 | 중앙집중형 |

변형 (적응형). 위장자 분산(|S| > 1, 순차 요청), 요청 쪼개기(한 클라가 조각으로), 운반자 분산(|A| 큼, 각각 작음), 미끼(정상처럼 보이나 빼면 크게 흔들리는 클라로 모집단 오염), 기준 오염, 지연 활성(요청 뒤 몇 라운드 후), 자기 완결형(한 클라가 A 와 S 를 모두 들고 샘플 단위 요청 = BadFU 원형).

## 3. 넓은 가족: 해로운 삭제 요청
정의. 요청 (k, D_k) 가 해롭다 ⇔ R(θ_T, k) 가 **남들의 입력**에서 θ_T 와 다르게 행동한다 (다른 클라 한 명을 같은 양만큼 뺐을 때의 변화보다 유의하게 크게).
- 상쇄형 백도어는 이 정의의 특수한 경우(X* 에서 타깃으로 쏠림).
- 삭제로 남의 샘플을 틀리게 만드는 공격(FedMUA 류)도 같은 정의에 들어간다 (쏠림 대신 틀림).
- 정상 요청은 이 정의를 만족하지 않아야 한다 (non-IID 소유자는 자기 클래스 입력에서만 변한다 — 이것을 '남들의 입력'에서 제외할지가 설계 선택).

## 4. 왜 기존 방어가 못 보나 (구조적)
- 몫 하나만 보는 통계(노름, 코사인, 부분공간 잔차, MASA 의 언러닝 손실)는 상쇄를 못 본다. 상쇄는 두 몫의 **관계**다. (MASA: 위장자 AUROC 0.0–0.1; SubID 식: non-IID 에서 소유자에 밀림)
- 학습 중에는 관계를 볼 수 있어도(라운드별 짝의 효과 합) 공개 입력에서 새는 억제(FUBA)만 보인다.
- 요청 시점에 S 를 빼면 상쇄가 풀리므로, 그때 X* ⊂ X 인 X 에서 효과를 재면 반드시 보인다.

## 5. 방어가 재는 양 (지표)
1 차 근사: k 를 빼면 X 위 클래스 c 의 손실 변화 ≈ −⟨U_k, g_c(X)⟩,  g_c(X) = ∇_θ mean CE(θ_T; x ∈ X, ŷ(x) = c) (가짜 라벨).
- **효과 벡터** v_k = (⟨U_k, g_c(X)⟩)_c, 라운드별 v_k^t.
- **크기** ‖v_k‖, **전 클래스 동일 부호** |mean_c sign v_k[c]| (타깃 하나로 쏠림), **라운드 일관성** mean_t cos(v_k^t, v_k), **상쇄 짝** min_j mean_t ‖v_k^t+v_j^t‖/(‖v_k^t‖+‖v_j^t‖).
- 모두 모집단 z 로 정규화. X = X_p (공개) 와 X = X_f(k) (잊을 집합) 두 판.
- 실제 빼 보기(dose_fu)는 이 1 차 근사의 정확한 판이며, 걸린 요청의 확정·수정·역할 지도에 쓴다.
코드: `FUBA/traj_indicators.py` (지표), `FUBA/dose_fu.py` (빼 보기), `FUBA/pair_roles.py` (역할 지도).

로컬 확인 (FUBA loc_fuba, 1 시드, 11 초):
| 지표 | 위장자 4 (공개 입력) | 위장자 4 (잊을 집합) | 정상 7·5 (잊을 집합) | 운반자 0–3 (공개) |
|---|---|---|---|---|
| mag z | +7.6 | **+12.2** | +0.6 / +0.5 | −0.5 ~ −0.6 |
| consist z | +2.4 | **+4.0** | +1.1 / +1.2 | −1.1 ~ −1.6 |
| spread | 0.8 (정상과 같음) | 0.8 | 0.8 | 0.2 ~ 0.6 (운반자가 오히려 낮음) |
| cancel (cos) | ≈ 0 (모두) | ≈ 0 | ≈ 0 | ≈ 0 |
- 크기와 라운드 일관성이 위장자를 가른다. 빼 보기(z 11~14)와 같은 결론을 역전파 10 회로 얻는다.
- **상쇄 짝은 공개 입력에서는 안 보인다** (코사인 ≈ 0). 운반자의 효과는 트리거 입력에만 있어서 공개 입력의 클래스 손실 공간에는 나타나지 않고, 위장자의 공개 입력 효과는 '큰 정상 클라'처럼 보인다. 따라서 상쇄 관계 자체는 X* 를 포함한 입력에서만 잴 수 있고, 학습 중 조기 경보(공개 입력만)는 이 지표로는 FUBA 에서 지지되지 않는다. 전 클래스 동일 부호(spread)도 FUBA 에서는 변별력이 없다 (BadFU 에서는 에이전트 확인상 있었음; 공격 메커니즘에 따라 다름).

로컬 확인 (BadFU loc_badfu, ResNet-18, K=6, 1 시드, 87 초): 잊을 집합 위에서
| 지표 | 위장자 5 | 정상 1 | 정상 2 |
|---|---|---|---|
| mag z | +0.5 | +2.4 | +2.8 |
| spread (값 / z) | **0.8** / +1.8 | 0.2 / 0.0 | 0.2 / 0.0 |
| cancel 짝 (z) | **0 = 진짜 운반자** (+2.3) | 2 (+1.7) | 1 (+2.3) |
- 방향은 맞다: 위장자만 전 클래스 동일 부호(0.8 vs 0.2), 상쇄 짝으로 진짜 운반자 0 을 찍는다. 그러나 K=6 모집단에서 z 가 문턱 3 을 못 넘고, 크기(mag)는 자기 데이터 효과 때문에 정상이 더 크다.
- 반면 실제 빼 보기(dose_fu, 잊을 집합 탐침)는 같은 궤적에서 첫 단계 z 8.4 로 잡았다. **1 차 근사는 싼 거름망, 확정은 실제 제거.** 두 단계 설계의 근거.

## 6. 피할 수 없음 (주장)
공격이 X* 에서 깨어나려면 J_X* Σ_S U_s ≠ 0 이어야 한다. 서버가 X ⊇ X* 에서 제거 효과(또는 그 1 차 근사)를 재면 그 값은 0 이 아니고, 같은 X 에서 정상 클라를 뺀 효과는 상쇄와 무관하므로 작다. 공격자가 지표를 낮추는 길은 (i) X* 를 X 밖으로 옮기거나(→ 지울 입력을 X 에 넣으면 막힘), (ii) 깨어나기를 포기하는 것뿐이다. 남는 공격면은 모집단 오염(미끼)과 분산(여러 S, 여러 A)이며, 이는 적응형 절에서 다룬다.
