# 쉬운 말로 정리 (2026-10-13)

## 1. 문제
- 여러 기관이 자기 데이터는 내놓지 않고, 모델만 같이 키운다. 이것이 연합학습이다.
- 나중에 한 기관이 "내 몫을 지워 달라"고 할 수 있다. 이것이 연합 언러닝이다.
- 공격자는 이 "지우기"를 역으로 쓴다. 한 패는 모델에 뒷문을 심고, 다른 한 명은 그 뒷문을 눌러서 막아 둔다.
- 학습이 끝난 모델은 깨끗해 보인다. 뒷문이 눌려 있기 때문이다.
- 그런데 막아 두던 사람이 "내 몫을 지워 달라"고 하면, 누르던 힘이 사라지고 뒷문이 열린다.

## 2. 우리가 확인한 사실
- 공격은 실제로 된다. 지우기 전에는 깨끗하고, 막던 사람을 지우면 뒷문이 열린다.
- 정확하게 지우는 것(처음부터 다시 학습)도 소용없다. 뒷문을 심은 패가 아직 남아 있기 때문이다.
- 즉 "요청자를 잘 지우는 것"이 답이 아니다. "뒷문을 심은 패를 걷어내는 것"이 답이다.
- 심은 패를 빼고 다시 학습하면, 요청도 들어주고 뒷문도 사라진다.

## 3. 누가 심은 패인지 어떻게 아는가
- 기존 방법들은 갱신 하나를 본다. 크기가 큰가, 방향이 남들과 다른가, 서로 닮았는가.
- 크기를 보면, 데이터가 많은 정상 기관도 같이 잡힌다.
- 방향을 보면, 심은 패는 남들과 아주 비슷해서 안 잡힌다.
- 우리가 본 것은 다르다. 갱신들끼리 서로 **지우는가**를 본다.

## 4. 균형 장부
- 서버는 매 라운드 각 기관의 갱신이 모델의 답을 어느 쪽으로 얼마나 미는지 적어 둔다.
- 정상 학습에서는 모두가 비슷한 쪽으로 조금씩 민다.
- 뒷문이 숨어 있으면 한 쪽은 세게 밀고, 한 명은 그만큼 세게 되민다.
- 그래서 합은 거의 0 인데 개별 크기는 크다. 이것을 "균형"이라 부른다.
- 되미는 한 명이 막던 사람이다. 미는 여러 명이 심은 패다.
- 한 명이 세게 밀고 다른 한 명이 되미는 경우도 있다. 이것은 데이터가 많은 정상 기관이다. 손대지 않는다.

## 5. 결과 (논문 설정, 여섯 번 실험)
| 본 것 | 결과 |
|---|---|
| 막던 사람이 "되미는 한 명"으로 나오는가 | 여섯 번 모두 |
| 심은 패가 "미는 여러 명"으로 나오는가 | 여섯 번 모두 |
| 데이터 많은 정상 기관이 심은 패로 오인되는가 | 아니다 (미는 사람이 한 명뿐이라 구분됨) |
| 언제부터 보이는가 | 전체 학습의 10분의 1 도 지나기 전 (노트북 1회 확인) |
| 심은 패를 빼고 다시 학습하면 | 뒷문 사라짐, 정확도 그대로 |

## 6. 논문 한 줄
지우면 열리는 뒷문은 "서로 지우는 기여들"로 숨는다. 이 균형은 학습 중 장부에서 보인다. 처방은 요청자를 심판하는 것이 아니라 심은 패를 걷어내는 것이다.

## 7. 왜 새로운가, 왜 넓게 통하는가
- 새로운 이유: 기존 방어는 전부 갱신 하나의 성질이나 갱신들의 닮음을 본다. "갱신들이 서로 지운다"는 관계를 보는 방어는 없다.
- 넓게 통하는 이유: 지워서 깨우는 뒷문은 어떤 식이든 학습 중에 숨어 있어야 하고, 숨으려면 되미는 힘이 반드시 있어야 한다. 되미는 힘이 있으면 장부에 남는다.
- 좁힌 조건: 서버가 라운드별 갱신을 저장하고, 공개 입력 몇 장을 갖고 있다.

## 8. 남은 일
- 서버에서 같은 분석을 여섯 실험 전부에 다시 돌려 표를 채운다 (명령은 그대로).
- 집계 방어가 켜진 실험, 막는 사람이 둘인 실험에서도 같은 표를 만든다.
- 다른 공격(BadFU) 세 시드에서 확인한다.
