# 지금 알고리즘과 확장 방안 (2026-10-13)

## 1. 지금 알고리즘 (두 층 + 대응)
| 층 | 재는 것 | 입력 | 판정 | 산출 | 상태 |
|---|---|---|---|---|---|
| 학습 중 (CCD) | 클래스별 누적 기여도 Φ_j(c): 참여자 갱신이 공개 입력의 클래스 로그 우도를 바꾼 양의 누적 | 라운드별 갱신, 공개 입력 500 장 | 상쇄 지수 H ≥ 0.8, 최소 기여자 z ≤ −3, 양의 기여자 ≥ 2 명, 집중도 ≤ 0.6, 3 라운드 연속 | 표적 클래스, 억제자, 주입자 집합, 복원 라운드 | 6/6 (R-013) |
| 요청 시 (DOSE 상대 기준) | 요청자 기여를 ρ 만큼 뺀 모델의 예측 변화를, 남들을 같은 ρ 로 뺀 변화의 분포에 대한 z 로 | 보관 기여, 공개 입력 (+ 삭제 대상 입력) | z ≥ 문턱 (단계마다) | 경보, 활성화 입력 | 3/3, 소유자 z 0 (R-009) |
| 대응 | 공모 집합 {억제자} ∪ 주입자 배제 | — | — | 복원 라운드에서 재개 또는 재학습 | ASR 0.5–0.7 (R-010, R-014) |

## 2. 확장 방안 (우선순위 순; 비용·얻는 것·필요한 것)
| # | 확장 | 무엇을 바꾸나 | 얻는 것 | 필요한 것 | 비용 |
|---|---|---|---|---|---|
| E1 | **참여 자연 실험으로 기여도 추정 (안전 집계 대응)** | 개별 갱신 없이 라운드별 전역 모델과 참여자 명단만으로, 클래스별 전역 변화를 참여 지표에 회귀해 Φ_j(c) 를 추정 | 서버가 개별 갱신을 보관하지 않는 설정(secure aggregation)에서도 CCD 동작 → 범용성의 가장 큰 확장 | 참여율 < 1 (이미 0.4), 라운드 수 ≫ K | 거의 0 (R-009 의 part_beta 가 이미 3/3) |
| E2 | **상쇄 그래프 (쌍별 상쇄 행렬)** | 라운드별 기여도의 클라이언트 쌍 반상관 행렬 → 스펙트럼 군집으로 공모 집합 추출 | 주입자·억제자가 여럿이어도 집합 단위로 식별 (현재는 최소 기여자 1 명 + 양의 집합) | 라운드별 기여도 (이미 저장) | 낮음 (캐시된 밀기로 즉시) |
| E3 | **입력 단위 상쇄 지도** | 클래스 평균 대신 입력 x 별 상쇄 에너지를 계산해 상쇄가 일어나는 입력 영역 X̂* 를 복원 | 전파 가정(η>0) 완화: 상쇄가 일부 입력에만 새도 그 입력에서 잡음; 트리거 영역 추정 → 요청 시 층의 입력으로 | 공개 입력을 500 → 수천 장 | 중간 (순전파 수 비례) |
| E4 | **순차 검정으로 경보 (CUSUM/SPRT)** | "3 라운드 연속" 을 누적 로그가능도비로 대체, 공격 없는 궤적으로 영분포 보정 | 오경보율을 수치로 보장 (명제 2 를 실측 기반으로) | 공격 없는 궤적 (생성 중) | 낮음 |
| E5 | **표적 클래스 가정 완화** | 클래스 단위 대신 "예측 분포 전체의 KL 변화" 로 상쇄 지수 정의 | 다중 표적·비표적 오분류형(FedMUA 류)까지 정의 1 의 조건 (ii) 로 통일 | 없음 | 낮음 |
| E6 | **강건 집계와 결합** | 서버가 실제로 쓴 집계 가중치(Median/Krum/FLAME 의 선택·절단)를 Φ 계산에 반영 | 집계 방어 위에서도 기여도가 정확 | tdef 궤적 (있음) | 낮음 |
| E7 | **대응의 세분화** | 전체 배제 대신 공모 집합의 가중치 축소(FoolsGold 식) 또는 복원 라운드 이후 공모 기여만 점진 감산 | 오탐 시 피해 축소, 재학습 비용 절감 | R-014 와 비교 실험 | 중간 |
| E8 | **적응형 공격자 실측** | 억제자 손실 가중치·atk_eps·clients_ratial 격자 | §5 의 trade-off 를 실측 표로 (반합성 → 실제) | 궤적 생성 (DISLAB) | 높음 (궤적 수) |
| E9 | **이론** | 명제 1 (전파 비율 η, 활성화 γ) 과 명제 2 (MAD 꼬리) 를 가정과 함께 정리로; 공격자의 trade-off 를 부등식으로 | 논문의 보장 절 | 없음 | 낮음 (글) |
| E10 | **규모·모달리티** | CIFAR-10/ResNet-18 (생성 중), 텍스트/표 데이터 | 범용성의 실증 | 궤적 | 높음 |

## 3. 제안 순서
1. E1 (안전 집계 대응) 과 E2 (상쇄 그래프) 는 캐시된 밀기로 바로 되고 범용성 주장을 가장 키운다 → 먼저.
2. E4 (순차 검정) 는 공격 없는 궤적이 오면 같이.
3. E3·E5 는 BadFU 결과(전파 안 됨)를 받는 확장 → BadFU 40 라운드 뒤.
4. E8·E10 은 DISLAB 궤적 일정에 맞춰.
