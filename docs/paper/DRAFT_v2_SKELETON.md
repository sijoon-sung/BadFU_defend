# 초안 v2 뼈대 — 주장 · 위협 모델 · 표 · 한계 (2026-10-12, 논문 설정 K=20 결과 반영)

이 문서는 "무엇을 주장하고, 무엇으로 증명하고, 무엇을 주장하지 않는가"를 한 장에 고정한다. 숫자는 `docs/RESULTS_LOG.md` 의 R-006 ~ R-009 (논문 설정: K=20, 악성 5/20, 100 라운드, 참여 0.4, 3 시드 × IID/owner).

## 1. 주장 (한 문장, 바꾸지 않는다)
> **삭제로 깨어나는 백도어는 기여들의 상쇄다. 상쇄는 갱신 하나나 전체 합에서는 보이지 않고 부분합에서 보이며, 올바른 처방은 요청을 심판하는 것이 아니라 심은 기여를 걷어내는 것이다.**

세 부분으로 나뉘고 각각 표 하나로 증명된다.
- A (보임): 부분합(요청자를 조금 뺀 모델)에서 상대 기준으로 재면 위장자가 갈리고, 정상·소유자는 갈리지 않는다. 갱신 하나 점수·전체 합 검사는 못 가르거나 소유자를 같이 잡는다. → 표 2.
- B (처방): 정확한 언러닝은 공격을 완성한다(재학습도 백도어). 심은 쪽을 걷어내면 삭제를 이행하면서 백도어가 사라진다. → 표 3.
- C (시점): 상쇄는 요청이 오기 전, 학습 중 부분합과 참여 무작위성에서 이미 보인다. → 표 4.

## 2. 위협 모델 (좁히는 칸 — 다섯 줄, 그대로 지킨다)
1. 서버는 라운드별 기여 U_j^t 를 저장한다 (FedEraser 류 FU 서버). 라벨 없는 공개 입력 500 장을 가진다. 라벨·트리거·역할은 모른다.
2. 공격: 운반자 집합 A 가 백도어를 심고 위장자 S 가 같은 입력에서 거꾸로 밀어 숨긴다. 악성은 소수 (논문 설정 5/20). 백도어는 한 타깃 클래스로 몰린다.
3. 요청: 클라이언트 단위. 요청자는 위장자일 수도, 정상(클래스 소유자 포함)일 수도 있다. 서버는 요청자의 의도를 판정하지 않는다.
4. 언러닝 연산자: 저장 기여 빼기(단계), 빼기+짧은 증류, 재학습(남은 클라 재참여). 전량 빼기는 100 라운드 궤적에서 무너진다 (EXPERIMENT_LOG).
5. 데이터·모델: MNIST/LeNet (FUBA), CIFAR-10/ResNet-18 (BadFU, 로컬). 집계 방어(Median, Multi-Krum, FLAME, FLDetector) 위 궤적 포함.
한계 칸으로 보내는 것: 위장자 여러 명, 다중 타깃, 트리거가 clean 특징과 겹치는 경우, K < 10 의 p 값.

## 3. 넓히는 칸 (이 조건 안에서 "어떤 경우에도")
공격 2 종 (FUBA, BadFU) × 연산자 3 종 × 요청자 3 종 (위장자 / 정상 / 소유자) × 집계 방어 4 종 위 궤적 × 2 분할(IID, owner).

## 5. 한계 (스스로 쓰는 칸)
- 해독제(DEFUSE)는 논문 설정에서 실패했다. 짝 집합이 20 명 중 10–18 명으로 커지고(정상도 정렬 −0.8), 투영 제거로는 띠 안으로 못 돌아온다. 처방은 재억제(α 0.1) 또는 운반자 제외 재학습(예정)으로 간다.
- 소유자: 상대 기준은 안 잡지만(z 0), 절대 기준은 잡는다. 재억제를 소유자에게 쓰면 α 0.33 (owner_kd 19) — 소유자의 지식이 되돌아온다. "경보 = 요청자 심판"이 아니라는 틀이 필요하다.
- 위장자 여러 명(K=16, sup2): 궤적만 있음, 분석 예정. 다중 타깃 미검증. BadFU 1 시드.
- 깊은 망의 빼기 연산자 열화 (BadFU ACC 76).

## 6. 왜 해독제가 논문 설정에서 실패했나 (로그 R-007 의 per-seed)
- 100 라운드 누적 기여는 ρ=0.1–0.2 단계 5–10 번이 필요하다. 코드의 정화 예산 `--max_purify 2` 가 셋째 단계에서 바닥나 `reject` 로 끝났다 (kd 연산자 실행에서도 같은 이유로 reject 가 났고, 그 시점의 모델은 ASR 3–9, ACC 96 이었다). → 예산을 단계 수에 맞춘다 (코드 수정 1).
- 활성화 입력 위 짝 집합이 커졌다: 운반자 정렬 −0.87~−0.91 은 그대로지만 정상 중 상당수가 −0.6~−0.88. 간격 규칙이 정상을 끌어들인다. → 단계마다 정렬을 재서 모든 단계에서 음수인 후보만 (코드 수정 2), 또는 최소제곱 가중치로 정상을 눌러 준다.
- λ 0.25 에서 z 가 18–25 로 남고 0.5 이상은 건강 상한을 넘는다: 위장자 몫이 너무 커서 운반자 몫의 h 성분만으로는 못 돌려놓는다. 이것은 방법의 한계이고, 처방을 재학습 쪽으로 옮기는 근거다.
