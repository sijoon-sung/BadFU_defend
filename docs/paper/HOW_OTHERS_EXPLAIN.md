# 방어 논문에서 가져올 것은 주장보다 도출 과정이다

2026-10-14. 이전 24편 조사표는 [당시 기록](../archive/paper_logic_20261013/HOW_OTHERS_EXPLAIN.md)으로 보존했다. 그 문서의 “좋은 방어는 모두 불변량 하나를 증명한다”, “정상 학습에는 상쇄가 없다”, “양의 다리 하나는 정상”이라는 결론은 채택하지 않는다. 아래는 네 논문의 본문을 다시 읽고 정리한 설계 관점이다. 공통 형식에 대한 해석은 우리 판단이며 각 논문의 정리가 아니다.

## 1. 어떤 논리 전개가 좋은가

| 논문과 읽은 절 | 출발하는 문제 → 관측 → 알고리즘 | 우리에게 적용할 전개 | 가져오면 안 되는 결론 |
|---|---|---|---|
| [MASA, WACV 2025](https://arxiv.org/html/2411.01040v1), §3–4 | 정상 과제와 백도어 과제가 결합되어 정적 차이가 가려진다 → 개별 언러닝으로 행동 차이를 드러낸다 → non-IID 영향을 줄이는 사전 융합과 손실 기반 점수를 설계한다 | 먼저 관측 가능한 차이를 만드는 개입을 정하고, 혼동 요인을 완화한 다음 점수를 정의한다 | 개별 언러닝이 모든 잠복 공격을 반드시 드러낸다는 보장. MASA와 우리 요청 감사가 같은 문제라는 주장 |
| [FLDetector, KDD 2022](https://zaixizhang.github.io/ZaixiZhang_files/FLDetector.pdf), §3–4 | 정상 갱신의 시간적 관계에서 예상 갱신을 도출한다 → 실제와 예상의 차이를 누적한다 → 군집으로 판정한다 | 변화의 절대 크기보다 “어떤 기준에서 예상 밖인가”를 먼저 정의한다 | 제한된 IID·평활성·학습률 및 갱신 반전 공격의 정리를 일반 백도어 탐지 정리로 확대하는 것 |
| [FLAME, USENIX Security 2022](https://www.usenix.org/system/files/sec22-nguyen.pdf), §3–5 | 공격자가 방향·크기를 조절할 수 있다 → 군집 필터 뒤에도 잔여 영향이 있다 → clipping과 잡음을 결합한다 | 각 구성요소가 남기는 실패를 다음 구성요소의 필요성과 연결한다 | 탐지 성공과 잔여 공격 제거를 동일시하는 것. 선형 모델 분석을 우리 DNN 삭제 연산자의 보장으로 옮기는 것 |
| [DeepSight, NDSS 2022](https://www.ndss-symposium.org/wp-content/uploads/2022-156-paper.pdf), §II–VII | 공격 효과와 모델 특성의 관계를 설정한다 → 여러 표현을 설계한다 → 분류·군집·clipping의 역할을 구분하고 소거 실험으로 확인한다 | “이 특징을 왜 재는가”와 “이 단계가 어떤 실패를 처리하는가”를 실험 질문에 대응시킨다 | 특정 지표의 성질 증명이나 공격자의 딜레마를 보편적 악의 식별 정리로 쓰는 것 |

전개 순서는 **문제에서 생기는 관측의 공백 → 검증 가능한 가설 → 측정 절차 → 정상 현상과의 혼동 통제 → 판정과 조치 → 각 설계 선택을 반박할 수 있는 실험**으로 잡는다. 반드시 하나의 불변량이나 새로운 정리가 있어야 하는 것은 아니다. 직관, 지표의 수학적 성질, 공격 탐지 성능을 서로 다른 근거 수준으로 기술한다.

## 2. 우리 원고에 적용한 결정

1. **출발점:** 삭제 전 모델의 행동만으로 삭제 후 활성화를 판단하기 어렵다. 학습 중 상쇄는 가능한 원인의 하나다.
2. **주 질문:** FL에서 주입과 억제가 이루는 기능적 장력을 기록하고, FU의 선택적 삭제가 그 관계를 깨뜨리는지를 삭제 모델 없이 검사할 수 있는가?
3. **핵심 수정:** 학습 중 CCD 장부를 삭제 가능한 단위로 일반화하고 양방향 삭제 경계 질량을 계산한다. BadFU 내부 표본과 FUBA의 클라이언트 역할은 같은 모형에 놓인다. soft 반응은 비교군으로 둔다.
4. **확인:** 학습 이력에서 발견한 관계와 삭제 경계의 효과를 정상 대조·별도 입력·실제 FU 결과로 검증한다. 이 마지막 FU 실행은 평가 절차이며 장력 검출을 위해 먼저 수행하는 단계가 아니다.
5. **역할:** CCD의 학습 중 장력 관측을 발전시키는 것이 중심이다. TRACE·공동삭제·DOSE는 비교와 확인, 복구와 망각 검증은 별도 조치다. 장력 그 자체를 악의의 증명으로 쓰지는 않는다.
6. **현재 결론:** FUBA의 한 설정에서 추가 신호가 있지만 BadFU 변형에서 개선은 없다. 현재 증거는 연구 후보를 뒷받침하며 두 공격 계열의 공통 방어 성공을 입증하지 않는다.
