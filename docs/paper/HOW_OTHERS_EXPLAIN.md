# 방어 논문에서 가져올 것은 주장보다 도출 과정이다

## 이번 구현과 원문 수치 검토 (2026-10-14)

요청한 **Problem / Key Idea / Evaluation / Limitations / Next Actions** 형식의 [방어 6편과 FedEraser 검토](../paper_reviews/05_defenses_novelty.md)를 추가했다. 각 수치에 표·조건·지표를 명시하고 저자 주장과 우리의 해석을 구분했다. [실행 가능한 알고리즘](TENSION_CONTROL.md)은 장력 B와 실제 FU 제안의 기능 증가 A를 결합해 방향을 선택하고, 보존 클래스 손실 제약 아래 실제 갱신을 수정한다. 벡터 replay와 실제 MNIST 보정 단계 실험을 구현했다. 전체 FU·원래 BadFU·망각 인증은 아직 없다.

첫 개발 단계 비교에서는 이력 없는 동일 제어가 더 좋은 대리 좌표 제어를 보였다. 실제 트리거로 재검사하자 oracle 장력 상위8좌표가 모두 실제 표적8을 가리켜, 그 대리 좌표 결과를 장력 원리의 실패로 읽을 수 없음을 확인했다. 실제 한 단계 ASR은 무방어20.74%, 밝기 관측 제어10.70%였으나 단순 선형 기준도10.70%였다. 전체 FU와 이력의 추가 가치는 미확정이다. ‘현재 증가’를 결합한 수정과 후속 진단은 같은 개발 모델을 사용하므로 별도 확인이 필요하다. 아래의 ‘아직 구현 전’ 표현은 이 추가 이전의 조사 기록이다.

## 현재 판단: FL→FU 백도어라는 위협을 고정하고 신규성의 근거를 검증한다

2026-10-14 추가 조사. 원고를 장력 점수의 개선만으로 완성하려 하지 않는다. 고정된 문제는 **FL에서 심은 백도어가 FU에서 활성화되는 과정의 방어**다. 장력, 관측 좌표, 제어 방식은 바꿀 수 있는 알고리즘 후보다. 구조를 정의한 것과 이 구조에 유효한 방어를 만든 것을 구분한다.

| 원논문과 확인한 위치 | 논문이 신규성을 세운 연결 | 우리에게 적용할 교훈과 한계 |
|---|---|---|
| [MASA](https://arxiv.org/html/2411.01040v1), Introduction 기여 목록, §§3–4 | 정적 통계에서 가려진 백도어 → 개별 언러닝 동역학 → non-IID의 행동 차이를 사전 모델 융합으로 완화 → 탐지 | 새로운 관측을 제안하는 것과 그 관측의 정상 혼동을 제거하는 장치를 함께 제시한다. 우리도 raw 장력의 문턱만 바꾸어서는 부족하다. |
| [BackdoorIndicator](https://arxiv.org/html/2405.20862v1), Introduction, §3, non-IID 실험 | 유사한 파라미터 갱신만으로 구분 어려움 → 서버가 OOD 지표 과제를 심어 관측 추가 → BN 통계 이동을 통제 → 지표 유지로 판정 | 식별 불가능한 기존 관측에서 점수만 고치지 않고 정보를 추가했다. OOD/지표 과제 가정이 우리 잠복 공격에서도 유지되는지는 별도 문제다. |
| [FedREDefense](https://proceedings.mlr.press/v235/xie24c.html), [저자 코드 설명](https://github.com/xyq7/FedREDefense), §§4–5 | 클라이언트 간 비교의 non-IID 취약성 → 개별 갱신을 압축된 지식으로 재구성 → 재구성 오차 검사 | 비교 기준을 다수 정상 클라이언트에서 개별 학습 과정으로 바꿨다. 실제 poisoned-data 학습도 재구성될 수 있으므로 이 방법을 그대로 붙이면 BadFU가 해결된다고 주장할 수 없다. |
| [DeepSight](https://www.ndss-symposium.org/wp-content/uploads/2022-156-paper.pdf), Introduction, §§V–VI | 단순 이상치 검사의 정상 오제외 → 여러 내부 표현·군집으로 강한 공격 영향 검사 → 남는 영향은 clipping | 악성 신원 완전 식별을 요구하지 않고 오제외와 잔여 공격 영향을 함께 평가한다. 희귀 클래스 ACC까지 보아야 한다. |
| [FLAME](https://www.usenix.org/system/files/sec22-nguyen.pdf), Goals and Contributions, §§4–5 | 필터 누락과 과도한 잡음의 성능 손실 → 군집·clipping으로 필요한 잡음 감소 → 공격 영향 완화 | 기존 부품의 조합도 각 부품이 다음 단계의 실패나 비용을 줄이는 근거가 있으면 기여가 될 수 있다. 단순히 세 기법을 나열하는 것으로는 부족하다. |
| [UnlearnGuard](https://arxiv.org/html/2501.17396v1), §§2.3, 4 | FU 도중 악성 갱신 제출 → FL 이력으로 FU 갱신 예측 → 크기·방향 검사 | FL 이력 활용과 FU 단계 방어는 이미 존재한다. 우리는 FL 이력 자체에 잠복한 기여 관계와 삭제 의존성이 추가 정보를 주는지를 보여야 한다. |

위 표의 “교훈”은 우리의 해석이다. non-IID에서의 실험상 개선을 의도 식별의 보편 정리나 모든 잠복 공격에 대한 보장으로 옮기지 않는다.

### 사용자 지적을 반영한 세 가지 정리

- **FedEraser 기록을 재사용할 수 있다.** [원논문 §III-B](https://arxiv.org/pdf/2012.13891)는 클라이언트별 저장 모델 업데이트의 노름과 새 보정 업데이트의 방향을 결합한다. 원시 minibatch gradient 전체가 필요한 것은 아니다. FUBA의 클라이언트 단위 장부에는 이 기록을 사용할 수 있지만, 원래 BadFU의 표본별 과거 기여가 자동으로 생기는 것은 아니다.
- **강한 주입을 가리는 상쇄는 기능적 장력을 요구한다.** 단, 실제 공격 입력과 좌표의 효과가 크다는 조건이 있어야 한다. 작은 분류 마진에서는 작은 변화도 ASR을 크게 올릴 수 있으므로 높은 ASR만으로 공개 입력의 큰 절대 장력을 증명할 수 없다.
- **동일한 관측이면 의도를 항상 구별할 수 없다.** 목표를 정당한 보존 과제와 망각을 지키며 표적 오작동을 줄이는 것으로 둔다. 정상/공격의 관측이 겹친다는 사실과 모든 non-IID 환경에서 모든 방어가 불가능하다는 주장은 다르다.

### 다음 후보는 관측과 실제 FU 조치를 함께 바꾼다

원고의 “신규성을 위한 다음 알고리즘 설계” 절에 미검증 명세로 반영했다.

1. **관측:** 동일 입력과 의미 보존 변환 입력의 중심화 로짓 차에서 학습 기여를 측정한다. 입력과 무관한 클래스 편향은 상쇄되지만 모든 non-IID 특징 변화가 제거되는 것은 아니다. 변환이 공격 특징을 자극하지 못하는 관측 실패도 별도로 측정한다.
2. **경계:** 그 좌표의 FL 장력과 실제 누적 삭제 요청으로 위험 기능 방향을 선택한다. 장력 단독·경계 단독·선형 삭제 영향과 비교하여 추가 정보를 검증한다.
3. **조치:** 실제 FU의 보정 갱신을 기준으로 위험 방향 증가에 벌점을 주고 보존 클래스 손실 증가를 제한하는 국소 제어를 검토한다. 억제 기여를 되넣지 않으며 클라이언트 전체를 공격자로 확정할 필요가 없다. 투영/정규화 자체는 기존 기법이므로 이력과 경계가 제어 방향을 정하는 효용이 신규성의 검증 대상이다.

원래 BadFU에서 표본별 과거 장부가 없다는 이유만으로 모든 방어가 막힌다고 해석하지 않는다. 실제 FU에서 camouflage를 제거한 보존 데이터로 계산한 보정 갱신은 추가 정보가 될 수 있다. 같은 현재 모델의 함수 Jacobian에서 과거 혼합 업데이트와 현재 보정 업데이트를 비교하는 경로를 원고에 후보로 적었다. 학습 길이·노름을 맞추고 정상 삭제 변화와 비교해야 하며, 이를 과거 표본 기여의 정확한 복원으로 주장하지 않는다. 새 후보 언러닝을 반복 실행하는 탐지와도 구분한다.

**기여가 되기 위한 관문:** 새로운 관측이 정상 혼동을 줄여야 하고, 이력 없는 같은 제어보다 FL→FU 조건부 제어가 좋아야 하며, 요청 이행·정상/희귀 클래스 ACC·ASR·비용을 함께 만족해야 한다. 어느 하나도 아직 실측 완료로 쓰지 않는다. 이미 제공한 v3 점수와 18/68개 실행기는 첫 단계의 비교 자료 수집 도구다.

**실험 전 구현 확인:** `FUBA/unlearn_method/federaser_faithful.py`는 평균을 낸 뒤 층별 노름을 적용한다. 원논문의 개별 클라이언트 보정 후 집계와 일반적으로 다르며 부분 참여 처리도 재검증이 필요하다. 이 파일 이름을 원논문 충실 구현의 증거로 쓰지 않는다. 현재 장력 재생은 이 코드를 실행하지 않는다.

## 1. 어떤 논리 전개가 좋은가

| 논문과 읽은 절 | 출발하는 문제 → 관측 → 알고리즘 | 우리에게 적용할 전개 | 가져오면 안 되는 결론 |
|---|---|---|---|

전개 순서는 **문제에서 생기는 관측의 공백 → 검증 가능한 가설 → 측정 절차 → 정상 현상과의 혼동 통제 → 판정과 조치 → 각 설계 선택을 반박할 수 있는 실험**으로 잡는다. 반드시 하나의 불변량이나 새로운 정리가 있어야 하는 것은 아니다. 직관, 지표의 수학적 성질, 공격 탐지 성능을 서로 다른 근거 수준으로 기술한다.

## 2. 우리 원고에 적용한 결정

1. **출발점:** 삭제 전 모델의 행동만으로 삭제 후 활성화를 판단하기 어렵다. 학습 중 상쇄는 가능한 원인의 하나다.
2. **주 질문:** FL에서 주입과 억제가 이루는 기능적 장력을 기록하고, FU의 선택적 삭제가 그 관계를 깨뜨리는지를 삭제 모델 없이 검사할 수 있는가?
3. **당시 수정:** 학습 중 CCD 장부를 삭제 가능한 단위로 일반화하고 양방향 삭제 경계 질량을 계산했다(v2). 이후 동일 비율 삭제 반례를 고친 v3도 여전히 관측 후보이며, 위의 신규성 관문을 대신하지 않는다. BadFU 내부 표본과 FUBA의 클라이언트 역할은 같은 모형에 놓인다. soft 반응은 비교군으로 둔다.
4. **확인:** 학습 이력에서 발견한 관계와 삭제 경계의 효과를 정상 대조·별도 입력·실제 FU 결과로 검증한다. 이 마지막 FU 실행은 평가 절차이며 장력 검출을 위해 먼저 수행하는 단계가 아니다.
5. **역할:** CCD의 학습 중 장력 관측을 발전시키는 것이 중심이다. TRACE·공동삭제·DOSE는 비교와 확인, 복구와 망각 검증은 별도 조치다. 장력 그 자체를 악의의 증명으로 쓰지는 않는다.
6. **현재 결론:** FUBA의 한 설정에서 추가 신호가 있지만 BadFU 변형에서 개선은 없다. 현재 증거는 연구 후보를 뒷받침하며 두 공격 계열의 공통 방어 성공을 입증하지 않는다.
