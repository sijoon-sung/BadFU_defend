## 0. 논문 한 줄
삭제로 깨어나는 백도어는 "서로 지우는 기여들"로 숨는다(모순 지도의 평균화). 이 상쇄 연합은 학습 중 장부에서 보이고, 처방은 요청자를 심판하는 것이 아니라 연합을 걷어내는 것이다.

## 1. 알고리즘 (두 단계로 줄임)
전에는 요청 시점에 DOSE(부분 제거) → TRACE(짝 찾기) → DEFUSE(해독제) → KD 재억제까지 네 단계였다. 지금은 탐지에서 얻은 정보(타깃 클래스, 위장자, 운반자 집합, 경보 라운드)를 그대로 처방에 쓴다.

```
학습 중, 매 라운드 t (서버):
  참여자 j 마다           P_j(c) += mean_x [ log p_c(x; θ_{t−1} + u_j^t) − log p_c(x; θ_{t−1}) ]     (공개 입력 500 장, 순전파 1 회)
  클래스 c 마다           H(c) = 1 − |Σ_j P_j(c)| / Σ_j |P_j(c)|
                          neg(c) = argmin_j P_j(c),  z_neg = MAD z,  Pos(c) = { j ≠ neg : z_j > 2 }
  공모(c)  ⇔  H(c) ≥ 0.8  ∧  z_neg ≤ −3  ∧  |Pos(c)| ≥ 2  ∧  Pos 중 한 명의 몫 ≤ 0.6
  경보     ⇔  같은 c 가 3 라운드 연속 공모   (t ≥ 5 부터 판정)
경보 시 (대응):
  연합 = {neg(c*)} ∪ Pos(c*).   t_back = 경보 전 H(c*) < 0.8 이었던 마지막 라운드.
  θ_{t_back} 로 되감고 연합을 제외한 채 남은 (T − t_back) 라운드를 이어 학습.   (저자 코드 그대로, 시작 모델과 제외 목록만 바꿈)
요청 시점 (이미 학습이 끝난 모델에 요청이 올 때):
  저장된 라운드별 갱신 위에 같은 장부를 사후 계산 → 같은 판정 → 연합 제외 재학습.
```
문턱값 (6 궤적에서 고정, 민감도는 R-013): h0 0.8, τ 3, κ 2, |Pos| ≥ 2, 몫 ≤ 0.6, 연속 3, 시작 5.
버린 단계: DEFUSE 해독제(논문 설정에서 실패, R-011), 요청 시점 DOSE 띠·TRACE 짝 찾기(장부가 같은 정보를 학습 중에 더 일찍 준다; 부록의 소거 실험으로만), KD 재억제(요청자 몫 10 % 가 되돌아옴, R-008; 비교 행으로만).

## 3. 결정: 정화는 이렇게 간다
1. **처방은 "연합 제외"로 통일한다.** 탐지가 준 목록(위장자 + 운반자)을 그대로 제외 목록으로 쓴다. 근거: 제외 재학습만이 ASR 0.5 와 정확도 99 를 동시에 준다(표 4). 재억제는 요청자 몫이 10 % 되돌아오고, 해독제는 실패했다.
2. **시점은 경보 즉시.** 요청이 올 때까지 기다리지 않는다. 경보가 13–14 라운드에 나므로 되감기 비용은 학습의 7–13 % 다. 되감기 없이 경보 라운드에서 바로 제외하고 이어 가는 변형은 R-014 에서 같이 잰다.
3. **요청 시점은 같은 장부의 사후 적용이다.** 새 절차가 아니다. 학습 로그만 있으면 같은 판정이 나오고(R-012 는 바로 그 사후 계산이다), 처방은 제외 재학습(R-010).
4. **버리는 것.** DOSE 띠·TRACE 짝 찾기·DEFUSE 해독제·KD 재억제는 본 알고리즘에서 뺀다. 부록에서 "왜 요청 시점 처방이 더 비싸고 약한가"의 소거 실험으로만 남긴다.
