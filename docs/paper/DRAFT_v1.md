# 초안 v1 (2026-10-12) — 상쇄 귀속: 삭제 요청이 깨우는 백도어를 요청자 데이터를 되살리지 않고 해제하기

(영문 제목 후보) **Cancellation Attribution: Defusing Unlearning-Activated Backdoors Without Un-forgetting**

이 초안은 "이대로 투고" 가 아니라 "지금 가진 것으로 쓰면 이렇게 된다" 를 보여 주기 위한 것이다. 마지막 절(§8)에 노벨티 자가 평가와 보강 방향을 적었다. 숫자는 REPORT_2026-10-12.md §13–15 (DISLAB 3 시드) 와 §14 (로컬 1 시드) 에서 가져왔다.

## 초록
연합 언러닝(FU)에서 클라이언트는 자기 데이터를 지워 달라고 요청할 수 있다. 최근 공격(FUBA, BadFU)은 이 권리를 역이용한다. 한 무리의 클라이언트가 백도어를 심고, 다른 클라이언트가 같은 입력에서 거꾸로 밀어 백도어를 잠재운 뒤, 자기 데이터를 지워 달라고 요청하면 백도어가 깨어난다. 학습 중에는 보이지 않으므로 학습 시 집계 방어는 실패하고, 요청 시 심사 방어는 수락/거부만 내며, 사후 복구(재억제·재학습)는 요청자의 기여를 다시 넣어 삭제 요청 자체를 어긴다.

우리는 이 공격을 **저장된 기여들 사이의 상쇄**로 정의하고, 삭제 요청을 "어디서, 누구의 기여를 요청자가 지우고 있었나"를 푸는 **귀속 문제**로 바꾼다. 서버는 저장된 기여와 요청만으로 목적식 하나를 교대 반복으로 풀어 (i) 상쇄가 사는 입력 ω, (ii) 짝 집합 S 와 가중치 w, (iii) 백도어 방향 h 를 얻고, 짝의 기여에서 그 방향 성분만 뺀다. 요청자의 기여는 건드리지 않으므로 삭제는 그대로 이행된다. 두 공격은 같은 반복의 수렴 회전만 다르다(BadFU 는 요청자가 넘긴 데이터 위에서, FUBA 는 요청자를 뺀 뒤 활성화된 입력 위에서 짝이 보인다). 정상 요청의 추가 비용은 순전파뿐이고 새 모델 생성은 없다.

MNIST(FUBA)·CIFAR-10(BadFU) 에서 3 시드 × IID/non-IID 로: 짝(운반자)을 정밀도·재현율 1.0 으로 찾고, 공격 성공률을 48 → 5 (IID), 54 → 11 (non-IID) 로 낮추며, 정확도는 재억제 방식과 0.6–1.1 점 차이, 요청자 기여의 재주입은 0 이다 (재억제는 0.16). 또한 매개변수 공간의 재주입이 0 이어도 기능 공간에서 잊은 것이 되돌아올 수 있음을 보이고, 이를 막는 증류 규칙을 제시한다.

## 1. 서론
- 배경: FU 와 삭제 권리. 요청을 들어주는 가장 싼 연산자는 저장된 기여를 빼는 것(FedEraser 류).
- 문제: 삭제 요청으로 활성화되는 백도어 (FUBA, BadFU). 공통 구조 = 상쇄. 학습 중 보이지 않음 → 집계 방어 무력. 요청 시 심사는 "지우면 나빠지나"만 답함. 복구는 요청자 기여를 되넣음.
- 긴장: **백도어 안전 vs. 삭제 이행**. 기존 해법은 하나를 얻기 위해 하나를 버린다. 거절 = 삭제 불이행, 재억제 = 삭제 되돌림.
- 우리 질문: 요청자의 기여를 되살리지 않고 백도어를 해제할 수 있는가? 답: 가능하다, 단 **누가 심었는지**를 알아야 한다. 그래서 탐지가 아니라 귀속이다.
- 기여 (아래 §1.1).

### 1.1 기여
1. **정의**: 삭제 요청 활성화 백도어 = 저장된 기여의 상쇄 J_{X*}(U_k + Σ_{j∈S} w_j U_j) ≈ 0. FUBA·BadFU 와 그 변형(다중 억제자, 조각 요청)을 한 식으로. (THREAT_MODEL.md)
2. **귀속 문제와 풀이**: 목적식 max_{ω,S,w} Σ_x ω(x)[‖Ẽ_k[x]‖² − ‖Ẽ_k[x] + Σ w_j Ẽ_j[x]‖²] 와 교대 반복. 기능 효과 Ẽ_j 는 유한차분 한 번으로 얻는 선형화. 모델 생성 없이 그램 행렬 위에서 푼다.
3. **짝은 어디서 보이는가**: 상쇄는 X* 위에서만 보인다. 요청자가 넘긴 데이터가 X* 를 담으면(BadFU) 저장 기여만으로 끝나고, 아니면(FUBA) 요청자를 뺀 뒤 활성화된 입력에서만 보인다. 깨끗한 입력에서는 무리 구조만 보여 정상도 운반자와 "상쇄"된다 — 저장 기여만 보는 탐지기가 실패하는 이유.
4. **망각 보존 정화**: 짝의 기여에서 활성화 방향 성분만 제거. 재주입 α = 0. 그리고 α=0 이 망각의 충분조건이 아님을 보이고(교사가 요청자 지식을 담으면 기능 공간에서 되돌아옴), "요청자를 빼도 답이 안 바뀐 입력에서만" 증류하는 규칙으로 막는다.
5. **비용**: 가상 제거 모델은 요청자와 무관하므로 모델 버전당 K 개를 공유. 요청당 새 모델 0, 순전파 O(K).

## 2. 위협 모델 (THREAT_MODEL.md 요약)
- 서버: 라운드별 기여 U_j^t 저장(FedEraser 류 FU 의 전제), 최종 모델 θ_T, 공개 입력 X_p (라벨 불필요). 라벨·트리거·역할 모름.
- 공격자: 운반자 집합 A 와 억제자(요청자) k. 학습 중 J_{X*}(U_k + Σ_A w_j U_j) ≈ 0 이 되게 공모. k 가 삭제를 요청. 변형: 억제자 여러 명(순차 요청), 요청 조각내기, 미끼 요청, 운반자 분산.
- 요청자가 넘기는 것: 지울 데이터 X_f (FU 규약상 서버가 받는 것; BadFU 에서는 트리거 그림).
- 방어 목표: (P1) 정상 요청은 기본 FU 와 같게, (P4) 요청자 기여를 되살리지 않고, 백도어가 깨어나지 않게. 출력에 귀속(짝·타깃·입력)을 포함.

## 3. 방법 (METHOD.md v3)
### 3.1 기능 효과와 중심화
E_j = [f(X; θ−εU_j) − f(X; θ)]/ε (N×C). 원시 E_j 는 모두 평행(코사인 0.9+; 누구를 빼도 생기는 일반 열화)이므로 중앙값을 빼 Ẽ_j 로.
### 3.2 목적식과 교대 반복
(§1.1-2). ω 고정 → (S,w) 는 그램 행렬 위 전진 선택 + 상자 제약 최소제곱. (S,w) 고정 → ω 는 상쇄 에너지 양수 입력.
### 3.3 절차
회전 1 (θ_T, ω⁰ = X_p ∪ X_f): 짝 S¹, 타깃, "어디서" 비율, 통계 네 개(상쇄·타깃 몰림·크기·라운드 반대 정렬) 의 conformal p 와 z.
빼 보기 (비선형 확인): θ' = θ_T − ρU_k, 남들을 같은 양 뺀 모집단의 LOO 중앙값 기준과 flow 통계 z. 활성화 입력 X_act, 타깃 c*.
회전 2 (θ', ω¹ = X_act, 타깃 열): 정렬 ⟨활성화, 후보 효과⟩, 가장 큰 간격 규칙으로 S². (회전 3+: 에너지 정련.)
정화: h = ∇ mean_{X_act} log p(c*|x; θ'), θ'' = θ' − λ Σ_{S²} proj_h(U_j), λ 는 띠 안 최소, 건강 = 비활성 입력 불변. 선택: U_k 직교 증류, 입력은 요청자 제거로 답이 안 바뀐 것만.
### 3.4 성질
P1 정상 = 기본 FU. P4 α≈0. P5 귀속 출력. 비용 표 (METHOD §6).

## 8. 노벨티 자가 평가 — 리뷰어가 뭐라고 할까
### 8.1 약한 곳 (솔직하게)
- "짝을 찾고, 빼 보고, 빼 준다"는 **각 부품이 다 알려진 도구**다. 빼 보기 = 언러닝 시뮬레이션 후 검증(요청 심사 논문들), 짝 찾기 = 비음수 최소제곱/코사인 귀속, 정화 = 작업 산술의 투영 제거. 부품 수준의 새로움은 없다.
- 평가가 좁다: MNIST K=8, CIFAR K=6, 공격 각 1 개, 3 시드.
- "하나의 목적식"은 포장이다. 실제로 회전 3+ 는 결과를 안 바꾼다. 리뷰어는 "두 공격을 두 휴리스틱으로 푼 것"으로 읽을 수 있다.

### 8.2 진짜로 새로운 것 (이걸 앞세워야 한다)
1. **문제 재정의**: 삭제 요청 활성화 백도어 방어를 "수락/거부"가 아니라 "귀속" 문제로. 출력이 모델 + 짝·타깃·입력. 이 틀은 FU 문헌에 없다 (POSITIONING.md 로 확인).
2. **망각 보존 해제**: 백도어 안전과 삭제 이행을 동시에. 기존 해법은 둘 중 하나를 버린다. 여기에 "α=0 이어도 기능 공간에서 되돌아온다"는 부정 결과와 그 처방이 붙는다. 이건 측정 지표 자체에 대한 기여다.
3. **짝은 어디서 보이는가**: 저장 기여만 보는 방법이 왜 실패하는지(무리 구조, 잠든 백도어)와 언제 성공하는지(X* 가 요청 데이터에 있을 때)를 분리한 경험적 결과. 식별 가능성 조건으로 쓸 수 있다.

### 8.3 보강하면 노벨티가 서는 세 가지 (우선순위 순)
1. **식별 가능성 명제** (이론, 실험 아님): 선형화 모델에서 "ω 의 지지집합이 X* 를 덮고, 짝의 효과가 X* 위에서 서로 독립이면 목적식의 해가 S = A 를 돌려준다"를 명제로 쓰고, 덮지 않으면 실패함(깨끗한 입력 위 FUBA)을 따름정리로. 회전 1 → 2 가 "덮을 때까지 ω 를 키우는 절차"가 된다. 이러면 두 회전이 휴리스틱이 아니라 명제의 조건을 만족시키는 단계다.
2. **공격자 비용 분석**: 이 방어를 피하려면 억제자가 여러 명으로 분산하거나 미끼를 써야 한다. 그 경우 (a) 억제 몫이 줄어 백도어가 학습 중에 새거나, (b) 순차 요청이 "정상 n 명 제거" 띠에 걸린다. 공격자의 회피 비용 곡선 하나(억제자 수 vs 학습 중 ASR 누출 vs 탐지율)를 그리면 "결국 공격자가 잃는다"는 주장이 된다. 적응형 실험 코드(attack_sim)로 가능.
3. **K=20, 공격자 20 %, 데이터셋 하나 추가**: conformal p 가 의미를 갖고, 소유자 혼동이 희석된다. 지금 약점의 절반이 여기서 풀린다.

### 8.4 쓰지 말아야 할 주장
- "하나의 목적식으로 모든 공격을 통합" — 회전 3+ 가 안 바뀌는 한 과장이다. "같은 반복, 다른 수렴 회전" 까지만.
- "학습 없음" — 직교 증류 50 걸음은 학습이다. "재학습 없음, 클라이언트 재참여 없음" 으로.
