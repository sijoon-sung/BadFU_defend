# 원점 분석: 공격 구조의 허점과 돌파 제안 (2026-10-12)

전제 하나를 바꾼다. **방어가 그냥 언러닝보다 싸지 않아도 된다.** 분명한 장점(안전, 정확한 결과, 책임 귀속)이 있으면 된다. 지금까지 "순전파만으로"에 묶여 버린 선택지를 다시 연다.
용어: 운반자 A (심는 쪽), 위장자 S (눌러 숨기고 삭제를 요청하는 쪽), X\* 트리거 입력, U_j^t 라운드 t 의 저장 기여, θ_t 라운드 t 전역 모델.

## 1. 공격의 구조를 식으로
학습: θ_t = θ_{t−1} + Σ_{j∈P_t} U_j^t  (P_t = 그 라운드 참여자, 논문 설정은 8/20).
공격의 평형 (FUBA 의 줄다리기): 모든 t 에 대해
```
J_{X*}( Σ_{s≤t, j∈A} U_j^s + Σ_{s≤t} U_S^s ) ≈ 0 ,     J_{X*} Σ_{s≤t, j∈A} U_j^s ≫ 0          … (E)
```
삭제: θ_T − U_S 에서 (E) 의 둘째 항이 사라져 첫째 항(백도어)이 드러난다.
S 가 매 라운드 해야 하는 일: 자기가 재현한 공격자 모델과 정상 미세조정의 차이 M_{j,E} − M^{attacker} 를 제출 (FUBA Alg. 2). 즉 **S 의 갱신은 A 의 누적 주입을 아는 벡터**다.

## 2. 피할 수 없는 성질 다섯 (각각 로그 근거)
| | 성질 | 왜 피할 수 없나 | 로그 |
|---|---|---|---|
| P-a | **부분합은 활성 상태다.** 잠복은 전체 합에서만 성립한다. S 를 뺀 어떤 부분합도 (E) 의 첫째 항이 남는다 | 공격의 정의 자체 | K=8: θ_T − U_S 에서 보통 이미지 25 % 가 타깃으로, ASR 63. K=20: ρ=0.2 만 빼도 ASR 46–93 |
| P-b | **S 의 기여는 크고, 깨끗한 입력으로 샌다.** A 넷의 주입을 혼자 상쇄하려면 크기가 |A| 에 비례한다. 억제는 트리거에만 정확히 맞출 수 없어 X_p 로 샌다 | 상쇄 벡터의 크기와 일반화 | 갱신 노름 3.6 배, 총노출 몫 32 %, Krum 점수 18 배; 깨끗한 입력에서 몰림 z 4–6 |
| P-c | **운반자는 혼자서는 무해하고, 함께만 필요하다.** 하나를 빼도 ASR 변화 없음(0.2–1.4), 활성화된 모델에서는 운반자만 활성화를 줄인다 | 백도어가 네 몫의 합 | 단일 운반자 제거 ASR ≤ 1.4; 활성화 입력 정렬 운반자 −0.9 / 정상 +0.7 |
| P-d | **평형은 시간 위에서 유지돼야 한다.** S 가 없는 라운드(참여 0.4 → 60 %)에는 A 의 주입이 그대로 들어간다. S 는 다음 참여 때 밀린 만큼 더 눌러야 한다 | 참여 무작위성 | 잠복 ASR 3–8 (평균은 낮음). 라운드별 요동은 **아직 안 잼** — 아래 M3 |
| P-e | **S 는 반드시 떠나야 한다.** 요청 자체가 공격의 방아쇠다 | 활성화 조건 | 요청 시점 DOSE z 4.5–13 (K=8), K=20 은 2 단계에서 |

이 다섯이 허점이다. 공격 논문이 시험한 방어 열 종은 전부 "갱신 하나 점수" 또는 "전체 합 검사"라서 P-a·c·d 를 쓰지 않는다.

## 3. 돌파 제안 (비용 제한 없이, 장점 순)

### M1. 공모 인지 언러닝 — 찾아서 **빼고 다시 학습한다** (정답에 도달)
```
1) DOSE: 요청 (S, X_f) 에 대해 부분 제거 θ_T − ρU_S 로 활성화 확인 (ρ=0.2, K 순전파)
2) TRACE: 활성화 입력 위 정렬로 A 추정 (K−1 순전파), conformal p ≤ 0.05 (K=20)
3) 제외 후 재학습: 서버가 FU 를 "S ∪ A 제외" 로 수행 — FedEraser 보정(남은 정직 클라 재참여) 또는 처음부터 재학습
4) A 는 영구 제외(책임 귀속), 증거 기록 (X_act, c*, h, 정렬표)
```
- 장점: **정답 모델**. 우리 K=8 로그에서 정상 재학습(retrain_benign)은 ASR 0.8, ACC 97.6 — 어떤 정화(ASR 9, ACC 91)보다 좋다. 삭제는 그대로 이행(요청자 데이터 없음), 백도어는 심은 쪽을 빼서 없앰.
- 비용: 재학습 한 번 (FedEraser 보정이면 라운드 수의 일부). "그냥 언러닝"보다 비싸지만, FedEraser·재학습은 이미 표준 FU 비용이다. **차이는 '누구를 빼는가'뿐이다.**
- 위험: TRACE 정밀도 (owner 0.87). 정상을 잘못 빼면 그 클라의 데이터 영향이 사라진다 → (i) K=20 conformal p 로 제한, (ii) 제외 전 확인: θ_T − ρU_S − Σ_A proj_h(U_j) 가 띠 안으로 돌아오는가 (DEFUSE 를 '확인 단계'로 씀), (iii) 재학습 뒤 ASR·자기 데이터 acc 보고.
- 왜 기존과 다른가: 요청 심사(거절), 재억제(되넣기), 사후 정화(방향만)와 달리 **원인(심은 기여)을 제거**한다. 재학습이 백도어 모델을 내는 이유는 운반자가 남아서였고(§2 문서), 그걸 고친다.
- 시험: k20_paper 6 궤적에서 cancel 로 A 를 얻고, benign_departure 의 재학습을 "S ∪ A 제외" 로 한 번 더 (retrain_benign 에 `--exclude` 추가, 저자 코드 그대로). 비교: 빼기 / 재억제 / 해독제 / **제외 재학습** / 서버 clean 미세조정(FUBA Table VIII).

### M2. 학습 중 부분합 감사 — 요청이 오기 전에 잡는다
P-a 를 학습 중에 쓴다. τ 라운드마다 (예: 10) 저장 기여로 "한 명 뺀 모델" K 개를 만들어 flow 통계의 모집단 z 를 본다 (DOSE 와 같은 계산, 모델 버전당 K 순전파).
```
매 τ 라운드:  z_j(t) = z( a(θ_t − ρ U_j^{≤t}) ; {a(θ_t − ρ U_i^{≤t})}_{i≠j} ),   ρ = 0.2
경보 ⇔ max_j z_j(t) > τ_a (또는 conformal p ≤ 0.05)  → 그 j 가 S, TRACE 로 A
```
- 장점: 요청 전에 공모를 안다. 요청 시점 적응형(쪼개기, 미끼, 순차 위장자)이 전부 무력해진다 — 요청이 아니라 **학습 궤적**을 검사하므로. 집계 방어가 못 보는 것(P-a)을 본다.
- 비용: τ 라운드마다 K 순전파 (학습 비용의 1 % 미만).
- 위험: 초반 라운드엔 백도어가 덜 심어져 신호가 약함 → 시간에 따라 z_S(t) 가 커지는 곡선 자체가 증거.
- 시험: k20_paper 의 라운드별 전역 모델이 전부 저장돼 있다 (`global_net_model_*_round_t.pkl`). t = 20, 40, 60, 80, 100 에서 위 z 를 계산 (새 스크립트 `audit_training.py`, 학습 없음, 궤적당 수 분).

### M3. 참여 무작위성 = 자연 실험 — 제거 없이 S 와 A 를 본다
P-d 를 쓴다. 라운드 t 의 전역 모델 변화에서 타깃 몰림 d_t = flow(θ_t vs θ_{t−1}; X_p) 를 재고, 참여 지표 I_{j,t} ∈ {0,1} 로 회귀한다.
```
d_t = β_0 + Σ_j β_j I_{j,t} + ε_t        (100 라운드 × 20 클라, 라운드당 8 명 참여)
예측: β_S < 0 (S 가 있으면 몰림이 줄고), β_A > 0 (A 가 있으면 늘고), β_정상 ≈ 0
```
- 장점: **제거를 아예 안 한다.** 저장된 전역 모델과 참여 명단만으로. 학습 중에도 계산 가능 (M2 보다 싸다). 여러 위장자(sup2)도 각자 β < 0 으로 나온다.
- 비용: 100 순전파 (라운드마다 하나) + 회귀.
- 위험: 신호가 작을 수 있다 (라운드당 주입이 작음). 몰림 대신 타깃 클래스 로짓 평균 변화 Δℓ_t(c) 를 쓰고 c 를 모르면 모든 c 에 대해 회귀해 최대 |β| 를 취한다 (c* 도 같이 나온다).
- 시험: k20_paper 6 궤적 (참여 0.4 이므로 가능; K=8 전원 참여 궤적에서는 불가능). 참여 명단은 로컬 모델이 전역과 같은지로 복원된다 (검증기가 이미 그렇게 센다).

### M4. 붕괴 없는 제거 연산자 (요청을 그대로 이행해야 할 때)
M1 이 재학습을 못 쓰는 상황(클라이언트 재참여 불가)의 대안. 둘 중 하나:
- 역순 단계 제거: θ − Σ_{t∈최근 m} U_S^t (덮이지 않은 최근 조각부터). m 은 건강 상한으로.
- 기능 공간 제거: 목표 로짓 f(x;θ_T) − ρE_S(x) 를 50 걸음 맞춤 (교사에 S 의 지식 없음).
둘 다 PROPOSALS_K20.md 1·2 절. 전량 빼기 붕괴(K=20 로그)의 직접 대책.

### M5. 판정은 p 값으로, 짝은 단계 일관성으로 (K=20 전용 정밀화)
PROPOSALS_K20.md 3·4 절. M1·M2 의 오탐을 수치로 묶는 장치.

### M6. 출력 = 감사 기록 (책임 귀속)
어느 제안이든 서버가 내는 것은 모델만이 아니라 (S, A, c\*, X_act, 정렬표, 라운드별 z 곡선). 공격 논문의 "서버는 구별 불가" 주장에 대한 직접 반박이고, 클라이언트 제외(ban)의 근거가 된다.

## 4. 논문 줄거리 (M1 + M2 를 축으로)
1. 잠복 백도어는 전체 합에서만 잠복한다 (P-a). 부분합을 보면 깨어난다 — 학습 중이든(M2) 요청 시점이든(DOSE).
2. 깨어난 입력 위에서 누가 줄이는지 보면 운반자가 나온다 (P-c, TRACE).
3. 그러면 올바른 처방은 정화가 아니라 **운반자를 빼고 다시 학습하는 것**이다 (M1). 재학습이 백도어 모델을 내던 이유가 바로 운반자가 남아서였다.
4. 비용은 재학습 한 번. 그 대신 ASR ≈ 1, ACC ≈ 98 (정답), 삭제 이행, 책임 귀속. 기존 방법은 셋 중 하나도 못 가진다.
5. 정화(DEFUSE)는 재학습이 불가능할 때의 저가 대안으로 한 절.
