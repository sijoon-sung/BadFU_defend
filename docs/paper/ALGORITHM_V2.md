# 알고리즘 v2: 상쇄 구조에서 나온 수락·정화 절차 (2026-10-12)

지금까지의 이야기를 하나로 다시 짠 것. 중심은 두 공격의 **공통 부분**이고, 궤적 지표와 빼 보기는 서로 보완한다.

## 0. 공통 부분 (THREAT_MODEL.md 2 절)
심는 사람 A 와 억누르는 사람 S. 트리거 입력 X* 에서 S 의 몫이 A 의 몫을 거꾸로 민다 (J_X*(U_A + U_S) ≈ 0, J_X* U_S ≠ 0). S 가 빠지면 깨어난다.
방어가 쓰는 세 가지 사실:
1. 상쇄는 몫 하나로는 안 보이고, S 의 몫을 **빼야** 보인다 → 요청 시점에 본다.
2. 깨어나는 자리는 X* 이고, X* 는 공개 입력에 새거나(FUBA) 지울 입력 안에 있다(BadFU) → 보는 입력 = 공개 ∪ 지울 입력.
3. S 의 몫은 "무엇을 거꾸로 밀었는지"의 증거다 → A 를 찾고, A 의 몫 중 그 부분만 뺀다.

## 1. 입력·출력
입력: {U_j^t} (저장 몫), θ_T, 요청 (k, X_f), 공개 입력 X_p. 라벨·트리거·역할 정보 없음.
출력: 수락(θ' = R(θ_T,k) 그대로) / 정화 후 수락(θ'') / 거부(판단 불가·정화 실패). 그리고 기록(z, A, α, 단계).

## 2. 절차 (3 단계)

### A. 거름망 — 궤적 지표 (역전파 10 회, 모델 생성 없음)
```
X ← X_p ∪ X_f ; ŷ(x) ← argmax θ_T(x)                       # 가짜 라벨
g_c ← ∇_θ mean CE(θ_T; {x : ŷ(x)=c})  (c = 1..C)
v_j^t ← (⟨U_j^t, g_c⟩)_c   for all j, t ;  v_j ← Σ_t v_j^t
지표(k):  mag = ‖v_k‖,  consist = mean_t cos(v_k^t, v_k),  spread = |mean_c sign v_k[c]|,  partner = min_j cos(v_k, v_j)
각 지표를 모집단 {v_j} 에서 z 로. 문턱은 LOO 보정(멤버 각자의 z 최댓값 + 1).
suspect ← (mag 또는 consist 가 문턱 초과)  OR  (X_f 위에서 spread 또는 partner 가 문턱 초과)
```
- FUBA 류는 mag·consist 에서, BadFU 류는 X_f 위의 spread·partner 에서 걸린다 (로컬 1 시드 확인; BadFU 는 방향만 맞고 K=6 에서 문턱 미달 → 거름망은 보수적으로, 놓치면 B 가 잡는다).
- suspect 가 아니면 **수락**: θ' = R(θ_T, k). 기본 FU 와 동일 (P1). 비용 끝.

### B. 확정 — 빼 보기 (걸린 요청만)
```
X_eval ← (X_p ∪ X_f) \ Own(k)                                # 요청자 '소유' 클래스 입력 제외 (정의 2 의 '남들 입력')
   Own(k) = { c : share_k(c) > 2·median_c share_k(c) },  share_k(c) = ⟨U_k, −g_c⟩ / Σ_j ⟨U_j, −g_c⟩  (클래스 c 손실 감소 기여 비율)
θ' ← R(θ_T, k, δ)  (δ: 모두가 견디는 양; 멀쩡하면 1)
P ← { R(θ_T, j, δ) : j ≠ k, 건강 }, ref ← median-ensemble(P), s_j ← a(P_j ; ref_{-j}),  a = X_eval 위 '한 클래스로 몰린 양'
z ← (a(θ';ref) − median s_j) / std s_j
z ≤ τ → 수락(θ').   z > τ → C 로.   무너짐(모두 비건강) → 거부.
```
- Own(k) 규칙은 non-IID 소유자 오탐(3 시드 중 2)을 겨냥한 **가설**이다. 소유자는 자기 클래스에만 share 가 높고, FUBA 억제자는 모든 클래스에 고르게 높아(IID) 아무 것도 제외되지 않으며, BadFU 위장자는 자기 깨끗한 데이터 클래스만 제외되고 트리거 입력(다른 클래스)은 남는다. **미검증** — owner 궤적(DISLAB)에서 확인해야 한다.

### C. 정화 — 해독제 방향 (공통 부분 3 에서)
```
c* ← θ' 에서 답이 몰린 클래스 ;  X_act ← { x ∈ X_eval : θ'(x) = c* ≠ ref(x) }
A ← 지도 순위 선택: Δ_j = a(θ') − a(θ' − U_j) 양수 순으로 z ≤ τ 까지 (pair_roles ranked)
h ← ∇_θ mean_{x∈X_act} log p(c* | x ; θ')                    # 백도어가 미는 방향
U_j^∥ ← (⟨U_j, h⟩/‖h‖²) h   (j ∈ A)
θ'' ← θ' − λ Σ_{j∈A} U_j^∥ ,  λ 를 작은 값부터 올려 z ≤ τ 가 되는 첫 값 (θ' 대비 변화 ≤ c 이면)
실패(λ 상한까지 z > τ 또는 무너짐) → 운반자 통째 제거 θ' − Σ_A U_j 로 대체, 그래도 실패 → 거부
```
- U_k 를 되살리지 않는다. 빼는 것은 **운반자 몫의 h 성분**뿐. α = ⟨θ''−θ', U_k⟩/‖U_k‖² 를 함께 보고한다 (h 가 U_k 와 반대로 정렬돼 있으면 α > 0 일 수 있다. 그래도 빠지는 것은 운반자의 몫이지 요청자 몫의 복원이 아니다 — 이 구분을 표로 보인다: '운반자 몫 중 뺀 비율' 열).
- 비교 팔: 요청만 / 운반자 통째 제거 / 재억제 수정(KD) / 해독제(λ). 코드: `FUBA/antidote.py`.

### D. 순차 요청
한 클라의 조각 요청은 누적 장부, 여러 클라의 순차 요청은 "정상 n 명 제거" 띠(schedule_fu). 변경 없음.

## 3. 성질
- P1 정상 요청 = 기본 FU (A 에서 통과하거나 B 에서 z ≤ τ 면 손대지 않음).
- P2 무너진 모델 불출.
- P3 내보낸 모델은 X_eval 에서 모집단 띠 안.
- P4 정화는 요청자 몫을 되살리는 대신 운반자 몫의 백도어 성분을 뺀다 (재우기 → 지우기).
- 비용: A 는 역전파 C 회 + K·T 내적. B 는 걸린 요청만 K 모델. C 는 기울기 1 회 + |A| 투영.

## 5. 바로 확인할 것 (실험 아님, 코드 검사 수준)
