# 원점 검토 (2026-10-12)

포장 없이, 처음부터. 쉬운 말로. 숫자는 REPORT_2026-10-12.md 에서 가져왔다.

## 1. 문제 (세 문장)
연합학습에서 클라이언트는 "내 데이터를 지워 달라"고 요청할 수 있다 (연합 언러닝). BadFU·FUBA 는 이 권리를 공격에 쓴다: 몇 명(**운반자**)이 백도어를 심고, 한 명(**위장자**)이 그 백도어를 눌러서 안 보이게 한 뒤, 위장자가 자기 데이터를 지워 달라고 하면 백도어가 살아난다. 서버는 요청을 들어주면 공격당하고, 안 들어주면 법(잊힐 권리)을 어긴다.

## 2. 원점에서 보이는 사실 하나 (논문의 출발점)
**요청을 "정확히" 들어줘도 백도어는 살아난다.** 위장자 데이터 없이 처음부터 다시 학습해도(가장 정확한 언러닝) 운반자들의 독 데이터는 그대로 있으므로 백도어가 든 모델이 나온다 (BadFU 논문의 재학습 결과가 그것이다).
따라서 "언러닝을 더 정확히 하는 것"은 답이 아니다. 서버는 **삭제와는 별개로 운반자들을 찾아서 백도어를 걷어내야 한다.** 그리고 찾으려면 "누가 위장자와 짝이었나"를 알아야 한다. 이게 우리가 하는 일이고, 억지가 아니라 문제 구조에서 강제되는 일이다.

기존 방법이 왜 안 되는지도 여기서 나온다:
- 요청 거절 → 잊힐 권리 위반.
- 다시 눌러 놓기(재억제 KD) → 지운 데이터의 영향을 다시 넣는다 (우리 측정: 재주입 0.16).
- 학습 중 집계 방어 → 위장자가 있는 동안 백도어가 안 보여서 못 잡는다.
- 사후 정화(INFOCOM SVD, null-space 게이트) → 누구 것을 지워야 하는지 모르고 방향만 찾는다. 우리 데이터에서 게이트는 ASR 63 → 61 (못 막음).

## 3. 우리가 하는 일 (쉬운 말, 네 단계)
1. **조금씩 빼 본다 (DOSE).** 위장자의 몫을 한 번에 다 빼지 않고 모델이 견디는 만큼 뺀다. 뺄 때마다 "다른 클라이언트를 같은 양 뺐을 때"와 비교해서, 유독 이상하게 변하면 멈춘다.
2. **누가 짝인지 찾는다 (TRACE).** 이상이 나타난 입력들 위에서 "누구를 더 빼면 이상이 사라지나"를 계산한다. 그 사람들이 운반자다.
3. **운반자 몫에서 백도어 부분만 걷어낸다 (DEFUSE).** 위장자 몫은 되돌리지 않는다. 삭제는 그대로 이행된다.
4. 이상이 없으면 그냥 빼 준다. 정상 요청은 기본 언러닝과 똑같고 추가로 만드는 모델이 없다.

## 4. "깨끗한 입력의 1/4 이 타깃" 이 무슨 말인가
위장자를 빼면, **트리거가 없는 보통 시험 이미지** 1,000 장 중 약 250 장이 백도어의 타깃 클래스(8)로 분류된다. 즉 백도어가 깨어날 때 트리거 이미지만 망가지는 게 아니라 보통 이미지도 같이 망가진다. 그래서 서버가 트리거를 몰라도 보통 이미지만 넣어 보면 깨어난 것을 알 수 있다. 이것이 DOSE 가 잡는 신호다. (3 시드 × 2 조건 모두에서 그렇다. 정확도도 95 → 79 로 떨어진다.)

## 7. 판정 (단호하게)
**논문은 쓸 수 있다.** 이유: 주장 1–8 이 3 시드로 서 있고, 출발점(§2) 이 억지가 아니라 공격의 정의에서 나온다. "삭제를 이행하면서 백도어를 걷어내는 요청 시점 방어"는 우리가 아는 한 처음이다 (INFOCOM 2026 SVD 정화와는 '누구 것을 걷어내는가'에서 다르다).

**어느 급인가.** 지금 상태(MNIST K=8, CIFAR 1 시드, 적응형 3 종 뚫림)로는 **중위권 보안 학회 또는 보안 저널(TIFS/TDSC 급)** 논문이다. 상위 학회(S&P/CCS/USENIX/NeurIPS)로 가려면 아래 둘이 더 필요하고, 둘 다 포장이 아니라 **실험**이다:
1. K=20 (공격자 20 %) + 두 번째 데이터셋 (FUBA 를 CIFAR 로) + BadFU 3 시드.
2. 적응형 3 종(위장자 분산·미끼·운반자 분산)을 막거나, 못 막으면 왜 못 막는지(조건)를 쓰기.

**못 쓰는 경우는 하나다.** 2 번에서 "위장자를 둘로 나누면 끝"이 사실로 확인되고 막을 방법이 없으면, 요청 시점 방어 논문은 못 쓴다. 그때는 그 사실 자체(요청 시점 방어의 한계)가 논문이 된다. 이것도 실험이 결정한다.
