# 요청 조건부 공동삭제 검증: 수학적 정의와 주장 범위

2026-10-13. 구현: `FUBA/paired_audit.py`, 통합: `FUBA/structural_guard.py`.
새 논문 원고는 `draft_v6.tex`다. 기존 CCD·DOSE·TRACE는 재사용한다.
아래는 **제안 알고리즘의 정확한 명세**이며, 모든 잠복 공격에 대한 탐지 보장이 아니다.

## 1. 삭제 단위와 연산자

삭제 단위를 클라이언트에 고정하지 않는다. 서로 겹치지 않는 데이터 묶음의 집합을
\(\mathcal U=\{1,\dots,K\}\), 누적 삭제 비율을 \(r\in[0,1]^K\)로 둔다.
FUBA에서는 클라이언트, 원래 BadFU에서는 같은 클라이언트 내 camouflage 묶음이 될 수 있다.
같은 클라이언트 안의 두 묶음을 구별하려면 그 단위의 실제 FU 연산자가 필요하다.
클라이언트 업데이트만 저장한 경우 이 구별을 계산할 수 있다는 주장은 하지 않는다.

\[
 M(r)=\mathcal R(\theta_0,\mathcal H,r;\xi),\qquad M(0)=\theta_0.
\]

\(\mathcal H\)는 학습 기록, \(\xi\)는 고정한 난수/학습 조건이다.
모든 비교는 같은 연산자·기준 모델·난수 규약을 쓴다.
현재 체크포인트 어댑터는
\(M(r)=\theta_0-\sum_jr_jU_j\)인 **근사 감산**이다.
가중치와 참여 기록을 반영한 \(U_j\)도 후속 학습의 비선형 의존성을 정확히 제거하지 않는다.
FedEraser/재학습은 교체 가능한 연산자이며, 현재 실험은 그 연산자까지 검증한 결과가 아니다.

연속 요청 \(\delta_t\)는 \(r_t=r_{t-1}+\delta_t\)로 누적한다.
부분 삭제 이후 모델로 기준을 재설정하지 않는다. 재학습으로 모델을 교체하면
새 학습 기록과 비교군을 구성한 뒤 다시 감사를 시작한다.

## 2. 네 개의 실제 개입 모델

요청 벡터 \(r\)의 지지집합을 \(S\), 추정 상대 벡터를 \(a\)라 하자.
\(\mathrm{supp}(a)\cap S=\varnothing\), \(0\le a_j\le1\).
다음 네 모델을 실제로 계산한다.

\[
 M_0=M(0),\quad M_S=M(r),\quad M_A=M(a),\quad M_{SA}=M(r+a).
\]

상대 \(A\)는 **공격자 정답이 아니라 기능 변화의 설명 후보**다.
주어진 모델이 예측하는 확률 \(p\)에 대해 클래스 중심화 로그확률을 사용한다.

\[
 \psi_c(p)=\log\max(p_c,\epsilon)-\frac1C\sum_d\log\max(p_d,\epsilon),
 \quad \epsilon=10^{-7}.
\]

클리핑이 작동하지 않으면 softmax 로짓의 공통 상수에 불변이고,
\(\psi(\mathrm{softmax}(z))=z-\bar z\mathbf1\)이다.
입력×클래스 행렬을 유지한다. 클래스 평균으로 압축하면 입력별 반대 변화가 지워질 수 있다.
클리핑된 확률 비율을 결과에 기록한다. 극단적 확률에서는 아래 가법성 해석이 근사다.

뷰 \(v\in\{\mathrm{public},\mathrm{request}\}\)마다
\[
 D_B^v=[\psi(p_{M_B}(x))-\psi(p_{M_0}(x))]_{x\in X_v},
 \quad B\in\{S,A,SA\}.
\]
요청 뷰는 삭제 대상에서 정당하게 관측 가능한 입력이며 트리거 정답으로 대체하지 않는다.
서버가 원시 입력을 볼 수 없으면 신뢰 가능한 분산 질의 등 별도 구현이 필요하다.
입력 약정 검증·secure aggregation 지원은 현재 구현 범위 밖이다.

## 3. TRACE 선택과 별도 입력에서의 확인

각 뷰를 선택용 \(X_v^d\)와 확인용 \(X_v^h\)로 한 번 분할한다.
선택 후 집합·가중치·문턱을 확인용 입력에 맞춰 다시 최적화하지 않는다.
원시 데이터의 독립성까지 보장하는 분할은 아니므로 이것만으로 통계 검정이 성립하지 않는다.

\(\rho=\max_jr_j\), \(E_j=D^d(\rho e_j)\)라 하면 기존 TRACE의 전진 선택과 box-NNLS를 재사용한다.

\[
 (\hat A,\hat w)\approx\arg\min_{|A|\le m,\ 0\le w_j\le1/\rho}
 \left\|D_S^d+\sum_{j\in A}w_jE_j\right\|^2,
 \qquad \hat a_j=\rho\hat w_j.
\]

기본 \(m=5\), 단계별 최소 상대 개선 0.01. \(m\)은 계산 예산이지 공격자 수가 아니다.
뷰별로 입력·클래스 수의 제곱근으로 나눈 뒤 연결하여 큰 뷰가 작은 뷰를 압도하지 않게 한다.
전진 선택은 전역 최적화를 보장하지 않는다.

**추가한 부분:** 선형 합으로 예측한 복원을 그대로 채택하지 않고,
고정한 \(\hat a\)로 \(M_A,M_{SA}\)를 실제 계산하여 \(X^h\)에서 확인한다.
확인용 에너지를 \(E_B=\|D_B^h\|^2\)라 하자. 여기서 노름 제곱은 원소별 제곱의 평균이다.

\[
 C_{S,A}=\frac{E_S+E_A-E_{SA}}{E_S+E_A},\qquad
 R_{S,A}=1-\frac{E_{SA}}{E_S}.
\]

구현은 분모를 \(10^{-12}\) 이상으로 두며, 요청 에너지가 \(10^{-6}\) 이하이면
구조 확인으로 취급하지 않는다. \(C\)는 상대·요청 에너지 대비 공동 잔차,
\(R\)은 요청만 삭제한 변화가 공동 삭제로 얼마나 줄었는지를 뜻한다.
두 값이 높아도 백도어가 제거됐거나 삭제를 완료했다는 뜻은 아니다.

## 4. 성립하는 명제

### 명제 1: 가법 효과에서의 반대 정렬

\(E_S+E_A>0\), \(D_{SA}=D_S+D_A\)이면
\[
 C_{S,A}=\frac{-2\langle D_S,D_A\rangle}{\|D_S\|^2+\|D_A\|^2}\in[-1,1].
\]
증명: 제곱 노름을 전개하고 Cauchy–Schwarz와 \(2uv\le u^2+v^2\)를 적용한다.
같은 크기의 완전 반대 효과면 \(C=R=1\), 직교 효과면 \(C=0\)이다.
이는 지표 해석이며 공격 탐지 정리가 아니다.

### 명제 2: 비선형 공동 삭제 오차

\(q=D_{SA}-(D_S+D_A)\)라 두면
\[
 \left|C_{S,A}+\frac{2\langle D_S,D_A\rangle}{E_S+E_A}\right|
 \le\frac{2\|D_S+D_A\|\,\|q\|+\|q\|^2}{E_S+E_A}.
\]
증명: \(\|D_S+D_A+q\|^2\)를 전개한 뒤 삼각부등식을 적용한다.
따라서 선형 TRACE 잔차가 작아도 실제 공동 삭제가 복원하지 않을 수 있다.
현재 구현은 \(\|q\|^2\)와 실제 잔차를 모두 기록한다.
일반 비선형 개입에서는 \(C\)의 하한 -1은 성립하지 않는다.

혼합 차분 \(D_{SA}-D_S-D_A\)만을 탐지 점수로 쓰지 않는 이유도 같다.
완벽하게 가법적인 잠복 상쇄에서는 이 값이 0일 수 있다.

### 명제 3: 상쇄만으로 악의를 식별할 수 없음

모든 관측 입력·개입에서 같은 \((M_0,M_S,M_A,M_{SA})\) 예측을 내는
정상 세계와 공격 세계를 구성할 수 있다. 정상 세계에는 충돌하는 두 학습 목적을,
공격 세계에는 주입·억제 목적을 배정하되 함수 효과는 같게 두면 된다.
관측 분포가 같으므로 그 관측의 함수인 어떤 판정기도 두 세계를 항상 구별할 수 없다.
따라서 추가 가정 없는 ‘상쇄 ⇒ 악성’ 또는 정상 오탐 0 보장은 불가능하다.
`honest_opposition` 합성 실험은 공격 fixture와 동일한 출력을 내도록 만든 명시적 반례다.

## 5. 점수와 판정

같은 전체 요청 크기·비율을 가진 비교 요청 집합 \(\mathcal B\)를 사용한다.
표본 수·참여량·분포까지 자동으로 일치하는 것은 아니다.
각 확인 뷰에서 비교 요청 에너지의 중앙값 \(\mu_v\), MAD 척도 \(s_v\)를 계산한다.

\[
 z_v=\frac{E_S^v-\mu_v}{\max(s_v,10^{-6})},\qquad
 T=\max_v [z_v]_+[C_v]_0^1[R_v]_0^1.
\]

휴리스틱 추가 경보: 어느 뷰에서 \(z_v\ge3,C_v\ge0.5,R_v\ge0.5\),
충분한 요청 에너지와 비어 있지 않은 상대 집합이 모두 성립.
공개 뷰의 요청/공동 모델 TV 변화가 0.3을 넘으면 `inconclusive`다.
공통 제어기의 더 엄격한 보존 예산(기본 0.15)도 따로 적용한다.
\(z\)를 정규분포 유의확률로 해석하지 않는다.

통합 규칙은 \(\mathrm{hold}=\mathrm{DOSE\ risk}\lor\mathrm{paired\ risk}\lor\mathrm{retention\ failure}\).
**paired 실패가 DOSE 경보를 취소할 수 없다.** BadFU 실제 실험이 이 설계를 지지한다.
CCD는 감사 우선순위를 제공하며 ‘경보 없음’으로 요청 검사를 생략하지 않는다.
새 단계는 `--paired_confirm`으로 켜는 실험 옵션이다.

### 선택 가능한 정상 에피소드 보정

선택·모델 개입·뷰 최댓값·삭제 단계 최댓값까지 포함한 전체 파이프라인을 고정한 후,
독립적으로 얻은 정상 에피소드 점수 \(T_1,\ldots,T_n\)로
\[
 p=\frac{1+\sum_i\mathbf1\{T_i\ge T_{test}\}}{n+1}
\]
를 정의한다. 정상 보정/시험 에피소드 점수가 교환 가능하면 순위 대칭성으로
\(\Pr(p\le\alpha)\le\alpha\)가 성립한다(동점은 보수적으로 처리).
이는 기존 순위 검정의 적용이며 새로운 통계 정리라고 주장하지 않는다.
최소 유의확률은 \(1/(n+1)\). \(\alpha=.05\)에는 최소 19개 보정 에피소드가 필요하며,
19개가 충분한 실증 검정력을 보장하는 것은 아니다.

같은 모델의 입력 500장, 클라이언트 20명, 여러 삭제 비율은 정상 학습 에피소드 500/20개가 아니다.
현재 실제 실험에는 이 보정 집합이 없으므로 실제 p값/유의수준 보장은 제시하지 않는다.
사전 고정된 L개 검정에는 Bonferroni를 적용할 수 있지만, 적응적 요청에는 조건부 유효성이
추가로 필요하다. 서로 의존하는 CCD 조건 확률을 곱하거나 Fisher/χ²를 무조건 적용하지 않는다.

## 6. 전체 방어 과정과 복구

1. 학습 중: 기존 CCD 기록으로 감사 우선순위를 정한다. 역할 확정에 쓰지 않는다.
2. 요청 시: 불변 기준에 누적 요청을 반영하고 작은 삭제 비율부터 DOSE와 선택적 paired 검사를 한다.
3. 위험/관측 부족: 현재 서비스 모델을 유지하고 요청을 보류한다. 삭제 완료로 표시하지 않는다.
4. 설명: TRACE 및 별도 입력의 실제 공동 삭제 결과를 후보 증거로 남긴다. 자동 추방하지 않는다.
5. 복구: 요청 전체를 반영한 재학습/FedEraser 등으로 후보 모델을 만든다. 되감기만으로는 이전 기여가 남을 수 있다.
6. 승인: 별도 입력에서 보존 성능·잔여 공격·망각 증거를 확인한 경우에만 교체한다.
7. 후속 학습: 새 기준/기여 기록으로 재활성화를 검사한다. 지연 재활성화 실증은 아직 필요하다.

현재 `Verification` 콜백은 확인 결과의 인터페이스다. 값이 True라는 사실 자체가 수학적
망각 인증을 생성하지 않는다. 실제 어댑터에는 이를 보장하는 검증기가 연결되어 있지 않다.

## 7. 비용

한 단위 요청에서 단일 삭제 예측을 재사용하면 기준 1 + 요청 1 + 동료 K-1 +
상대/공동 모델 최대 2, 즉 최대 K+3개 개입 모델을 평가한다.
다중 요청 비교군은 추가 모델이 필요하며 코드의 `n_interventions`를 보고한다.
TRACE는 후보 효과의 Gram 행렬을 만든 뒤 제한된 전진 선택을 한다.
순전파 외 학습이 없다는 것은 근사 감산 어댑터에만 해당한다.
모델 상태를 생성/로딩하는 비용이 있으며 FedEraser나 재학습 연산자를 쓰면 그 비용이 추가된다.

## 8. 노벨티를 어디에 둘 것인가

유지: 기존 CCD·DOSE·TRACE·FedEraser, 공동 상쇄라는 기존 관찰.
후보 기여: **요청에 조건부인 상대 선택 → 독립 입력에서 실제 네 모델 확인 →
선형 복원 실패/정상 반대 기여/관측 부족을 구별하는 감사 프로토콜**.
고유한 값은 이름이나 정규화 비율이 아니라, 기존 선택 결과를 검증 가능한 주장으로 제한하는 데 있다.
‘최초의 counterfactual backdoor defense’는 주장하지 않는다.

- [MASA, WACV 2025](https://openaccess.thecvf.com/content/WACV2025/html/Xu_Identify_Backdoored_Model_in_Federated_Learning_via_Individual_Unlearning_WACV_2025_paper.html)는 개별 언러닝으로 악성 로컬 모델을 탐지한다. v5의 ‘악성 삭제 요청 탐지, 2024’ 표기는 수정한다.
- [UnlearnGuard, WWW 2025](https://arxiv.org/abs/2501.17396)는 언러닝 중의 악성 업데이트와 재구성/필터링을 다룬다. 잠복 공격에 적용 불가능하다고 단정하지 말고 동일 위협·정보·비용 조건에서 비교해야 한다.
- [BadFU 원문](https://arxiv.org/abs/2508.15541)은 같은 악성 클라이언트의 backdoor/camouflage 표본을 사용한다. 로컬 6클라이언트 surrogate와 구분한다.
- [BBCaL 공개 원고](https://openreview.net/notes/edits/attachment?id=cJ3e8RwIZu&name=pdf)는 입력의 counterfactual 변형을 통한 추론 시점 탐지를 이미 다룬다. 여기서는 삭제 단위의 모델 개입이라는 차이를 검증해야 한다.
- [교환 가능성과 순위 검정](https://arxiv.org/abs/2005.06095)의 조건을 실제 에피소드 설계에서 충족해야 한다.

문헌 차이만으로 노벨티가 확정되지는 않는다. 기존 TRACE에 대한 기여 분리 실험,
동일 오탐률의 비교, 다른 학습 시드/연산자 검증이 출판 수준의 기여를 결정한다.
