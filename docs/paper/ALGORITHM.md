# DOSE + TRACE + DEFUSE: 알고리즘 정식화와 가정 (2026-10-12)

이 문서가 방법의 **정본**이다. METHOD.md 는 설명, MATH.md 는 유도, 이 문서는 "정확히 무엇을 계산하고, 무엇을 가정하는가". 코드는 `FUBA/cancel_fu.py` (세 부품이 한 파일), 삭제 연산자 부품은 `FUBA/dose_fu.py` 의 `Engine`.

## 0. 가칭과 역할
| 가칭 | 하는 일 | 책임지는 성질 | 코드 |
|---|---|---|---|
| **DOSE** | 요청자 기여를 견디는 양만큼 단계로 빼고, 단계마다 "남들을 같은 양 뺀 모집단" 띠 안인지 확인하는 삭제 연산자 | 안전: 띠 밖 모델·무너진 모델 불출 (P2, P3). 정상 요청 = 기본 FU (P1) | `dose_fu.Engine` (dose / population / check / threshold), `cancel_fu.py` 본 루프 |
| **TRACE** | 띠를 벗어나면 "어디서(ω), 누가(S, w)" 요청자와 서로 지우고 있었는지를 푸는 귀속 | 귀속 출력 (P5): 짝 S, 타깃 c*, 입력 X_act, 방향 h | `cancel_fu.attribute` (회전 1), `cancel_fu.pair_at_activation` (회전 2+) |
| **DEFUSE** | 짝의 기여에서 활성화 방향 성분만 빼서 띠 안으로 되돌리는 해제 | 삭제 이행 (P4): 요청자 기여 재주입 0, 잊힌 것 되가르치지 않음 | `cancel_fu.purify`, `cancel_fu.kd_orth` |

전체: **DOSE+TRACE** (DEFUSE 는 TRACE 의 출력을 쓰는 후속 단계라 이름에서 생략). 한 줄: DOSE 가 안전을, TRACE+DEFUSE 가 삭제 이행을 책임지고, 둘을 합쳐 **안전과 삭제 이행을 동시에** 얻는다.

## 1. 가정 (전부)
각 가정에 "어디에 쓰이나"와 "깨지면 무엇이 안 되나"를 붙인다. 실험에서 확인된 것은 ✔, 가정으로만 두는 것은 ○.

## 2. 기호
- K 클라이언트, T 라운드, U_j = Σ_t U_j^t, θ_T 최종 모델, C 클래스, f(x; θ) ∈ R^C 로그확률, p = exp f.
- 요청 (k, X_f). 탐침 X = X_p ∪ X_f, N = |X|. 가짜 라벨 ŷ(x) = argmax f(x; θ_T).
- 기능 효과 E_j(X; θ, ε) = [f(X; θ − εU_j) − f(X; θ)]/ε ∈ R^{N×C}. 중심화 Ẽ_j = E_j − median_i E_i.
- 제거 연산자 R(θ, k, ρ) = θ − ρU_k (subtract) 또는 그 뒤 짧은 증류 (kd; 깊은 망).
- 변화 비율 chg(θ_a, θ_b; X) = mean_x 1[argmax f(x;θ_a) ≠ argmax f(x;θ_b)].
- flow 통계 a(P_k, P_ref): 기준 답 i → 모델 답 j 의 흐름 행렬 F 에서, 가장 많이 받은 열 j* 의 양 × 출발 클래스 다양성(정규화 엔트로피). 출력 (a, c* = j*, src_div, flip_conf).
- 강건 z: z(x; {s_j}) = (x − median s)/std(s) (ddof 1). 흩어짐 0 이면 "판단 불가" 표시 (Z=99).

## 3. DOSE (삭제 연산자)
### 3.1 부품
```
Population(θ, ρ, k):                                     # 모델 버전 θ, 양 ρ 마다 한 번 (요청자 무관, 공유)
    for j in 1..K:  θ_j ← R(θ, j, ρ);  P_j ← p(X_p; θ_j);  chg_j ← chg(θ_j, θ; X_p)     # K 순전파
    H ← { j ≠ k : chg_j ≤ c }                            # 건강한 남들
    P_j ← [P_j ; p(X_f; θ_j)]  for j ∈ H                 # 요청자가 X_f 를 냈으면 그 위도 (K 순전파)
    ref_{−j} ← median_{i∈H∖{j}} P_i ;  s_j ← a(P_j, ref_{−j})   for j ∈ H       # LOO 통계
    ref ← median_{i∈H} P_i
    return (H, ref, {s_j}, h = median_j chg_j)
Dose(θ, k, ρ_left):                                      # 모두가 견디는 양
    for ρ in [ρ_left, 0.8, 0.6, 0.4, 0.2, 0.1] with ρ ≤ ρ_left:
        pop ← Population(θ, ρ, k);  if pop.h ≤ c: return ρ, pop
    return δ_min, Population(θ, δ_min, k)
Guard(θ, k, ρ):  chg(R(θ,k,ρ), θ; X_p) ≤ c  인 가장 큰 ρ' ≤ ρ 를 고른다; 없으면 '무너짐'
Check(θ_k, pop):  P_k ← p(X; θ_k);  (a_k, c*, …) ← a(P_k, pop.ref);  z ← z(a_k; {s_j}_{j∈H})
Threshold(pop):  τ (fixed)  또는  max_j z_LOO(s_j) + margin (loo)
```
### 3.2 루프 (요청 k)
```
θ ← θ_T; ρ_done ← 0; trace ← []
while ρ_done < 1:
    ρ, pop ← Dose(θ, k, 1 − ρ_done);  ρ ← Guard(θ, k, ρ)  (무너짐이면 break: accept(partial))
    θ ← R(θ, k, ρ);  z, c*, X_act ← Check(θ, pop)
    ρ_done += ρ;  trace.append(ρ, z)
    if z > Threshold(pop):  θ ← DEFUSE(TRACE(θ, pop, k))    # §4, §5; 실패면 reject
return θ, trace
```
### 3.3 성질
- P1: z ≤ τ 인 요청은 R 만 적용된 모델이 나간다 (기본 FU 와 동일). 추가 비용 = 순전파.
- P2: 무너진 모델(chg > c) 은 만들지도 내보내지도 않는다.
- P3: 내보내는 모델은 모든 단계에서 띠 안 (z ≤ τ).
- 비용: 모델 버전당 K 개 가상 제거 모델(공유), 요청당 새 모델 0, 순전파 K (X_f 위) + 1.

## 4. TRACE (귀속)
### 4.1 목적식
```
max_{ω ≥ 0, S, 0 ≤ w ≤ w_max, |S| ≤ r}   Σ_x ω(x) · [ ‖Ẽ_k[x]‖² − ‖Ẽ_k[x] + Σ_{j∈S} w_j Ẽ_j[x]‖² ]
```
ω = 어디서, (S, w) = 누가. 괄호 안 = 입력 x 의 상쇄 에너지.
### 4.2 풀이 부품
```
BoxLS(G, b, S):   min_{0≤w≤w_max} 2 Σ_j w_j b_j + wᵀ G_SS w      (좌표 하강; G 그램, b 목표와의 내적)
Forward(G, b, base, cand):  S ← ∅; repeat: j* ← argmin_j resid(BoxLS(G,b,S∪{j})); 개선 < η·resid 면 멈춤; |S| ≤ r
Gap(align): 정렬 오름차순 정렬 → 인접 차가 최대인 곳에서 자름 → 아래쪽 중 align ≤ −a_min 인 것 전부
```
### 4.3 회전
```
회전 1  (θ_T, ω⁰ = 1[X_p ∪ X_f]):
    Ẽ_j ← 중심화 E_j(X; θ_T, ε)  for all j                          # 공개 부분은 모델 버전당 1 회 공유; X_f 부분 K 순전파
    G ← ẼẼᵀ (K×K);  for all j:  (c_j, S_j, w_j) ← Forward(G, G[j], G_jj, others(j))
    where: e(x) = ‖Ẽ_k[x]‖² − ‖Ẽ_k[x] + Σ_{S_k} w Ẽ[x]‖²;  어디서 비율 = Σ_{x∈X_f} e⁺ / Σ_x e⁺
    통계 (모든 j): c_j 상쇄, g_j = max_c mean_x Ẽ_j[x,c] × src_div, m_j = ‖Ẽ_j‖/√N, a_j = mean_t −cos(Ẽ_j^t, Σ_{S_j} w Ẽ^t) (궤적, 선택)
    p^{(s)} ← conformal(k 의 통계 vs 남들),  z^{(s)};  Fisher F = −2Σ log p^{(s)}
    경보₁ ← Fisher p ≤ α_p  or  max_s z^{(s)} > τ_a
    출력: S¹ = S_k, w¹, c¹ = argmax_c mean_x Ẽ_k[x,c], 어디서 비율
회전 2  (θ' = DOSE 의 현재 모델, ω¹ = 1[X_act], 타깃 열 c*):
    A ← f(X_act; θ')[·,c*] − log ref(X_act)[·,c*]                   # 활성화 (기준 = 모집단 중앙값)
    for j ≠ k:  θ'_j ← θ' − ε₂U_j (ε₂ = 0.5ρ);  if chg(θ'_j, θ'; X∖X_act) > c: 제외
                E'_j ← (f(X_act; θ'_j) − f(X_act; θ'))[·,c*]/ε₂   (중심화 없음)
    align_j ← ⟨A, E'_j⟩/(‖A‖‖E'_j‖);  S² ← Gap(align);  w² ← BoxLS(G', b', S²)
회전 i ≥ 3 (선택):  resid ← A + Σ_{S} w E';  ω ← 1[A² − resid² > 0];  S, w 다시 (BoxLS·Gap on ω);  S 불변이면 멈춤
```
### 4.4 식별 가능성 (명제, 선형화 하에서; 증명은 초안 작업)
**명제.** T1 이 성립하고, ω 의 지지집합 X̂ 가 (i) ‖J_{X̂∩X*}U_k‖² ≥ γ‖J_{X*}U_k‖² 를 만족하며, (ii) X̂ 위에서 {Ẽ_j : j ∈ A} 가 선형 독립이고 정상 j ∉ A 의 Ẽ_j 가 span{Ẽ_k, Ẽ_A} 에 직교하면, 목적식의 (S, w) 최소해는 S = A, w = w* + O(잔차/γ) 이다.
**따름정리 (불가능).** X̂ ∩ X* = ∅ 이고 X̂ 위에서 Ẽ_k 가 정상 클라이언트의 Ẽ 와 분포가 같으면(누출 없음), X̂ 만 보는 어떤 절차도 k 를 정상과 구분하지 못한다.
**절차와의 대응.** BadFU: X_f ⊃ X* 라 회전 1 의 ω⁰ 가 (i) 를 만족 → 회전 1 에서 S = A (로컬 ✔). FUBA: X_p ∩ X* = ∅ 이나 누출(크기·몰림 z) 이 있어 DOSE 경보가 나고, X_act 가 (i)(ii) 를 만족 → 회전 2 에서 S = A (3 시드 ✔). 깨끗한 입력에서 (ii) 가 깨지는 것(무리 구조) 이 회전 1 의 짝이 정상에게도 운반자로 나오는 이유.

## 5. DEFUSE (해제)
```
입력: θ' (DOSE 현재), pop, k, S (= S² 또는 S¹), X_act, c*
h ← ∇_θ mean_{x∈X_act} log p(c*|x; θ')                      # 역전파 1 회
U_j^∥ ← (⟨U_j, h⟩/‖h‖²) h   for j ∈ S                        # 짝 몫의 활성화 방향 성분 (로컬: 몫의 4–5 %)
for λ in Λ (오름차순):
    θ'' ← θ' − λ Σ_{j∈S} w_j U_j^∥   (w 균등)
    if chg(θ'', θ'; X∖X_act) > c: break                      # 건강 = 비활성 입력 불변
    z'' ← Check(θ'', pop).z;  if z'' ≤ z_target: accept λ; break
(선택, 본 방법 아님) Polish:  교사 = ref (모집단 기준), 입력 = X   # 정확도 회복용. 교사에 요청자 지식이 들어 있어 되가르침이 생긴다 (O6) → 소거 실험으로만
    θ'' ← 50 걸음 SGD on KL(p(·;θ'') ‖ ref), 매 걸음 기울기 g ← g − ⟨g, û_k⟩û_k   (α 는 불변, 기능 망각은 아님)
    채택 조건: z ≤ τ, 건강 ≤ c
실패 → 재억제 (KL to ref, 전 입력, 투영 없음; α > 0) → 그래도 z > τ 면 reject
보고: α = ⟨θ'' − θ', U_k⟩/‖U_k‖²,  요청자 자기 데이터 정확도 (기능 공간 망각)
```
- P4: 본 방법(증류 없음)에서 θ'' − θ' 는 h 방향(짝 몫)뿐 → α ≈ 0 이고 요청자 자기 데이터 정확도도 빼기만 했을 때와 같다 (오탐 시드 50.7 vs 49).
- 증류를 붙이면 (DISLAB·로컬 확인): 교사 = θ' 자신은 백도어를 되살림 (z 0.9 → 12.5); 교사 = 남들 모델(pop) 은 오탐 시 되가르침 (자기 데이터 50 → 79); 답이 안 바뀐 입력만(agree) 도 75; 영향 작은 공개 입력 절반만(low) 은 모델이 흔들려 ACC 90 → 84. **결론: 요청자 지식이 든 모델을 교사로 쓰는 어떤 정확도 회복도 기능 공간에서 요청자 지식을 되들여온다.** 본 방법은 증류 없이 가고, 증류는 'ACC +1~3 vs 망각' trade-off 소거 실험으로만 보고한다 (O6).
