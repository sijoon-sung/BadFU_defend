# MNTD 방식 GPU 예비 실험 결과

2026년 10월 9일, RTX 3060 Ti에서 CIFAR-10/ResNet18 shadow 모델 32개와 두 메타 분류기를 실제 학습했다. **이번 소규모 설정에서는 학습한 질의가 고정 무작위 질의보다 좋다는 근거를 얻지 못했고, 정상 보정 모델로 정한 임계값에서 두 방식 모두 평가 공격 4개를 놓쳤다.**

원래 BadFU의 정상·공격 FU 전후 체크포인트는 이 작업 공간에 없어 검사하지 못했다. 이 결과는 별도의 범용 patch/blend shadow 실험이며, BadFU/FUBA의 언러닝 후 활성화 탐지 결과가 아니다. 원래 네 조건을 읽는 검사 코드는 [실행 안내](../../experiments/mntd_check/README.md)에 있다.

## 실제 측정 결과

| 방법 | 평가 AUC | 공격 경보 | 정상 오탐 | 정상 보정 임계값 |
|---|---:|---:|---:|---:|
| 고정 무작위 질의와 학습한 분류기 | 0.8125 | 0/4 | 0/4 | 0.190304 |
| 질의와 분류기를 함께 학습 | 0.7500 | 0/4 | 0/4 | 0.384743 |

두 방법의 입력·분류기 초기화와 meta 학습 순서를 맞췄다. 차이는 질의 tensor를 최적화하는지 여부다. 임계값은 각각 별도 정상 보정 모델 4개의 최대 점수로 고정했고, 평가 공격 결과를 보고 낮추지 않았다. 점수는 logit이며 확률이 아니다. 평가 모델이 정상 4개·공격 4개뿐이므로 AUC 차이에 통계적 유의성을 주장하지 않으며, 관측된 오탐 0/4가 모집단 FPR 0%를 뜻하지 않는다.

평가 정상 모델의 clean ACC 평균은 39.10%, 공격 모델의 clean ACC 평균은 30.90%였다. 평가 공격 모델의 각자 트리거에 대한 ASR 평균은 96.72%였다. 모델 학습량이 작고 정상·공격의 정상 성능도 달라, 점수의 차이가 백도어 특성인지 모델 품질 차이인지 분리되지 않았다. 학습/보정 공격에는 ASR이 낮은 모델도 포함되어 있으며, 결과를 보고 제거하지 않았다.

학습 질의 방식의 평가 공격 최대 점수는 0.187574로 임계값 0.384743보다 낮았다. 따라서 AUC 0.75를 실용적인 탐지 성공으로 해석할 수 없다. 반대로 소수 shadow·수정된 모델·eval 모드 조건의 실패만으로 원 MNTD 전체가 무효라고 결론 내릴 수도 없다.

## 실행 조건

- GPU: NVIDIA GeForce RTX 3060 Ti, 8 GB. 기존 CPU 환경과 별도로 CUDA 가상환경 설치.
- PyTorch 2.5.1+cu121, torchvision 0.20.1. 실제 실험 본문 약 78.27초. 환경 설치와 CIFAR 다운로드 시간은 제외되며, 최초 ResNet 가중치 로드는 포함된다.
- 정상 보조 이미지: CIFAR-10 학습셋에서 고정 seed로 뽑은 1,000개. 모델 품질 진단은 테스트셋 앞 1,000개에서 수행.
- Shadow: 학습 정상 8·오염 8, 보정 정상 4·오염 4, 평가 정상 4·오염 4. 모델 seed 300000–300031, split 간 중복 없음.
- 각 모델: ImageNet 초기화 ResNet18의 conv1과 fc를 교체, SGD 0.01, batch 64, 3 epochs.
- 오염: 모델마다 patch/blend 크기·위치·값·타깃·비율을 무작위 생성. BadFU record와 트리거는 사용하지 않음.
- Meta: 진단 입력 10개, 모든 클래스 logit을 연결한 100차원 입력, 은닉 20, 출력 1. Adam 0.001, 10 epochs, meta seed 8193.
- 입력 질의는 정규화된 CIFAR tensor 공간에서 학습. shadow 모델은 eval 모드에서 동결. backward는 메타 학습용이며 검사 시에는 forward만 사용.
- 정상 보정 임계값의 모집단 FPR 또는 정상 FU로의 이전은 보장하지 않음. 정화와 추가 진단 FU는 수행하지 않음.

원본 CIFAR 호스트가 느려 최초 실행은 다운로드 단계에서 중단했다. 동일 archive의 미러를 사용한 후 torchvision의 원본 MD5와 일치함을 확인했다: `c58f30108f718f92721af3b95e74349a`. 이 중단은 모델 학습 전에 발생했으며, 결과를 보고 실험을 선택한 것이 아니다.

## 재현과 기록

```bash
python -u -m experiments.mntd_check --pilot --out artifacts/mntd_pilot --data-root /path/to/cifar10
```

공개 기록: [전체 점수](mntd_pilot_20261009/summary.json), [실행 설정](mntd_pilot_20261009/experiment.json), [shadow 모델 품질](mntd_pilot_20261009/shadow_inventory.json), [정상 입력 ID](mntd_pilot_20261009/auxiliary.json). 학습된 모델은 로컬 실험 폴더에 보존하고 Git에 올리지 않는다. 공개 inventory의 경로는 실험 폴더 기준 상대경로로 표기했다.

코드 검증 4개가 통과했다: AUC 방향·동점, query 학습 중 원 모델/BN 비변경, 네 체크포인트 대응과 hash 검사, 모델 누락 시 가짜 결과를 만들지 않는 동작.

## 다음 판단

MNTD를 바로 정화 제어에 연결할 근거는 아직 없다. 먼저 현재 정상 보정 기준을 유지한 채 원래 BadFU 전후 모델을 검사해야 한다. 원 체크포인트에서 점수 분리가 없으면 이 소규모 이식 방식은 채택을 보류한다. 추가 학습량·더 많은 shadow·FL에 맞춘 분포를 시험한다면 개발 실험으로 구분하고 새 평가 모델을 사용한다.
